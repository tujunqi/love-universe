media/videos/ 使用说明
========================================

这里放视频。

推荐格式：MP4（H.264 视频 + AAC 音频）
推荐大小：单个 200MB 以内
文件名：英文或数字，不要有空格和中文，例如 first-trip.mp4

放好之后，打开上级目录的 museum.js，找到：

  videos: [
    // {
    //   src: "media/videos/first-trip.mp4",
    //   poster: "media/photos/p07.svg",
    //   title: "第一次旅行",
    //   date: "2024.01.13",
    //   note: "在陌生城市醒来的第一个早上"
    // }
  ],

把 // 去掉，改成你们自己的文件名和标题，保存刷新。

手机拍的 MOV 如果不能播放，先用 HandBrake 或格式工厂转成 MP4。
iPhone 的 HEVC 格式有些浏览器不支持。

没有视频也没关系，保持空数组 []，页面会显示“影音厅正在布展”。
