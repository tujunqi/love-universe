我们的私人博物馆 · 离线版
========================================

这是一座只接待两位观众的私人博物馆。
不需要联网，不需要安装软件，照片、视频、语音、回忆录都放在这个文件夹里。

------------------------------------------------------------
一、30 秒开始
------------------------------------------------------------

Windows：
  双击「打开我-Windows.bat」。
  如果系统问“用什么程序打开”，选 Edge、Chrome 或 Firefox 任意一个浏览器。

macOS：
  双击「打开我-Mac.command」。
  第一次如果提示“无法打开，因为无法验证开发者”，
  右键这个文件 → 打开 → 再点一次“打开”。

Linux：
  在终端里执行：bash 打开我-Linux.sh

进入封面后：
  1. 点「推门进入」。
  2. 背景音乐需要这一次点击才能播放，这是浏览器的规定，不是坏了。
  3. 想全屏参观，双击「全屏参观.bat」；退出按 Alt + F4。

如果双击 HTML 没反应：
  右键「离线博物馆.html」→ 打开方式 → 选择浏览器。
  （不要用 Word、记事本打开 HTML，会看到一堆代码。）


------------------------------------------------------------
二、文件夹里都有什么
------------------------------------------------------------

离线博物馆.html      博物馆本体，双击就能看
museum.css           外观样式，不用改
museum.js            所有文字、照片、日期都在这个文件里改
使用说明.txt         你正在看的这一份
打开我-Windows.bat   Windows 一键打开
打开我-静默.vbs      Windows 无黑框打开（适合做快捷方式）
全屏参观.bat         用浏览器全屏模式打开，像展馆
打开我-Mac.command   macOS 一键打开
打开我-Linux.sh      Linux 一键打开
autorun.inf          U 盘自动播放配置（Windows 通常不认，详见后文）
museum.ico           博物馆图标，可以设为 U 盘图标

media/photos/        照片（现在是 20 张示例插画）
media/videos/        视频（现在为空，页面显示“布展中”）
media/voice/         语音（现在有 2 条示例语音）
media/memoirs/       回忆录、PDF、TXT 文档
media/audio/         背景音乐

所有素材都在本地。断网、拔网线，博物馆仍然能开。


------------------------------------------------------------
三、先改成你们自己的（只改 museum.js 顶部）
------------------------------------------------------------

用「VS Code」或「Notepad++」打开 museum.js。
不要用 Windows 记事本，它可能把中文和引号改坏。

整个文件最上面有一大段：

  const MUSEUM = {
    ...
  };

你只需要改这一段，下面的代码一行都不要动。

【1. 名字】
  names: {
    me: "阿星",
    partner: "小满"
  },
  把“阿星”“小满”换成你们的名字。
  馆里所有 {me} 和 {partner} 会自动变成这两个名字。

【2. 在一起的日期】
  startDate: "2023-05-20T20:13:00",
  格式是 年-月-日T时:分:秒。
  只改数字，引号和字母 T 都保留。
  序厅的“在一起 X 天”和“X 年”会按这个时间实时计算。

【3. 纪念日】
  anniversary: { month: 5, day: 20 },
  只写月和日，不写年份。

【4. 开馆封面】
  cover: {
    image: "media/photos/cover-1.svg",
    kicker: "OUR PRIVATE MUSEUM",
    title: "我们的私人博物馆",
    subtitle: "仅接待两位观众",
    note: "请轻推门 · 馆内禁止赶时间",
    enter: "推门进入"
  },
  image 换成你们自己的封面照片，例如：
    image: "media/photos/封面.jpg",
  建议横图，1600×1000 左右，文件小于 500KB。
  标题最多 8 个汉字最稳，太长会换行。

【5. 背景音乐】
  music: "media/audio/bgm.wav",
  把你们的歌改名成 bgm.mp3，放进 media/audio/，
  然后改成：
    music: "media/audio/bgm.mp3",
  支持 MP3 / WAV / M4A。建议 MP3，文件小。
  如果不想自动播放：
    autoplayOnEnter: false,

【6. 馆藏版本号】
  version: "离线版 · 2026.10 · 第 1 版",
  每年更新一次，写给几十年后的自己看。

改完保存，回到浏览器按 F5 刷新。不需要重新打包。


------------------------------------------------------------
四、换照片（最常做的事）
------------------------------------------------------------

【方法 A：保留文件名，直接覆盖】
  把你们的照片改名成 p01.jpg、p02.jpg……p20.jpg，
  放进 media/photos/，覆盖原来的 p01.svg……p20.svg。
  然后打开 museum.js，把对应的 ".svg" 改成 ".jpg"。
  例如：
    { src: "media/photos/p01.jpg", title: "第一次一起看海", ... }

【方法 B：用新文件名，逐条改】
  把照片放进 media/photos/，名字用英文或数字，不要用空格。
  然后在 photos: [ ... ] 里逐条改 src、title、date、tag、alt。

  src    图片路径
  title  照片标题（显示在照片下方）
  date   日期，例如 "2024.09.17"
  tag    筛选标签，只能从已有的标签里选：
         "旅行" "日常" "纪念日" "风景"
         想加新标签，直接在任意一条里写，筛选按钮会自动出现。
  alt    一句图片描述，给读屏软件和图片丢失时看

照片建议：
  · 长边 1600 像素以内，单张 300KB 左右最合适
  · JPG / PNG / WebP / SVG 都可以
  · 竖图、横图、方图混着放更好看
  · 文件名不要有空格、#、?、% 这些符号
  · 至少保留 6 张，页面才不空

想加减照片：
  在 photos: [ ... ] 里复制一整行（从 { 到 },），
  改内容就是新增；删掉一整行就是减少。
  最后一行后面不要留逗号。


------------------------------------------------------------
五、加视频
------------------------------------------------------------

1. 把视频放进 media/videos/，例如 first-trip.mp4。
   推荐 MP4（H.264 + AAC），这个格式所有浏览器都认。
   手机拍的 MOV 最好先转成 MP4。
2. 打开 museum.js，找到：

  videos: [
    // { ... }
  ],

3. 把注释符号 // 去掉，改成：

  videos: [
    {
      src: "media/videos/first-trip.mp4",
      poster: "media/photos/p07.svg",
      title: "第一次旅行",
      date: "2024.01.13",
      note: "在陌生城市醒来的第一个早上"
    }
  ],

  src     视频文件
  poster  视频封面图（可以不写）
  title   视频标题
  date    日期
  note    一句话说明

4. 保存刷新。点击视频卡片，视频会在页面里直接播放。

注意：
  · 单个视频建议小于 200MB，太大打开会卡
  · 文件名用英文/数字，不要用中文和空格
  · 如果是 iPhone 的 HEVC 视频，浏览器可能不支持，先转码


------------------------------------------------------------
六、加语音
------------------------------------------------------------

1. 用手机录音，导出 MP3 / M4A / WAV。
2. 放进 media/voice/，例如 2024-birthday.m4a。
3. 在 museum.js 的 voices: [ ... ] 里加一条：

  {
    src: "media/voice/2024-birthday.m4a",
    title: "你 24 岁生日那天说的话",
    date: "2024.05.20",
    note: "在厨房，油烟机有点吵"
  },

4. 保存刷新。点播放键就能听，时长会自动读出来。

想删掉示例语音：
  把 voices 里的两条示例整段删掉，换成你们自己的。
  一条都没有也可以，页面会显示“暂无语音”。


------------------------------------------------------------
七、回忆录与文档
------------------------------------------------------------

【回忆录正文】
  在 museum.js 的 memoirs: [ ... ] 里。
  每一章是一个 { title, date, minutes, paragraphs }。
  paragraphs 里：
    "普通一句话"         = 正文段落
    "> 想强调的一句话"   = 引用样式
    "---"                = 一条分隔线

  一章建议 3～6 段，每段 1～3 句。
  章节标题格式：
    "第一章 · 我们是怎么开始的"

【馆藏文档】
  把 PDF / TXT / DOCX 放进 media/memoirs/，
  然后在 documents: [ ... ] 里登记：

  {
    src: "media/memoirs/给未来读者.pdf",
    title: "给未来读者",
    note: "如果网页打不开，先读这一页",
    type: "PDF"
  },

  type 写 PDF / TXT / DOCX。
  PDF 和 TXT 会在浏览器里直接打开；
  DOCX 会让浏览器下载，需要 Office 或 WPS 才能看。

  强烈建议同时保留一份 TXT：
  几十年后，PDF 阅读器可能没了，TXT 几乎永远能打开。


------------------------------------------------------------
八、时间胶囊
------------------------------------------------------------

  capsule: {
    openDate: "2035-05-20T20:13:00",
    password: "0520",
    ...
  }

  openDate  到这一天之后，倒计时结束，可以打开信
  password  打开信的密码（示例是纪念日 0520）

  在 capsule.paragraphs 里写这封信。
  密码只是“防手滑”，不是真正的加密。
  真想保密，请把信放进加密压缩包，别直接放在 U 盘里。

  提示：密码可以写在纸质卡片上，和 U 盘分开放。
  别把密码写在同一个 U 盘的说明文件里。


------------------------------------------------------------
九、U 盘使用（重点）
------------------------------------------------------------

【拷贝】
  把整个 offline 文件夹的内容拷到 U 盘根目录。
  不要只拷 HTML，照片和音乐都在 media 里。

【打开】
  Windows：进 U 盘，双击「打开我-Windows.bat」。
  Mac：双击「打开我-Mac.command」。
  如果换电脑后打不开，先把整个文件夹拷到桌面再试，
  有些电脑会限制 U 盘里直接运行脚本。

【关于“插上 U 盘就自动播放”】
  Windows 10 / 11 出于安全考虑，默认禁止 U 盘自动运行，
  所以 autorun.inf 在大多数电脑上不会生效。
  这是系统限制，不是文件写错了。

  比较可靠的做法：
    1. 在 U 盘根目录放一个显眼的「打开我-Windows.bat」；
    2. 把 U 盘卷标改成“我们的博物馆”；
    3. 设置 U 盘图标（右键 U 盘 → 属性 → 自定义 → 更改图标）；
    4. 附一张纸质小卡片：插上 → 打开 U 盘 → 双击 bat。

  详见 docs/03-U盘离线博物馆.md 和 docs/05-开机画面与自动运行.md。

【格式】
  U 盘建议 exFAT：
    · Windows 和 Mac 都能读写
    · 单文件可以超过 4GB
  如果要在很老的设备上放，才考虑 FAT32（单文件不能超过 4GB）。

【安全拔出】
  等音乐停止、浏览器关闭后再弹出 U 盘。
  不要在播放视频时直接拔。

十、单文件版
------------------------------------------------------------

如果不想带一堆文件夹，可以用「单文件版」：
  media 里的照片、音乐、语音全部内嵌进一个 HTML 文件，
  拷到任何地方，双击就能看。

单文件版的位置：
  offline/单文件版/恋爱纪念博物馆-单文件版.html

限制：
  · 文件会比较大（现在约 2～3MB，加视频会更大）
  · 视频默认不内嵌，避免文件过大
  · 改内容后需要重新生成

重新生成的方法见 docs/03-U盘离线博物馆.md 的“单文件版”一节。


------------------------------------------------------------
十一、常见问题
------------------------------------------------------------

Q：打开是白屏？
A：确认 museum.css、museum.js 和 HTML 在同一个文件夹。
   如果是从压缩包里直接双击，先解压。

Q：照片显示“照片未找到”？
A：检查文件名大小写。Windows 不区分，但浏览器和 U 盘可能区分。
   p01.jpg 和 P01.JPG 是两回事。

Q：音乐没有自动响？
A：浏览器规定必须先有一次点击。点「推门进入」后才会播放。
   还是没声音，检查右下角音量、系统输出设备、文件路径。

Q：视频只有声音没有画面？
A：编码不被支持。用格式工厂 / HandBrake 转成 MP4（H.264 + AAC）。

Q：中文变成乱码？
A：用 VS Code 打开 museum.js，右下角选择 UTF-8，再保存。
   不要用记事本另存为 ANSI。

Q：改了文字刷新没变化？
A：浏览器缓存。按 Ctrl + F5 强制刷新。

Q：胶囊密码忘了？
A：打开 museum.js 搜索 password，能看到密码。
   这也说明它只是防手滑，不是真加密。

Q：手机能看吗？
A：可以。把整个文件夹拷进手机，用支持本地文件的浏览器打开。
   更推荐部署到网上，用链接看，见 docs/02-公网部署教程.md。


------------------------------------------------------------
十二、隐私提醒
------------------------------------------------------------

· 博物馆完全离线，不上传任何数据。
· 但 U 盘会丢、会坏、会被别人捡到。
· 不要把身份证、银行卡、住址、工作单位等敏感信息放进去。
· 真要有私密内容，用加密压缩包，密码单独保存。
· 送人之前，先在一台没登录过你们账号的电脑上完整看一遍。
