# 恋爱小助手 · 使用说明

> 一个只在你电脑上运行的命令行小工具。
> 不需要联网、不需要安装任何第三方包、不会把你们的任何内容上传。
> 记忆、情话、约会方案，全部围绕你自己填写的数据。

完整的新手教程（含安装 Python、语音、定时早安消息）在项目根目录：
[`docs/09-Python小助手运行教程.md`](../docs/09-Python小助手运行教程.md)

---

## 一、一分钟启动

### Windows

1. 电脑上要有 Python 3.9 或更新的版本。
2. 双击本文件夹里的 **`启动小助手.bat`**。
3. 看到下面这样的画面，就成功了：

```
======================================================
  恋爱小助手
  只存在你电脑里的纪念日与心事
======================================================
  今天：2026年10月25日 星期日
  阿星 & 小满：在一起第 1255 天
  最近的日子：2026年11月3日 星期二 · 小满体检复查 · 还有 9 天
======================================================

  1. 今日概览
  2. 问问小助手（记忆问答）
  ...
  0. 退出
```

如果双击后窗口一闪就没了，或者提示找不到 Python，先看本文最后的「常见问题」。

### macOS / Linux

在终端里进入本文件夹，运行：

```bash
python3 love_assistant.py
```

如果提示 `python3: command not found`，先安装 Python 3，再重试。

### 不想进菜单，直接问一句

```bash
python love_assistant.py --today
python love_assistant.py --ask "小满喜欢什么"
python love_assistant.py --scene night --note "她今天加班到十点"
python love_assistant.py --plan --budget 200 --hours 4 --indoor --start 14:00
python love_assistant.py --upcoming 60
```

## 二、文件夹里有什么

```
assistant/
├─ 启动小助手.bat          Windows 双击入口（推荐）
├─ love_assistant.py       主程序，所有功能都在这里
├─ 使用说明.md             你正在看的这份
├─ data/
│  ├─ memory.json          你的全部记忆（明文，重要）
│  ├─ backups/             每次保存前的自动备份
│  └─ exports/             你手动导出的副本
└─ out/                    生成的情话/约会方案保存到这里（用完才出现）
```

只有 `data/memory.json` 是必须保护的。其他文件删了都能重新生成。

## 三、主菜单能做什么

| 菜单 | 功能 | 典型用法 |
| --- | --- | --- |
| 1 | 今日概览 | 每天打开看一眼：在一起第几天、最近有什么日子 |
| 2 | 记忆问答 | 问「她喜欢什么」「第一次看海」「我们在一起多久」 |
| 3 | 生成情话 | 早安、晚安、道歉、安慰，可混入「今天的小事」 |
| 4 | 安排约会 | 输入预算、时间、室内外，给出 3 个方案和时间线 |
| 5 | 重要日子 | 查看未来 N 天的纪念日与事项 |
| 6 | 管理记忆 | 添加纪念日、重要事项、喜好、回忆；改资料；删除 |
| 7 | 备份与导出 | 手动备份、导出 JSON、查看备份、从备份恢复 |
| 8 | 使用帮助 | 在程序里快速查看命令和路径 |
| 0 | 退出 | 数据已经实时保存，直接关窗口也不会丢 |

> 每次在菜单 6 里修改，程序都会先自动备份，再写入文件。
> 备份最多保留 30 个，旧的会自动清理。

## 四、第一次改成你们自己的故事

打开程序，进入 **6 → 5 修改基本资料**，依次改：

- 你的称呼
- 对方的称呼
- 在一起的起点（例如 `2023-05-20 20:13`）
- 对方生日（`10-16` 这种格式）
- 你的生日（可空）

然后按自己的情况添加：

- **6 → 1** 添加纪念日（每年重复，日期写 `05-20`）
- **6 → 2** 添加重要事项（只提醒一次，日期写 `2026-11-03`）
- **6 → 3** 添加喜好 / 雷区 / 送礼参考
- **6 → 4** 添加一条回忆（以后能直接搜到）

示例数据里的名字、日期、故事都只是占位。**不改也能运行，但改成自己的才有意义。**

## 五、直接编辑数据文件

除了菜单，也可以用记事本、VS Code、Typora 打开 `data/memory.json`。
它就是一个普通的 JSON 文件，结构如下（只截取关键部分）：

```json
{
  "couple": {
    "me": "阿星",
    "partner": "小满",
    "start": "2023-05-20T20:13:00",
    "partner_birthday": "10-16",
    "my_birthday": "",
    "city": "我们住的城市"
  },
  "anniversaries": [
    {
      "title": "在一起纪念日",
      "date": "05-20",
      "count_from": "2023-05-20",
      "note": "20:13，那句「那就在一起吧」。"
    }
  ],
  "important": [
    {
      "title": "小满体检复查",
      "date": "2026-11-03",
      "note": "上午，记得空腹。"
    }
  ],
  "preferences": {
    "小满": {
      "喜欢": ["海鲜面", "热咖啡（不加糖）"],
      "不喜欢": ["太吵的餐厅"],
      "送礼": ["手写信"],
      "在意": ["累的时候先问要不要帮忙"]
    }
  },
  "memories": [
    {
      "date": "2023-07-16",
      "title": "第一次看海",
      "detail": "照片几乎全糊了，海边那家海鲜面没排上。",
      "tags": ["旅行", "海边"]
    }
  ]
}
```

### 修改时只要记住四条

1. **双引号必须成对**，中文引号不能代替英文引号。
2. **每两项之间要有逗号**，但最后一项后面不能多一个逗号。
3. 日期格式：
   - 每年重复：`"05-20"`
   - 一次性：`"2026-11-03"`
   - 在一起的起点：`"2023-05-20T20:13:00"`
4. 改完先存一份副本。程序发现 JSON 坏了，会把坏文件改名成 `memory.broken-时间.json`，然后用示例数据重建；不会让坏文件直接消失，但你的修改需要从坏文件里手工找回。

> 如果你不确定有没有改对，重新打开程序，进入 **6 → 7 查看数据摘要**。能正常显示，就说明 JSON 结构没问题。

## 六、问答能问什么

它不是大模型，不会编造没有记录的事。它只做两件事：**认意图 + 关键词搜索**。

可以问：

- 我们在一起多久 / 第几天 / 几年了
- 小满生日 / 我的生日
- 小满喜欢什么 / 小满不喜欢什么 / 送小满什么礼物
- 小满在意什么
- 第一次看海 / 雪 / 吵架 / 生日
- 最近有什么重要的事
- 今天是什么日子
- 你叫什么 / 你是谁

问不到时，它会提示你换一种说法，或者去菜单 6 添加。**搜不到不代表没记录，换个更接近标题的词通常就能找到。**

## 七、情话怎么生成，怎么改

进入 **3**，选择场景，然后可以输入一句「今天的小事」。
这句话会被织进其中一条情话里，例如：

```
今天的小事：她今天加班到十点

1. 今天的小事：她今天加班到十点。我记着呢，早上先提醒你一句，别忘。
2. 今天不祝你顺利，祝你遇到麻烦的时候，刚好有人帮你。
3. 小满，如果今天有点难，就把难的部分留一点给我。
```

### 改模板（不需要懂代码）

用记事本打开 `love_assistant.py`，搜索 `SCENE_TEMPLATES`，会看到四组中文句子：

```python
SCENE_TEMPLATES = {
    "morning": [
        "早上好，{partner}。...",
        ...
    ],
    "night": [...],
    "apology": [...],
    "comfort": [...],
}
```

- 直接改引号里的中文即可。
- `{partner}` 会自动替换成对方的称呼，`{me}` 替换成你的称呼。
- 带 `{note}` 的句子只在你输入「今天的小事」时才会出现。
- 每个场景至少保留两条**不带** `{note}` 的句子，否则不输入小事时没有内容可用。
- 改完保存，重新启动程序即可，不需要安装任何东西。

## 八、约会方案怎么来的

程序内置了 18 个方案，从 0 元散步到 700 元主题乐园，覆盖：

- 室内 / 室外 / 都行
- 30 分钟到 8 小时
- 宅家、城市、自然、体验、大餐

输入预算、时间和偏好后，它会：

1. 过滤掉超出预算、超出时间、不符合室内外的方案；
2. 按「预算用掉约 65%、时间用掉约 75%」打分；
3. 尽量选不同类别的 3 个方案；
4. 给出可执行的时间线、出发前准备和一个不花钱的惊喜。

### 改方案

搜索 `DATE_PLANS`，每个方案长这样：

```python
{
    "id": "noodle-home",
    "title": "在家煮一锅番茄面",
    "cost": 50,
    "minutes": 150,
    "place": "室内",
    "category": "宅家",
    "tags": ["在家", "做饭", "低预算"],
    "summary": "买菜、煮面、把手机放到一边。",
    "flow": [
        (0, "一起去楼下买菜，顺便走一圈"),
        (30, "回家洗菜，放一首你们都喜欢的歌"),
    ],
    "prep": ["提前问一句：今天想不想出门"],
    "surprise": "在碗底压一张便签。",
}
```

- `cost` 是两个人一共的大致花费；`minutes` 是总时长。
- `flow` 括号里的数字是「从开始算起第几分钟」。
- `place` 只能写 `"室内"`、`"室外"`、`"都行"`。
- `category` 用来避免推荐重样，可以自己起名。
- 复制一整段、改文字和数字，就能加自己的方案。注意逗号和括号不要丢。

## 九、备份、导出与恢复

### 自动备份

每次通过菜单修改并保存时，程序会把旧版本复制到 `data/backups/`，文件名带时间。
最多保留 30 个。

### 手动备份

主菜单 **7 → 1**，或命令行：

```bash
python love_assistant.py --backup
```

### 导出

主菜单 **7 → 2**，或：

```bash
python love_assistant.py --export
```

导出文件在 `data/exports/`。它是明文，**发给别人前先想清楚**。

### 恢复

主菜单 **7 → 4**，选择要恢复的备份。
恢复前，程序会先把当前数据再备份一份，所以选错了还能回来。

### 搬家

把整个 `assistant` 文件夹复制走即可。
想保留记忆，至少要带走 `data/memory.json`；想保留历史，把 `data/backups/` 一起带走。

## 十、隐私与安全

- 所有数据只在 `data/memory.json`，不联网、不上传、不调用任何 API。
- 它是**明文**。任何能打开这个文件夹的人都能读到。
- 不要在里面记录身份证号、银行卡、密码、他人隐私、未经对方同意的内容。
- 想加一道锁：
  - 用 7-Zip / Bandizip 把整个文件夹压成加密压缩包；
  - 或把项目放进 BitLocker / VeraCrypt 加密盘；
  - 或在系统里给 Windows 账户设置密码和锁屏。
- 在公共电脑上使用后，至少删除 `data` 文件夹和 `out` 文件夹。
- 备份文件和导出文件同样是明文，复制到网盘/U 盘前要确认接收方。

## 十一、命令行参数速查

```text
--today                今日概览
--ask "问题"           直接问一个问题
--scene morning        生成早安（night / apology / comfort）
--note "今天的小事"     把小事织进情话
--count 3              生成几条（默认 3）
--plan                 安排约会
--budget 200           预算（元）
--hours 4              时间（小时）
--indoor / --outdoor   只要室内 / 只要室外
--start 14:00          约会开始时间
--upcoming 60          未来 60 天的重要日子
--seed 7               固定随机结果，方便复现
--save                 把本次输出保存到 out/
--backup               立即备份
--export               导出数据
--where                显示所有数据路径
```

## 十二、常见问题

### 1. 双击 BAT，窗口一闪就没了

说明 Python 没装好，或者没加入 PATH。

- 打开「命令提示符」，输入 `python --version`。
- 如果提示「不是内部或外部命令」，去 <https://www.python.org/downloads/> 重新安装。
- 安装第一页一定要勾选 **Add python.exe to PATH**。
- 装完关闭所有命令行窗口，再双击 BAT。

### 2. 输入 `python` 却打开了微软商店

这是 Windows 的「应用执行别名」占了位置。

- 打开「设置 → 应用 → 高级应用设置 → 应用执行别名」；
- 关闭 `python.exe` 和 `python3.exe` 的两个开关；
- 重新打开命令行，输入 `python --version` 确认。

### 3. 中文显示成乱码

- 推荐直接双击 `启动小助手.bat`，它会先把控制台切到 UTF-8。
- 如果手动运行，先执行 `chcp 65001`，再运行 `python love_assistant.py`。
- Windows 10/11 的「Windows Terminal」对中文支持更好。

### 4. 提示 `python` 不是内部或外部命令，但 `py` 可以用

把 BAT 里的 `python love_assistant.py` 换成 `py -3 love_assistant.py`。
现在的 BAT 已经会自动尝试 `py -3`。

### 5. 保存时提示文件被占用 / 只读

- 关掉正在打开 `memory.json` 的记事本、VS Code 或其他程序；
- 检查 `assistant` 文件夹是不是放在只读目录或同步盘里；
- 不要同时在两个窗口里运行并修改同一份数据。

### 6. 改完 JSON 后程序提示格式错误

看提示里的 `memory.broken-...json` 路径，用编辑器打开它，逐项检查：

- 双引号是不是英文的 `"`；
- 最后一项后面是不是多了逗号；
- 大括号、中括号是不是成对；
- 日期是不是写成了 `2026-11-03` 这种格式。

### 7. 日期算出来不对

- 「在一起的起点」必须包含年月日；时间可写可不写，建议写 `2023-05-20 20:13`。
- 电脑系统时间不对，天数也会不对。先检查右下角日期。
- 2 月 29 日的纪念日，在非闰年会按 2 月 28 日提醒。

### 8. 我删了 data 文件夹，还能恢复吗

如果有备份或导出文件，把它们放回 `data/`，再运行 `--where` 确认路径。
如果没有，程序会重新生成一份示例数据，但原来的内容找不回来。

### 9. 能不能发给对方

能，但先想清楚：

- `data/memory.json` 里可能有你不想让对方看到的记录；
- 想只发程序，可以删除 `data/` 和 `out/`，让对方第一次运行时生成示例数据；
- 想连同记忆一起发，先通读一遍，删掉不该分享的部分。

### 10. 能不能不用命令行

可以。双击 BAT 后就是菜单，按数字选择即可。
所有功能都有菜单入口，命令行只是给习惯键盘的人准备的快捷方式。
