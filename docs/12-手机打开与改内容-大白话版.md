# 手机打开与改内容：大白话版

先说结论：

**HTML 不是手机 App，不用安装。它更像一张“网页”，用浏览器打开就行。**

手机上打不开，通常不是手机的问题，而是少了两个东西之一：

1. 少一个**网址**（文件还躺在电脑里）；
2. 少配套的**文件夹**（只发了 `index.html`，图片、样式、脚本都没跟过去）。

下面把“怎么在手机上看”和“怎么改内容”用最直白的话讲一遍。
不需要懂编程，照着做就行。

---

## 一、先选一种打开方式

| 你的情况 | 用哪种 | 难度 | 对方在外地能看吗 |
| --- | --- | --- | --- |
| 想现在就把东西发到手机上 | 发「手机版」单文件 | 最简单 | 能（文件发出去了就行） |
| 手机和电脑在同一个 Wi-Fi，只想自己看看 | 同一 Wi-Fi 预览 | 简单 | 不能 |
| 想发给她一个网址，点开就能看 | 公网链接 | 中等 | 能 |
| 想完全不联网，放 U 盘或发文件 | 离线博物馆单文件版 | 简单 | 能，但手机打开方式有限制 |

**最重要的一句话：平时改内容用的主页由 `index.html` + `css/` + `js/` + `assets/` 组成。**
只把 `index.html` 一个文件发过去，打开会没有样式、没有照片——这就是大多数
"手机上打不开" 的真正原因。想发文件，请发下面「方法 0」里的单文件版。

---

## 二、方法 0：直接把「手机版」文件发过去（最快）

项目里已经生成了一个**自带全部照片、样式、脚本、音乐**的单文件主页：

```text
手机版/恋爱主页-发手机打开这份.html
```

它大约 1.6 MB，这一个文件就是完整的主页，微信、QQ、网盘、U 盘随便发。
旁边还有一份 `手机版/怎么发到手机-必读.txt`，发文件时顺手一起发。

### 安卓手机

1. 微信/QQ 里点开这个文件 → 右上角「…」→ **用其他应用打开** → 选浏览器；
2. 看到粉色封面就成功了，往上滑就是全部内容。

如果微信里点开是乱码或空白：先「保存到手机」，再到「文件管理」里找到它，
长按 → 用浏览器打开（Chrome、Edge、系统浏览器都行）。

### iPhone

iPhone 自带的「文件」App 点开本地 HTML 只会显示静态画面、没有动画和照片
（苹果预览器的限制，不是文件坏了）。推荐任选一种：

- 装一个免费的 **Documents** App，把文件传进去点开，效果完整；
- 用下面的「同一 Wi-Fi 预览」或「公网链接」，用 Safari 直接看，体验最完整。

### 改了内容之后，这份文件要重新生成

在项目根目录运行：

```bash
node tools/build-phone-single.js
```

它会把最新的 `index.html`、样式、脚本、照片、音乐重新打包进「手机版」文件夹。

## 三、方法 1：同一个 Wi-Fi 下，用手机预览

适合：你们坐在一起，或者你自己想用手机看看效果。

### Windows 步骤

1. 打开 `love-universe` 文件夹；
2. 双击根目录的 **`手机预览-Windows.bat`**；
   （它用的是 Windows 自带的 PowerShell，**不需要安装任何软件**）；
3. 会弹出一个黑色窗口，里面有一行：

   ```text
   手机浏览器打开：http://192.168.1.23:8765/
   ```

   你的数字可能不一样，以窗口里显示的为准；
4. 确认手机和电脑连的是**同一个 Wi-Fi**；
5. 打开手机浏览器（Safari、Chrome、Edge 都行），在地址栏手动输入那一行；
6. 看到封面就成功了。

第一次运行时，Windows 可能弹出“防火墙”提示。
请点 **“允许访问”**，否则手机打不开。

想停止：回到黑色窗口，按 `Ctrl + C`，或直接关掉窗口。

### 如果双击后一闪就没 / 报错

极少数电脑禁用了 PowerShell 脚本。两个办法任选：

- 安装 Python 后改用：`python tools/phone_preview.py`；
- 或直接用「方法 0」发单文件，不用开服务。

### 手机输入地址后打不开，按顺序检查

| 检查 | 怎么做 |
| --- | --- |
| 两台设备是不是同一个 Wi-Fi | 手机不要用流量，电脑不要插手机热点 |
| 黑窗口是不是还开着 | 关掉窗口，服务就停了，需要重新双击 |
| Windows 防火墙 | 第一次弹窗时点「允许访问」；没弹就检查防火墙 |
| 地址有没有输错 | 冒号、点、端口 `8765` 都要对，不要输成 `https` |
| 电脑 IP 变了 | 路由器重新分配 IP 后，重新看窗口里的新地址 |
| 手机开了 VPN / 代理 | 先关掉再试 |
| 公司或酒店 Wi-Fi | 可能禁止设备互访，换手机热点或回家再试 |

还是不行，就换一个端口再试：

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tools/phone_preview.ps1 -Port 9000
```

### Mac / Linux

在项目文件夹里打开终端，输入：

```bash
python3 -m http.server 8765 --bind 0.0.0.0
```

然后查电脑的局域网地址：

- Mac：`ipconfig getifaddr en0`
- Linux：`hostname -I`

手机浏览器打开 `http://电脑地址:8765/`。

## 四、方法 2：做一个公网链接，发给她

适合：她不在你身边，想让她用自己的手机点开。

原理很简单：把整个 `love-universe` 文件夹放到一个公开网站上，网站会给你一个网址。
她点网址，就像打开普通网页一样。

三种常见做法：

| 方式 | 适合 | 特点 |
| --- | --- | --- |
| Cloudflare Tunnel | 临时给她看 | 电脑要开着，关掉链接就失效 |
| GitHub Pages | 长期放着 | 免费、稳定，需要注册 GitHub |
| Vercel | 想以后换域名 | 免费额度够个人用，操作也不难 |

完整步骤在 [公网部署教程](02-公网部署教程.md)，这里只说你最容易卡住的几点：

1. **上传的是整个文件夹，不是单个 `index.html`**；
2. 至少要包含 `index.html`、`css/`、`js/`、`assets/`；
3. 部署成功后，你会得到一个 `https://` 开头的网址；
4. 把这个网址发到微信里；
5. 她在微信里点开后，如果排版不对，点右上角 **“…” → 在浏览器打开**。

### 加到手机桌面，看起来就像 App

- **iPhone**：用 Safari 打开网址 → 点底部“分享” → “添加到主屏幕”；
- **安卓**：用 Chrome 打开网址 → 右上角三个点 → “添加到主屏幕”。

它本质上还是一个网页，但图标会留在桌面上，点开很方便。

### 必须提醒你

公网链接是**公开的**。
拿到链接的人都能看，页面里的密码只是“防手滑”，不是真正的加密。

所以：

- 不要放身份证、住址、公司、学校；
- 不要放太私密的照片；
- 想真正保密，用 U 盘或单文件版，不要放公网。

## 五、方法 3：离线单文件版

适合：U 盘、网盘、邮件，或者完全不想联网。

项目里已经有一个把所有照片、音乐、文字都塞进一个文件的版本：

```text
offline/单文件版/恋爱纪念博物馆-单文件版.html
```

它大约 3 MB，可以像普通文件一样发送。

### 手机上怎么打开

- **安卓**：用文件管理器找到这个 HTML → “打开方式” → 选择 Chrome / Edge；
- **iPhone**：iPhone 的“文件”App 对本地 HTML 支持不稳定，建议用带浏览器功能的文件 App（例如 Documents），或者干脆用公网链接。

微信里直接点开 HTML，有时只会显示代码，或者不运行脚本。
所以尽量用**系统浏览器**打开，不要用微信内置浏览器。

注意区分两个单文件版：

- `手机版/恋爱主页-发手机打开这份.html` ← **恋爱主页**的单文件版（见「方法 0」）；
- `offline/单文件版/恋爱纪念博物馆-单文件版.html` ← **离线博物馆**的单文件版（本节）。

另外，平时改内容用的主页是 `index.html` + `css/` + `js/` + `assets/` 的组合，
**不要只把 `index.html` 单独发出去**，那会没样式、没照片。想发文件就发上面的单文件版。

## 六、怎么改内容：先记住三句话

**先试试最简单的方法：打开网页，点右上角的 ⚙。**
名字、日期、照片标题、时间线、默契题、信和密码，全部能在设置面板里改，
改完点「保存并应用」就生效——下面的内容是给想直接改代码的人看的。

1. **只改引号里的字，不要改引号、逗号、括号。**
2. **一次只改一小处，保存后刷新看看。**
3. **动手前先复制一份备份。**

改文件推荐用：

- 电脑自带的**记事本**（改一两句够用）；
- 或者免费的 **VS Code**（有颜色、有行号，更不容易改错）。

**不要用 Word、WPS。**
它们会把英文引号自动变成中文引号，网页会直接坏掉。

## 七、主页最常改的地方

最快的方法是打开网页，点右上角 **⚙ 设置**。
下面这份是「想直接改代码」时用的对照表。

打开：

```text
js/main.js
```

第 11 行左右，有一大段 `CONFIG`。
你只需要改这里面引号中的内容，其他代码不用动。

```js
const CONFIG = {
  names: { me: "阿星", partner: "小满" },
  startDate: "2023-05-20T20:13:00",
  anniversary: { month: 5, day: 20 },
  birthday: {
    monthDay: "10-16",
    title: "生日快乐，我最喜欢的人",
    message: "今天世界又多爱你了一年。"
  },
  secretPassword: "0520",
  unlockMode: "password",
  defaultTheme: "rose",
  coverQuote: "日子是普通的，和你在一起的那部分，闪闪发光。",
  // 下面还有照片、时间线、情话、题目、信
};
```

### 对照表

| 你想改 | 找这一项 | 怎么改 |
| --- | --- | --- |
| 你的名字 | `names.me` | 把 `阿星` 换成你的名字 |
| 她的名字 | `names.partner` | 把 `小满` 换成她的名字 |
| 在一起的日期 | `startDate` | 按 `年-月-日T时:分:秒` 写 |
| 纪念日 | `anniversary` | 改 `month` 和 `day` |
| 她的生日 | `birthday.monthDay` | 例如 `10-16` |
| 生日弹窗文字 | `birthday.title` / `message` | 改引号里的句子 |
| 隐藏信的密码 | `secretPassword` | 例如 `0520`；也可以在 ⚙ → 信里改 |
| 信的解锁方式 | `unlockMode` | `password` 密码解锁 / `quiz` 答对默契题解锁 |
| 默认颜色 | `defaultTheme` | `rose` 粉 / `night` 蓝 / `retro` 棕 |
| 封面那句话 | `coverQuote` | 改引号里的句子 |

日期一定要写成这种格式：

```text
2023-05-20T20:13:00
```

意思是：2023 年 5 月 20 日 20 点 13 分 00 秒。
中间的 `T` 不能少，也不能换成空格。

改完保存，回到浏览器按 **`Ctrl + F5`** 强制刷新。
手机上看的话，下拉刷新，或者关掉页面重新打开。

## 八、怎么换照片

现在有两种方法，先选你会的那种。

### 方法 A：直接拖进去 / 点按钮上传（最快，不用改代码）

1. 用 `手机预览-Windows.bat`、公网链接或手机版单文件打开网页；
2. 找到想换的相框；
3. 电脑上：从文件夹里把照片**拖到相框上**，看到虚线提示后松手；
4. 手机上：点相框右上角的 **`↻`**，会打开相册/文件选择；
5. 也可以点开大图，左上角有 **换一张 / 还原默认**；
6. 封面下方有 **换这张封面 / 还原默认**；
7. 页脚密码信解锁后，可以点 **上传视频**，也可以直接把 mp4 拖到那块区域。

这个方式适合快速试照片。

如果是在微信/QQ 里点按钮没反应，不是照片坏了，是微信内置浏览器经常限制本地文件选择。
请点右上角 **「…」→「在浏览器打开」**，再试一次。

但它有一个必须知道的限制：

> **拖进去的照片只保存在当前这台设备、当前这个浏览器里。**
> 换手机、换电脑、清浏览器数据，或者发给别人的单文件版，都不会自动带上。
> 页面上会显示「本机已换」，就是在提醒你这件事。

想让对方永久看到，还是用下面的方法 B。

### 方法 B：放进文件夹（永久生效，推荐最终这样做）

#### 最简单的试法：先换一张

1. 准备一张照片，横图最好，宽度 1600 像素左右；
2. 把文件大小压到 500KB 以内，手机打开更快；
3. 把照片放进 `assets/photos/`；
4. 打开 `js/main.js`，找到：

   ```js
   photos: [
     { src: "assets/photos/p01.svg", title: "第一次一起看海", date: "2023.07.16", alt: "我们在海边的合照" },
   ```

5. 把 `p01.svg` 改成你的文件名，例如 `p01.jpg`；
6. 顺便改 `title`（标题）、`date`（日期）、`alt`（图片说明）；
7. 保存，刷新。

确认一张能正常显示后，再换剩下的。

### 两种方法怎么选

| 你现在想做什么 | 用哪种 |
| --- | --- |
| 自己电脑上快速试一张 | 拖拽 |
| 想让手机上的她也看到 | 公网链接 + 拖拽（同一浏览器）或方法 B |
| 想长期保存、发给别人 | 方法 B |
| 想生成手机版单文件 | 方法 B，然后重新生成 |
| 不想碰代码 | 先拖拽预览，确认效果后再让 AI 或朋友帮你替换文件 |

### 照片墙最多 120 张，默认 100 张

你可以：

- 少放几张：删掉整行 `{ ... },`；
- 多放几张：照着格式复制一行，改内容；
- 不想碰代码：在 ⚙ → 照片里加格子、删格子、改标题、日期和分类；
- 页面上方可以按「吃喝 / 日常 / 出行 / 节日 / 重要时刻 / 小心动」筛选。

### 封面三张图

找 `coverSlides`，改里面的 `src`。
封面建议用你们最喜欢的合照。

### 换完不显示，先检查这 3 件事

1. 文件名和扩展名是否一致（`.jpg` 就是 `.jpg`，不是 `.jpeg`）；
2. 路径是不是 `assets/photos/你的文件名`；
3. 这一行末尾有没有英文逗号 `,`。

## 九、怎么改时间线、情话、题目和信

这些都在 `js/main.js` 的 `CONFIG` 里，往下找就能看到。

### 时间线

```js
timeline: [
  { date: "2023-05-20", title: "在一起", text: "那天晚上 20:13。", icon: "♡" },
];
```

- `date`：日期；
- `title`：标题；
- `text`：那段话；
- `icon`：节点上的小图标，可以换成任何 emoji。

### 50 条情话

找 `quotes: [`。
每一条都是一对引号包起来的一句话，用逗号隔开：

```js
quotes: [
  "今天也很喜欢你。",
  "想和你一起吃饭。",
];
```

改句子就行。
最后一条后面可以没有逗号，但前面的每条都要有。

### 默契测试

默认有 10 道题，但**不预设正确答案**。
有两种玩法：

- **两人默契模式**：一个人先答，另一个人再答，最后看你们有多少选择一样；
- **标准答案模式**：由你们在 ⚙ → 默契题里给每题选一个正确答案，再让别人来测。

代码里对应的是 `quiz`。`answer: -1` 表示没有标准答案；
如果要设置答案，把 `answer` 改成选项编号，编号从 0 开始。

### 页脚那封信

找 `letter: {`。
里面有标题、段落、落款。
段落通常是一个数组，每段一行：

```js
paragraphs: [
  "第一段。",
  "第二段。",
],
```

改引号里的字即可。

### 恋爱清单

页面里新增了「想和你一起完成的 100 件小事」。
这个不用改代码：

- 点圆圈 = 完成；
- 输入框 = 新增；
- 悬停 × = 删除；
- 顶部进度 = 自动统计。

清单只保存在当前设备浏览器里，也可以用 ⚙ → 备份导出带走。

## 十、怎么改博物馆

打开：

```text
offline/museum.js
```

最上面是 `MUSEUM` 配置。

- 照片放进 `offline/media/photos/`；
- 视频放进 `offline/media/videos/`；
- 语音放进 `offline/media/voice/`；
- 文档放进 `offline/media/memoirs/`；
- 然后改 `MUSEUM` 里对应的文件名、标题、日期。

### 改了之后，单文件版要重新生成

如果你发给对方的是：

```text
offline/单文件版/恋爱纪念博物馆-单文件版.html
```

那它是“旧照片的快照”。
你改了文件夹版之后，要重新运行：

```bash
node tools/build-single-file.js
```

否则单文件版还是旧内容。

不会用命令行也没关系：
改文件夹版，直接双击 `offline/离线博物馆.html` 就能看到新内容。
单文件版可以等你熟悉了再重新生成。

## 十、5 备份怎么导出、怎么导入、怎么自动回滚

### 自动本地快照

现在不用你每次手动备份。系统会在这些动作前自动留一份快照：

- 保存设置前；
- 导入备份前；
- 恢复出厂默认前；
- 恢复某个快照前；
- 你在 ⚙ → 备份里点「立即备份一次」。

打开 ⚙ → 备份，能看到快照历史。点「恢复」就能回到刚才那一版。

普通更新版本不会清掉这些快照。真正会丢数据的通常是：

- 清除浏览器数据；
- 卸载重装 App；
- 换手机；
- 换浏览器；
- 无痕模式。

所以快照很有用，但它仍然保存在这台设备上。换设备还是要导出备份文件，或复制备份文本。

### 导出

1. 打开网页，点右上角 ⚙；
2. 进入「备份」页签；
3. 点 **⬇ 导出备份**；
4. 浏览器会下载一个 `恋爱纪念宇宙-备份-日期.json`。

如果手机浏览器没有自动下载，页面上会显示「点这里手动下载备份」。

### 导入

1. 先拿到别人导出的 `.json` 文件；
2. 打开网页，点右上角 ⚙ → 备份；
3. 点 **⬆ 选择备份文件导入**，选中那个 json；
4. 也可以把 json 直接拖到「把备份 JSON 直接拖到这里」的区域；
5. 导入成功后页面会刷新。

### 导入没反应，通常是什么问题

- **微信/QQ 内置浏览器**可能不让选文件：把网页用系统浏览器打开；
- 文件被聊天软件改名或损坏：重新导出一个 json；
- 浏览器空间不足或无痕模式：换普通模式，或删掉部分上传照片再导出；
- 导入的是别人的备份：会覆盖当前设置，但不会删除对方设备上的数据。

assistant/启动小助手.bat

## 十二、新手最容易踩的 9 个坑

| 坑 | 后果 | 怎么避免 |
| --- | --- | --- |
| 把英文引号改成中文引号 | 整个脚本报错，页面不动 | 只用记事本/VS Code，不用 Word |
| 删了行尾逗号 | 照片墙或时间线少一块 | 每行末尾保留英文 `,` |
| 括号删多了 | 页面空白 | 只改引号里的字，不动括号 |
| 图片路径写错 | 照片显示不出来 | 对照 `assets/photos/文件名` |
| 扩展名大小写不一致 | 电脑能看，手机不能看 | `.JPG` 改成 `.jpg` |
| 以为拖拽上传会永久保存 | 换设备或清浏览器数据后消失 | 最终照片放进 `assets/photos/` |
| 只改单文件版 | 重新生成后被覆盖 | 改源文件，再重新生成 |
| 改完没刷新 | 以为没生效 | `Ctrl + F5` 强制刷新 |
| 只发 `index.html` | 没样式、没照片 | 发链接，或发整个文件夹 |

## 十三、改坏了怎么办

### 最简单的办法：用备份覆盖

动手前，把整个 `love-universe` 文件夹复制一份，改名成：

```text
love-universe-备份
```

改坏了，就把备份里的 `js/main.js` 或整份文件夹复制回来。

### 页面白屏，怎么找原因

1. 在电脑浏览器按 `F12`；
2. 点 **Console（控制台）**；
3. 看红色报错；
4. 最常见的是：
   - 少了一个逗号；
   - 少了一个引号；
   - 中文引号；
   - 括号不配对。

把红色报错截图，通常一眼就能定位。

## 十四、给你一个 10 分钟动手顺序

1. 复制一份备份；
2. 打开 `js/main.js`；
3. 改你们的名字；
4. 改在一起的时间；
5. 改她的生日；
6. 改密码；
7. 改封面情话；
8. 保存，双击 `index.html`，按 `Ctrl + F5`；
9. 换第一张照片，确认能显示；
10. 用 `手机预览-Windows.bat` 或公网链接，在手机上看一眼。

做完这 10 步，它就已经是“你们的”了。
剩下的时间线、情话、信，可以慢慢改。

## 最后，一句话选择建议

- **想现在就发到手机**：发 `手机版/恋爱主页-发手机打开这份.html` 这一个文件；
- **只想自己用手机看**：双击 `手机预览-Windows.bat`，同一个 Wi-Fi 打开；
- **想发给她一个网址**：做公网链接，发网址；
- **想保存几十年**：用 U 盘里的离线博物馆；
- **想改内容**：先只改 `js/main.js` 最上面的 `CONFIG`，别碰其他代码；
  改完记得重新生成手机版（`node tools/build-phone-single.js`）。
