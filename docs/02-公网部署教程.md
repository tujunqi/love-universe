# 公网部署教程：把纪念宇宙变成一个链接

这一篇讲三件事：

1. 用 **Cloudflare Tunnel** 在自己电脑上把网站发布到公网，得到一个可以发给对方的链接；
2. 用 **GitHub Pages** 免费托管，电脑关机也能访问；
3. 用 **Vercel** 部署，适合以后想换域名、加访问密码的人。

三种方式选一种就够。第一次做，推荐先用 Cloudflare Tunnel 的“临时隧道”试水，十分钟能看到公网链接；想长期稳定，再选 GitHub Pages 或 Vercel。

---

## 0. 先确认你要发布的是什么

发布的是整个 `love-universe` 文件夹，不是单个 `index.html`。

必须一起上传的内容：

```text
love-universe/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  └─ main.js
└─ assets/
   ├─ photos/
   ├─ music/
   └─ video/
```

`docs/`、`brain/`、`assistant/`、`offline/`、`tools/` 不是主页运行必需的，可以不上传。上传了也不会影响主页，但会暴露你的教程和模板，建议只传主页三件套加 `assets`。

### 发布前必须知道的隐私问题

- 公网链接意味着**任何拿到链接的人都能看到照片和信**；
- 页面里的密码只是“防手滑”，不是真正的访问控制，查看源代码就能绕过；
- 搜索引擎可能会收录公开页面；
- 不要把身份证、住址、聊天记录、他人隐私照片放上去；
- 分手、争吵等敏感内容，建议只放在本地或 U 盘版本。

如果照片比较私密，优先用「Cloudflare Access」或「Vercel 密码保护」这类真正的访问控制，具体见本文最后一节。

### 建议先加一行“不要收录”

打开 `index.html`，在 `<head>` 里加：

```html
<meta name="robots" content="noindex, nofollow">
```

这不能阻止别人访问，但能减少被搜索引擎收录的概率。更彻底的做法是在网站根目录放一个 `robots.txt`：

```text
User-agent: *
Disallow: /
```

## 一、Cloudflare Tunnel：电脑当服务器，十分钟出链接

### 1.1 它是什么

Cloudflare Tunnel 会在你的电脑和 Cloudflare 之间建立一条加密隧道。别人访问 `https://xxx.trycloudflare.com` 时，请求会转发到你电脑上的 `http://localhost:8765`。

优点：

- 不用买服务器、不用备案；
- 自动 HTTPS；
- 可以绑定自己的域名；
- 适合临时展示、给对象一个惊喜。

缺点：

- **电脑必须开着，网页服务必须开着**；
- 电脑睡眠、断网、关机，链接就打不开；
- 临时隧道的网址每次重启都会变；
- 免费版不保证 SLA，不适合长期正式使用。

### 1.2 第一步：先把网站在本机跑起来

Cloudflare Tunnel 转发的是“本机的一个网址”，所以先让网站跑在本机。

#### 方法 A：用 Python 自带的小服务器（推荐，Windows 自带或官网安装）

1. 打开 `love-universe` 文件夹；
2. 在文件夹空白处按住 `Shift` + 右键，选择“在此处打开 PowerShell 窗口”或“在终端中打开”；
3. 输入：

```powershell
python -m http.server 8765
```

看到类似输出就成功了：

```text
Serving HTTP on 0.0.0.0 port 8765 (http://0.0.0.0:8765/) ...
```

4. 浏览器打开 `http://localhost:8765`，能看到封面；
5. **这个窗口不要关**，关了网站就停了。

如果提示 `python 不是内部或外部命令`：

- 去 Python 官网下载安装包，安装时勾选 “Add Python to PATH”；
- 或者用 Node.js 的 `npx serve`：

```powershell
npx serve -l 8765
```

#### 方法 B：直接双击 index.html

能看，但 Cloudflare Tunnel 需要一个 HTTP 服务，不能直接转发 `file://`。所以发布时还是用方法 A。

#### 端口被占用怎么办

把 `8765` 换成 `8787`、`9000` 等，后面所有命令跟着改。

### 1.3 第二步：注册 Cloudflare 账号

1. 打开 <https://dash.cloudflare.com/sign-up>；
2. 用邮箱注册，验证邮箱；
3. 不绑定域名也能用临时隧道；
4. 想用固定域名，再把域名接入 Cloudflare（见 1.7）。

### 1.4 第三步：下载 cloudflared

1. 打开 Cloudflare 官方下载页：<https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>；
2. Windows 64 位选择 `cloudflared-windows-amd64.exe`；
3. 下载后改名为 `cloudflared.exe`；
4. 建议放到一个固定目录，例如：

```text
C:\Tools\cloudflared\cloudflared.exe
```

不要放在中文路径或桌面深层文件夹里，减少路径问题。

### 1.5 第四步：启动临时隧道

1. 打开 PowerShell；
2. 进入 `cloudflared.exe` 所在目录：

```powershell
cd C:\Tools\cloudflared
```

3. 执行：

```powershell
.\cloudflared.exe tunnel --url http://localhost:8765
```

4. 终端会输出一大段日志，找到类似这一行：

```text
https://random-words-1234.trycloudflare.com
```

5. 复制这个网址，用手机 4G/5G 打开测试。

第一次运行时 Windows 可能弹出防火墙提示，选择“允许访问”。

看到 `ERR_CONNECTION_REFUSED`，通常是：

- 本机网站没开；
- 端口写错；
- Python 服务绑定在 `127.0.0.1`，而隧道访问的是 `localhost`，一般没问题；如果仍失败，启动服务时用：

```powershell
python -m http.server 8765 --bind 0.0.0.0
```

临时隧道的网址**每次重启都会变**。适合今天发、今天看；不适合长期放在签名里。

关闭隧道：在终端按 `Ctrl + C`。

### 1.6 第五步：让链接更像“你们的”

临时网址是一串随机单词，不够浪漫。三种处理：

1. **用自己的域名**（推荐，见 1.7）；
2. 用短链服务把长网址缩短，但不要用会插广告、要求登录的陌生短链；
3. 直接发二维码，见《10-惊喜发送全攻略》。

### 1.7 固定域名：命名隧道（需要自己的域名）

命名隧道重启后地址不变，适合长期使用。

#### 1.7.1 把域名接入 Cloudflare

1. 在 Cloudflare 控制台点 “Add a site”；
2. 输入你的域名，例如 `example.com`；
3. 选择 Free 计划；
4. 按提示到域名注册商处，把 NS 记录改成 Cloudflare 给的两个地址；
5. 等待生效，通常几分钟到 24 小时。

没有域名？可以在 Cloudflare 或其他注册商买一个，常见 `.com`、`.cn`、`.love` 等。买之前确认续费价格。

#### 1.7.2 登录并创建隧道

在 PowerShell 里：

```powershell
cd C:\Tools\cloudflared
.\cloudflared.exe tunnel login
```

浏览器会打开授权页，选择你的域名，授权。

然后创建一条隧道，名字随意：

```powershell
.\cloudflared.exe tunnel create love-home
```

成功后会输出一个 UUID，例如：

```text
Created tunnel love-home with id 6ff42ae2-765d-4adf-8112-31c55c1551ef
```

记下这个 UUID。

#### 1.7.3 给隧道绑定域名

```powershell
.\cloudflared.exe tunnel route dns love-home love.example.com
```

把 `love.example.com` 换成你想用的子域名，例如 `our.example.com`、`days.example.com`。

这条命令会自动在 Cloudflare DNS 里加一条 CNAME。

#### 1.7.4 写配置文件

在 `C:\Users\你的用户名\.cloudflared\` 下新建 `config.yml`：

```yaml
tunnel: 6ff42ae2-765d-4adf-8112-31c55c1551ef
credentials-file: C:\Users\你的用户名\.cloudflared\6ff42ae2-765d-4adf-8112-31c55c1551ef.json

ingress:
  - hostname: love.example.com
    service: http://localhost:8765
  - service: http_status:404
```

注意：

- `tunnel` 后面是 UUID；
- `credentials-file` 是创建隧道时生成的 JSON 文件路径；
- YAML 用空格缩进，不要用 Tab；
- 冒号后面有一个空格；
- Windows 路径用反斜杠，或者用正斜杠 `C:/Users/...` 也可以。

#### 1.7.5 启动

```powershell
.\cloudflared.exe tunnel run love-home
```

浏览器打开 `https://love.example.com`，应该能看到封面。

#### 1.7.6 装成 Windows 服务（可选）

想开机自动运行，用管理员权限打开 PowerShell：

```powershell
cd C:\Tools\cloudflared
.\cloudflared.exe service install
```

然后启动服务：

```powershell
Start-Service cloudflared
```

查看状态：

```powershell
Get-Service cloudflared
```

卸载：

```powershell
.\cloudflared.exe service uninstall
```

注意：服务方式运行时，Python 的网页服务也要开机自启，否则隧道在、网站不在。可以把启动命令写成一个 `.bat`，放进“启动”文件夹。

#### 1.7.7 一个最小的开机启动脚本

新建 `启动纪念宇宙.bat`：

```bat
@echo off
cd /d "C:\Users\你的用户名\Desktop\love-universe"
start "love-universe" /min python -m http.server 8765 --bind 0.0.0.0
timeout /t 2 >nul
cd /d "C:\Tools\cloudflared"
start "cloudflared" /min cloudflared.exe tunnel run love-home
```

按 `Win + R`，输入：

```text
shell:startup
```

把 `启动纪念宇宙.bat` 的快捷方式放进打开的文件夹。下次登录会自动运行。

### 1.8 Cloudflare 常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `cloudflared` 不是命令 | 没进目录，或没加 PATH | 用 `.\cloudflared.exe` |
| 502 Bad Gateway | 本机网站没开或端口错 | 先打开 `http://localhost:8765` |
| 1033 错误 | 隧道没运行 | 重新 `tunnel run` |
| 链接打不开但本机能开 | 防火墙/安全软件拦截 | 允许 cloudflared 和 Python 通过防火墙 |
| 手机能开、电脑不能 | DNS 缓存 | 换网络或等几分钟 |
| 图片 404 | 路径大小写、文件没上传 | 检查 `assets/photos/` |
| 样式丢失 | `css/style.css` 路径错 | 保持目录结构 |
| 隧道频繁断 | 网络不稳/QUIC 被拦 | 加 `--protocol http2` 再试 |
| 网址每次变 | 用的是临时隧道 | 改用命名隧道 |
| 中文文件名 404 | URL 编码问题 | 全部改成英文数字文件名 |

### 1.9 安全提醒

Cloudflare Tunnel 会把本机端口暴露到公网。不要用它转发路由器管理页、数据库、NAS 后台等敏感服务。只转发这个静态网站。

如果只是给对象看，建议：

- 用不明显的子域名，例如 `m.example.com`；
- 加 `noindex`；
- 不要把链接发到公开群；
- 看完后按 `Ctrl + C` 关掉隧道。

## 二、GitHub Pages：免费、稳定、电脑关机也能看

### 2.1 适合谁

- 想长期保存一个链接；
- 电脑经常关机；
- 不介意网址是 `用户名.github.io/仓库名`；
- 能接受公开仓库（免费版）。

### 2.2 注册 GitHub

1. 打开 <https://github.com>；
2. 注册账号，验证邮箱；
3. 建议开启两步验证。

### 2.3 新建仓库

1. 右上角 `+` → `New repository`；
2. 仓库名建议：`love-universe`；
3. 选择 `Public`（免费 Pages 需要公开仓库）；
4. 勾选 `Add a README file`；
5. 点 `Create repository`。

### 2.4 上传文件

最简单的方法：网页上传。

1. 进入仓库，点 `Add file` → `Upload files`；
2. 把 `index.html`、`css` 文件夹、`js` 文件夹、`assets` 文件夹拖进去；
3. 注意保持目录结构，不要把所有文件平铺在根目录；
4. 底部写一句提交说明，点 `Commit changes`。

网页上传的限制：

- 单个文件建议小于 25MB；
- 视频如果超过 25MB，网页上传会失败；
- 大视频建议放 B 站/YouTube 私享链接，或者用 Git LFS，或者不放。

也可以命令行上传：

```bash
cd love-universe
git init
git add index.html css js assets
git commit -m "our love universe"
git branch -M main
git remote add origin https://github.com/你的用户名/love-universe.git
git push -u origin main
```

第一次 push 会要求登录，按提示用浏览器授权。

### 2.5 开启 Pages

1. 进入仓库 → `Settings`；
2. 左侧 `Pages`；
3. `Build and deployment` → `Source` 选 `Deploy from a branch`；
4. `Branch` 选 `main`，目录选 `/ (root)`；
5. 点 `Save`；
6. 等 1 到 3 分钟，页面顶部会出现网址：

```text
https://你的用户名.github.io/love-universe/
```

7. 用手机流量打开测试。

如果 404：

- 等几分钟，首次部署慢；
- 确认 `index.html` 在仓库根目录，不是套了一层文件夹；
- 确认分支是 `main`；
- 确认 Pages 设置里显示 “Your site is live”。

### 2.6 更新内容

网页上传会覆盖同名文件。改完 `main.js` 后：

1. 进入仓库；
2. 找到 `js/main.js`；
3. 点铅笔图标编辑，或重新上传；
4. 提交后等 1 到 2 分钟；
5. 手机刷新时加 `?v=2` 绕过缓存。

### 2.7 自定义域名（可选）

1. 在仓库 `Settings` → `Pages` → `Custom domain` 填入域名；
2. 到域名服务商添加 CNAME 记录：

```text
类型：CNAME
主机记录：love（或 @）
记录值：你的用户名.github.io
```

3. 勾选 `Enforce HTTPS`（证书签发可能需要几小时）。

GitHub Pages 的自定义域名不支持裸域（`example.com`）直接 CNAME 到 GitHub 的旧方式，建议用 `www` 或子域名；裸域需要 A 记录，具体以 GitHub 文档为准。

### 2.8 GitHub Pages 的坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 404 | 文件不在根目录 / 分支错 | 检查目录和 Pages 设置 |
| 样式丢失 | 路径大小写不一致 | Linux 服务器区分大小写 |
| 图片不显示 | 文件名含中文/空格 | 改成英文数字 |
| 更新不生效 | CDN 缓存 | 等几分钟，加 `?v=2` |
| 视频无法播放 | 单文件过大或格式不支持 | 压缩成 MP4，或外链 |
| 私有仓库不能开 Pages | 免费版限制 | 改公开仓库，或用 Vercel |
| 仓库体积过大 | 照片没压缩 | 压到 1600px、单张 < 800KB |

## 三、Vercel：更快的部署和更像“作品”的网址

### 3.1 适合谁

- 想要更短的网址；
- 想以后加密码保护、访问统计；
- 已经有 GitHub 仓库，想一键导入；
- 不介意免费版有流量限制。

### 3.2 注册

1. 打开 <https://vercel.com>；
2. 用 GitHub 账号登录最方便；
3. 选择 Hobby（个人免费）计划。

### 3.3 导入项目

1. 点 `Add New` → `Project`；
2. 选择你的 GitHub 仓库 `love-universe`；
3. `Framework Preset` 选 `Other`；
4. `Root Directory` 保持默认；
5. `Build Command` 留空；
6. `Output Directory` 留空或填 `.`；
7. 点 `Deploy`。

等待几十秒，得到网址：

```text
https://love-universe-xxxx.vercel.app
```

### 3.4 不用 GitHub 的部署方式

安装 Node.js 后，在项目目录执行：

```bash
npx vercel
```

按提示登录、确认项目名，最后执行：

```bash
npx vercel --prod
```

得到正式网址。

### 3.5 自定义域名

1. 项目 → `Settings` → `Domains`；
2. 添加你的域名；
3. 按提示在域名服务商添加 A 记录或 CNAME；
4. 等待证书签发。

### 3.6 Vercel 的坑

- 免费版适合个人项目，不要放超大视频；
- 静态文件路径同样区分大小写；
- 每次 push 会自动重新部署；
- 国内访问速度不稳定，给国内对象看时建议同时准备 GitHub Pages 或 Cloudflare 方案；
- 免费版可以通过 `Deployment Protection` 加密码，但部分功能可能要求付费计划，以控制台实际显示为准。

## 四、真正的访问控制：别把密码当安全

前端密码（页面里的 `secretPassword`）只能防手滑。需要真正保护时，选一种：

### 4.1 Cloudflare Access（推荐，需域名接入 Cloudflare）

1. Cloudflare 控制台 → `Zero Trust`；
2. `Access` → `Applications` → `Add an application`；
3. 类型选 `Self-hosted`；
4. 域名填 `love.example.com`；
5. 新建策略：`Allow`，条件可以填对方的邮箱；
6. 保存后，访问者需要邮箱验证码才能进入。

免费版有一定用户数限制，具体以 Cloudflare 当前政策为准。

### 4.2 Vercel 密码保护

项目 → `Settings` → `Deployment Protection`，按控制台提示开启。不同计划功能不同。

### 4.3 最稳妥的方式

- 不发布到公网；
- 用 U 盘当面送出；
- 或者只在家庭局域网内访问。

## 五、发布后的检查清单

- [ ] 手机 4G/5G 能打开，不只 Wi-Fi；
- [ ] 封面图加载正常；
- [ ] 背景音乐按钮能播放；
- [ ] 照片墙里的照片都能点开；
- [ ] 密码信能解锁；
- [ ] 留言板能写入（只存在访问者自己的浏览器）；
- [ ] 三个主题都能切换；
- [ ] 没有横向滚动条；
- [ ] 控制台没有红色报错；
- [ ] 链接没有出现在搜索引擎里（`noindex` + `robots.txt`）；
- [ ] 发给对方前，用无痕窗口再走一遍。

## 六、链接的“惊喜包装”

技术发布只是第一步，怎么发同样重要。完整玩法见《10-惊喜发送全攻略》，这里先给三个不踩雷的原则：

1. **不要伪装成银行、快递、政务等真实机构**，这不叫浪漫，可能构成欺诈；
2. 可以低调，例如用 `our-days.com`、`m.example.com` 这种看不出内容但真实的域名；
3. 链接之前先给一句“铺垫”，让对方有心理准备，而不是在忙碌时突然点开。

一个可用的开场：

> 今天整理相册，发现我们已经攒了这么多普通的日子。
> 我做了个东西，想给你看。等你有十分钟，安静的时候再点。

然后把链接发过去。

## 七、三种方案怎么选

| 需求 | 推荐 |
| --- | --- |
