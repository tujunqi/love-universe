# 开机画面、自动运行与 U 盘封面

这一篇把“仪式感”做到开机那一刻。

先分清三个概念：

1. **电脑开机画面**：主板 UEFI/BIOS 的 logo，普通人改不了，也不建议改；
2. **进入系统后自动打开博物馆**：可以做到，但需要在那台电脑上做设置；
3. **博物馆自己的开馆画面**：完全由我们控制，换一张图、一句话就行。

大多数“浪漫开机”其实是第 3 种。它安全、可控、换电脑也能用。

---

## 一、博物馆自带的开馆画面

打开 `offline/离线博物馆.html`，第一眼看到的就是开馆封面。

### 1.1 它包含什么

- 全屏背景图；
- 馆名，例如“我们的私人博物馆”；
- 副标题：“仅接待两位观众”；
- 在一起的天数；
- 当天日期；
- “推门进入”按钮；
- 一行小字：“离线运行 · 不联网 · 不收集任何信息”。

点击进入后：

- 背景音乐淡入；
- 封面淡出；
- 进入序厅。

### 1.2 换成你们的照片

打开 `offline/museum.js`，找到最上面的 `MUSEUM` 配置：

```js
const MUSEUM = {
  names: { me: "阿星", partner: "小满" },
  startDate: "2023-05-20T20:13:00",

  cover: {
    image: "media/photos/cover-1.svg",
    kicker: "OUR PRIVATE MUSEUM",
    title: "我们的私人博物馆",
    subtitle: "仅接待两位观众",
    note: "请轻推门 · 馆内禁止赶时间",
    enter: "推门进入"
  },
  ...
};
```

改这几项：

| 字段 | 作用 |
| --- | --- |
| `image` | 封面背景图，建议横图 1600px 以上 |
| `kicker` | 顶部英文小字 |
| `title` | 馆名 |
| `subtitle` | 副标题 |
| `note` | 一句小字 |
| `enter` | 进入按钮文字 |

想更克制，可以把 `kicker` 改成日期，例如 `EST. 2023.05.20`。

### 1.3 改开馆音乐

```js
music: "media/audio/bgm.wav"
```

- 换成 `bgm.mp3`；
- 进入时才播放，符合浏览器规则；
- 右上角有音乐开关；
- 如果文件不存在，不报错，只是没有声音。

### 1.4 改开馆动画

`museum.css` 里搜索 `boot`：

- `.boot`：整层封面；
- `.boot.is-leaving`：点击进入后的淡出；
- `.boot-title`：馆名字号；
- `.boot-veil`：照片上的暗色遮罩。

不建议大改布局，改颜色和字号就够。开馆画面最重要的是“安静”，不是“热闹”。

## 二、全屏 / 展厅模式

当面送出时，全屏打开最像展览。

### 2.1 Edge 全屏

项目已经带了 `offline/全屏参观.bat`，双击即可。它会按顺序寻找 Chrome / Edge，找不到就退回默认浏览器：

```bat
@echo off
setlocal
cd /d "%~dp0"
set "PAGE="
for %%F in ("*.html") do if not defined PAGE set "PAGE=%%~fF"
set "BROWSER="
for %%B in (
  "%ProgramFiles%\Google\Chrome\Application\chrome.exe"
  "%ProgramFiles(x86)%\Google\Chrome\Application\chrome.exe"
  "%ProgramFiles%\Microsoft\Edge\Application\msedge.exe"
  "%ProgramFiles(x86)%\Microsoft\Edge\Application\msedge.exe"
) do if not defined BROWSER if exist "%%~B" set "BROWSER=%%~B"
start "" "%BROWSER%" --kiosk --autoplay-policy=no-user-gesture-required "file:///%PAGE:\=/%"
```

说明：

- `cd /d "%~dp0"` 切到脚本所在目录，U 盘盘符变了也不怕；
- `--kiosk` 全屏，没有地址栏；
- 退出按 `Alt + F4`；
- 没有浏览器时，会退回默认浏览器，不会卡住。

### 2.2 Chrome 全屏

```bat
@echo off
start "" chrome --kiosk "file:///%~dp0离线博物馆.html"
```

Chrome 的 `--kiosk` 会直接全屏。

### 2.3 应用窗口模式

不想全屏，但想没有地址栏：

```bat
@echo off
start "" msedge --app="file:///%~dp0离线博物馆.html" --window-size=1280,860
```

`--app` 会打开一个像独立软件一样的窗口，适合放在旧笔记本上。

### 2.4 macOS 全屏

```bash
open -a "Google Chrome" --args --kiosk "file:///Volumes/你的U盘/恋爱纪念博物馆/离线博物馆.html"
```

或者打开后按 `Control + Command + F`。

### 2.5 展厅模式的细节

- 提前把电脑音量调到 30% 左右；
- 关闭微信、邮件等通知；
- 关闭屏保和自动睡眠；
- 把浏览器缩放设为 100%；
- 用触控板/鼠标都可以，不要假设对方会按键盘；
- 在最后一页留一个“出口”，不要让全屏成为困住对方的牢笼。

## 三、插入 U 盘自动打开：可行方案

再次强调：**现代 Windows 默认不允许 U 盘 AutoRun 自动执行程序。** 这不是你设置错了，是系统安全策略。

下面按可靠性排序。

### 3.1 方案 A：`autorun.inf`（设置图标和卷标）

在 U 盘根目录放：

```ini
[AutoRun]
open=恋爱纪念博物馆\open-museum.bat
icon=恋爱纪念博物馆\museum.ico
label=我们的宇宙
```

它能做的：

- 设置 U 盘图标和卷标（部分系统有效）；
- 在 AutoPlay 开启的电脑上出现在“选择操作”里；
- 老系统可能自动运行。

它不能做的：

- 在现代 Windows 上保证自动执行；
- 在 macOS/Linux 上生效；
- 绕过杀毒软件。

**不要**为了自动运行去关闭杀毒软件、修改注册表或使用来源不明的“U 盘自动播放工具”。

### 3.2 方案 B：Windows 自动播放设置

在展示用的电脑上：

1. 打开“设置”；
2. 搜索“自动播放”；
3. 打开“使用自动播放”；
4. 选择“每次询问”；
5. 插入 U 盘；
6. 在弹出的窗口里选择“打开文件夹以查看文件”；
7. 双击 `01-双击我-进入博物馆.bat`。

这只能减少一步，不是真正自动。

### 3.3 方案 C：任务计划程序（插入指定 U 盘时打开）

适合自己家的固定电脑。思路：监听设备插入事件，条件匹配你的 U 盘，执行浏览器打开命令。

#### 步骤

1. 按 `Win + R`，输入 `taskschd.msc`，回车；
2. 右侧“创建任务”；
3. **常规**：
   - 名称：`打开我们的纪念博物馆`；
   - 勾选“使用最高权限运行”（如果打开失败再试）；
   - 配置：Windows 10。
4. **触发器** → 新建：
   - 开始任务：`事件`；
   - 日志：`Microsoft-Windows-Kernel-PnP/Configuration`；
   - 事件 ID：`400`（部分系统用 `410`）；
   - 勾选“延迟任务 5 秒”，避免 U 盘还没挂载。
5. **操作** → 新建：
   - 程序：`msedge.exe` 的完整路径，例如：

```text
C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
```

   - 参数：

```text
--app="file:///E:/恋爱纪念博物馆/离线博物馆.html"
```

6. **条件**：
   - 取消“只有在使用交流电源时才启动”；
   - 其他保持默认。
7. 保存，插入 U 盘测试。

#### 大坑

- **盘符会变**：这台电脑是 `E:`，另一台可能是 `F:`。可以把资料放在固定盘符（磁盘管理里改），或者用 `.bat` 自动找盘符。
- **事件 ID 因系统版本不同**：400/410 是常见值，但并非所有系统都触发。
- **需要管理员权限**：单位/学校电脑通常没有。
- **杀毒软件可能拦截**：任务计划启动浏览器一般没事，但 `.bat` 可能被误报。
- **UEFI 安全启动**：与此无关，不要混为一谈。

#### 更稳的替代：登录时打开

如果只是自己家的电脑，不一定要等 U 盘插入。可以把博物馆复制到本地硬盘，然后：

1. 任务计划程序 → 创建基本任务；
2. 触发器：`登录时`；
3. 操作：启动 `msedge.exe`，参数 `--kiosk "file:///C:/Museum/离线博物馆.html"`；
4. 延迟 10 秒，等系统稳定。

这比“U 盘插入事件”可靠得多。

### 3.4 方案 D：macOS

macOS 没有 Windows 式 AutoRun。可选：

- 在 U 盘根目录放 `打开我-Mac.command`，让对方双击；
- 用 Automator 的“文件夹操作”监听 `/Volumes`，插入时运行脚本；
- 用 LaunchAgent 登录时打开。

Automator 思路：

1. 打开 Automator → 新建“文件夹操作”；
2. 工作流程收到位于 `/Volumes` 的文件夹时；
3. 添加“运行 Shell 脚本”；
4. 脚本判断卷名，`open` 对应 HTML；
5. 保存为应用程序，放进登录项。

对大多数人，直接双击 `.command` 更省事。

### 3.5 方案 E：Linux

可以用 `udev` 规则监听 USB 插入，但不同发行版差异大，不建议普通用户折腾。更简单的是：

- 桌面快捷方式；
- 文件管理器里双击 HTML；
- 或者写一个 `open-museum.sh`，放在 U 盘根目录。

### 3.6 方案 F：物理提示（最可靠）

- U 盘上贴标签：`插入后双击「01-双击我」`；
- 附一张卡片，写三步；
- 文件名用数字开头，自动排在前面；
- 把 `.bat` 图标换成博物馆图标（需要改快捷方式，不是改 `.bat` 本身）。

## 四、U 盘图标与卷标

### 4.1 图标文件

`offline/museum.ico` 已经准备好，里面包含 16/32/48/64/256 五个尺寸。

想重新生成：

```bash
node tools/make-icon.js
```

它会用 `offline/media/photos/cover-1.svg` 合成一个带金边的方形图标。想换成你们的照片：

1. 选一张正方形照片；
2. 改 `tools/make-icon.js` 里的图片路径和 `object-position`；
3. 运行上面的命令；
4. 用新生成的 `offline/museum.ico` 覆盖旧文件；
5. 重新插拔 U 盘。

Windows 对图标有缓存。换了不生效时：

- 换一个 USB 口；
- 在“设备管理器”里卸载 U 盘再插；
- 或者改个文件名，让系统重新读取。

### 4.2 卷标

`autorun.inf`：

```ini
label=我们的宇宙
```

卷标建议：

- 不超过 8 个汉字；
- 不要用特殊符号 `\ / : * ? " < > |`；
- 不要用“新建卷”“U盘”这种默认名。

### 4.3 图标不显示的原因

- 系统禁用了自定义图标；
- `autorun.inf` 路径写错；
- `.ico` 不是真正的 ICO 格式（只是改了后缀）；
- U 盘是 NTFS 且权限异常；
- 企业电脑策略限制。

不显示也不影响使用，不必死磕。

## 五、U 盘封面设计与打印

### 5.1 尺寸

常见 U 盘：

- 长 5.5 到 6.5cm，宽 1.5 到 2cm；
- 名片尺寸 9cm × 5.4cm 适合做外包装卡；
- 圆形贴纸直径 3cm 到 4cm。

### 5.2 排版模板

```text
┌──────────────────────────────┐
│  OUR PRIVATE MUSEUM          │
│                              │
│      我们的私人博物馆          │
│                              │
│   2023.05.20 — ∞             │
│   仅接待两位观众               │
│                              │
│   插入后双击「01-双击我」       │
└──────────────────────────────┘
```

字体建议：

- 中文用宋体/思源宋体，英文用 Georgia；
- 主标题不要超过 18pt；
- 小字至少 7pt，打印出来才看得清；
- 深色底配米白字，或者米白底配深棕字。

### 5.3 材料

- 哑光不干胶：不反光，像展签；
- 牛皮纸：复古；
- 透明 PVC 卡套：耐磨损；
- 不要用普通打印纸直接贴，容易起边。

### 5.4 和实物的组合

- U 盘 + 一张开馆卡 + 一小束干花；
- U 盘 + 一本打印的回忆录；
- U 盘 + 两张电影票根；
- 装进一个小木盒，盒盖内侧贴开馆说明。

技术不是主角，**被认真对待的感觉**才是。

## 六、“开机画面”的替代方案

### 6.1 旧平板 / 旧笔记本做成展柜

- 找一台不用的旧设备；
- 把博物馆复制到本地；
- 设置开机自动全屏打开；
- 关闭通知和睡眠；
- 放在书桌上，像一个数字相框。

这比改 BIOS 安全，也比网页链接更有“实物感”。

### 6.2 电子相框

- 把精选照片导出成 JPG；
- 放进电子相框的 SD 卡；
- 博物馆 U 盘放在旁边，作为“完整版”。

电子相框不会打开 HTML，但它能让照片每天都在。

### 6.3 打印一本“展册”

- 从博物馆里选一批照片；
- 每张配一段文字；
- 用在线打印店做成骑马钉小册子；
- 最后一页印上二维码（链接到在线版）。

纸和数字互为备份。

### 6.4 关于修改 Windows 开机 logo

不建议。原因：

- 需要改 UEFI 固件，失败可能变砖；
- 不同主板方法不同；
- 系统更新可能还原；
- 与“纪念”无关，风险却很高。

如果真的很想要“开机即见”，用“登录时自动全屏打开”就够了。

## 七、测试清单

在送出前，至少测一遍：

- [ ] 双击 `.bat` 能打开；
- [ ] 全屏模式能进入、能退出；
- [ ] 点击“推门进入”音乐响起；
- [ ] 封面文字没有被裁切；
- [ ] U 盘图标显示（如果系统允许）；
- [ ] 拔掉网络后仍能打开；
- [ ] 换一台电脑仍能打开；
- [ ] 视频、语音能播放；
- [ ] 手机 OTG 能打开（可选）；
- [ ] 单文件版能独立打开；
- [ ] 说明书和密码提示放在显眼位置。

---

## 八、最后的建议

不要把“自动运行”当成成败标准。

真正会让人记住的，是：

- 插上 U 盘后，屏幕上出现你们的名字；
- 点开第一张照片时，音乐刚好响起；
- 翻到最后一页，看到一句只写给她/他的话；
- 以及你在旁边说：“不着急，慢慢看。”

技术会过时，这个下午不会。
