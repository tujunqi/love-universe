# 09 · Python 本地恋爱小助手：从零运行

> 这是一个跑在你自己电脑上的命令行小助手。
> 它记得住纪念日、生日、重要事项、喜好和零散回忆，能回答你的问题，能在四个场景里生成情话，还能根据预算和时间排出约会方案。
>
> 不联网、不调用任何 AI 接口、不需要安装第三方库。所有数据只写进一个文件：
> [`assistant/data/memory.json`](../assistant/data/memory.json)

这一篇写给**完全没装过 Python 的人**。照着做，大约 10 分钟能跑起来。
如果你已经会 Python，直接跳到「四、第一次运行」即可。

## 二、安装 Python（Windows 最详细版）

### 第 1 步：确认有没有装过

按 `Win + R`，输入 `cmd`，回车。在黑色窗口里输入：

```bat
python --version
```

- 显示 `Python 3.9.x` 或更高：已经装好了，跳到「三、下载并打开项目」。
- 显示「不是内部或外部命令」：继续第 2 步。
- 弹出微软商店：看下面的「微软商店拦截」。

### 第 2 步：下载

打开浏览器，访问 Python 官方下载页：

```text
https://www.python.org/downloads/
```

点击页面上黄色的 **Download Python 3.x.x** 按钮。
不要下载「Embeddable package」，那是给嵌入程序用的，不带完整环境。

### 第 3 步：安装（只有一个地方容易错）

双击下载好的安装包，在第一个页面**务必勾选**：

```text
[√] Add python.exe to PATH
```

然后再点 **Install Now**。

> 如果忘了勾：卸载重装，或者在安装程序里选 Modify → 勾选 Add Python to environment variables。
> 不要一边装一边点「Disable path length limit」，那个可点可不点，不影响本工具。

### 第 4 步：验证

关闭所有命令行窗口（重要，PATH 要重新读取），重新打开 `cmd`：

```bat
python --version
```

应该显示：

```text
Python 3.14.3
```

版本号不重要，只要是 3.9 以上即可。

再输入：

```bat
python -c "print('你好，Python')"
```

应该输出：

```text
你好，Python
```

如果中文变成乱码，先执行 `chcp 65001` 再试。这个工具自己的 BAT 会自动处理编码。

### 微软商店拦截

如果你输入 `python` 却弹出了微软商店，说明系统里的「应用执行别名」把 Python 指向了商店。

关闭方法：

1. 打开「设置」；
2. 进入「应用」→「高级应用设置」→「应用执行别名」；
3. 找到 `python.exe` 和 `python3.exe`；
4. 把两个开关都关掉；
5. 重新打开 `cmd`，输入 `python --version`。

### macOS / Linux

macOS 一般自带 Python 3，或者用 Homebrew：

```bash
brew install python
python3 --version
```

Ubuntu / Debian：

```bash
sudo apt update
sudo apt install python3
python3 --version
```

后面的命令里，Windows 用 `python`，macOS/Linux 通常用 `python3`。

## 三、下载并打开项目

### 1. 找到 assistant 文件夹

项目根目录下有一个 `assistant` 文件夹，里面至少有：

```text
assistant/
├─ 启动小助手.bat
├─ love_assistant.py
├─ 使用说明.md
└─ data/
   └─ memory.json
```

### 2. 建议放在一个不会被误删的位置

- 不要放在 `C:\Windows`、`Program Files` 这类需要管理员权限的位置；
- 路径里可以有中文，Python 3 支持得很好；
- 不要放在会自动同步、自动清理的临时目录；
- 如果放在 OneDrive，注意同步冲突可能会产生副本文件。

### 3. Windows 双击启动

双击 **`启动小助手.bat`**。

它会自动做四件事：

1. 把控制台代码页切到 UTF-8；
2. 进入脚本所在目录；
3. 优先用 `python`，找不到就用 `py -3`；
4. 启动 `love_assistant.py`。

如果 Windows 提示「已保护你的电脑」：

- 点「更多信息」→「仍要运行」；
- 这个 BAT 只有十几行，可以用记事本打开逐行查看；
- 它不是从网络下载的可执行文件，只是调用你本机的 Python。

### 4. 手动启动（BAT 出问题时）

在 `assistant` 文件夹的地址栏输入 `cmd`，回车，然后：

```bat
chcp 65001
python love_assistant.py
```

macOS / Linux：

```bash
cd assistant
python3 love_assistant.py
```

## 五、逐项使用

### 5.1 今日概览（菜单 1）

显示：

- 今天几号、星期几；
- 在一起第几天；
- 换算成几年几个月几天；
- 今天恰好是什么日子；
- 未来 30 天的纪念日和重要事项。

「第几天」把开始那天算作第 1 天。
如果开始日期在未来，会提示你去改资料。

### 5.2 记忆问答（菜单 2）

输入问题，回车；再输入空行返回。

它不是大模型，**不会编造**。工作方式是：

1. 先识别意图：问天数、生日、纪念日、重要事项、喜好、回忆；
2. 再在 `memory.json` 里做关键词搜索；
3. 找不到就明确说「我还没记住」，并告诉你三种补充办法。

能问的例子：

```text
我们在一起多久
第几天
小满生日
小满喜欢什么
小满不喜欢什么
送小满什么礼物
小满在意什么
第一次看海
雪
吵架
最近有什么重要的事
今天是什么日子
```

搜索是按中文两字片段匹配的，所以：

- 问「看海」也能找到「第一次看海」；
- 问「咖啡」能找到「热咖啡（不加糖）」；
- 问太长的整句可能反而不好匹配，**用标题里的词最准**。

### 5.3 生成情话（菜单 3）

流程：

1. 选场景：1 早安、2 晚安、3 道歉、4 安慰；
2. 输入「今天的小事」（可空）；
3. 生成 3 条；
4. 回车返回，`r` 换一批，`s` 保存到 `assistant/out/`。

「今天的小事」会被织进其中一条，例如：

```text
今天的小事：她今天加班到十点

1. 今天的小事：她今天加班到十点。我记着呢，早上先提醒你一句，别忘。
2. 今天不祝你顺利，祝你遇到麻烦的时候，刚好有人帮你。
3. 小满，如果今天有点难，就把难的部分留一点给我。
```

**不要直接群发。** 挑一条，改一两个词，加上只有你们知道的细节，它才像你写的。

### 5.4 安排约会（菜单 4）

依次输入：

1. 两个人一共的预算（回车默认 200 元）；
2. 可用时间（小时，回车默认 4）；
3. 室内 / 室外 / 都行；
4. 大概几点开始（可空，回车跳过）。

然后得到 3 个方案。每个方案都有：

- 预算、时长、适合场景；
- 为什么推荐它；
- 从开始时间推算出的时间线；
- 出发前准备；
- 一个不花钱的惊喜。

如果预算或时间太紧，程序会给出最接近的方案，并明确告诉你超了多少。
**它不会假装一个 50 元的方案是 500 元的体验。**

### 5.5 重要日子（菜单 5）

输入想看未来多少天，默认 60。

输出包含：

- 日期、星期、事件名；
- 还有几天；
- 类型（纪念日 / 重要事项）；
- 备注；
- 7 天内会提醒「可以开始准备了」。

一次性事项过去后不会再出现在提醒里，但数据仍然保留在 `memory.json`。

### 5.6 管理记忆（菜单 6）

这是最常用的子菜单。

| 选项 | 作用 | 会问什么 |
| --- | --- | --- |
| 1 | 添加纪念日 | 名称、月-日、从哪年开始（可空）、备注 |
| 2 | 添加重要事项 | 名称、完整日期、备注 |
| 3 | 添加喜好/雷区 | 是谁、类别、具体内容 |
| 4 | 添加回忆 | 日期、标题、细节、标签 |
| 5 | 修改基本资料 | 称呼、开始时间、两个生日 |
| 6 | 删除条目 | 类型、序号、二次确认 |
| 7 | 查看数据摘要 | 只读，用来确认数据规模 |

每次保存都会：

1. 在 `data/backups/` 里复制一份旧数据；
2. 用原子写入替换 `memory.json`；
3. 最多保留 30 个备份。

删除操作需要输入 `y` 确认；直接回车是「不删除」。

### 5.7 备份与导出（菜单 7）

- **立即备份**：手动留一个快照；
- **导出 JSON**：复制到 `data/exports/`，文件名带时间；
- **查看备份**：列出最新 10 个；
- **从备份恢复**：选序号、确认；恢复前会再备份当前数据。

### 5.8 使用帮助（菜单 8）

在程序里快速查看数据路径、常用命令和安全提醒。

## 六、数据文件详解

### 6.1 位置

```text
assistant/data/memory.json
```

可以用记事本、VS Code、Typora、Obsidian 打开。
它是 UTF-8 编码的普通 JSON。

### 6.2 结构

```json
{
  "meta": {
    "version": 1,
    "created_at": "2026-10-25T22:00:00",
    "updated_at": "2026-10-25T22:00:00"
  },
  "couple": {
    "me": "阿星",
    "partner": "小满",
    "start": "2023-05-20T20:13:00",
    "partner_birthday": "10-16",
    "my_birthday": "",
    "city": "我们住的城市"
  },
  "anniversaries": [
    {
      "title": "在一起纪念日",
      "date": "05-20",
      "count_from": "2023-05-20",
      "note": "20:13，那句「那就在一起吧」。"
    }
  ],
  "important": [
    {
      "title": "小满体检复查",
      "date": "2026-11-03",
      "note": "上午，记得空腹。"
    }
  ],
  "preferences": {
    "小满": {
      "喜欢": ["海鲜面", "热咖啡（不加糖）"],
      "不喜欢": ["太吵的餐厅"],
      "送礼": ["手写信"],
      "在意": ["累的时候先问要不要帮忙"]
    }
  },
  "memories": [
    {
      "date": "2023-07-16",
      "title": "第一次看海",
      "detail": "照片几乎全糊了，海边那家海鲜面没排上。",
      "tags": ["旅行", "海边"]
    }
  ]
}
```

### 6.3 字段说明

| 字段 | 说明 |
| --- | --- |
| `couple.start` | 在一起的起点，必须能解析出年月日；建议带时间 |
| `couple.partner_birthday` | `MM-DD`，例如 `10-16` |
| `couple.my_birthday` | 可空；空字符串表示未填写 |
| `anniversaries[].date` | 每年重复，只写 `MM-DD` |
| `anniversaries[].count_from` | 可选；填了会显示「第 N 个」 |
| `important[].date` | 一次性事项，写 `YYYY-MM-DD` |
| `preferences` | 人 → 类别 → 字符串列表；类别可以自己加 |
| `memories[].tags` | 字符串数组，用于搜索和整理 |
| `meta` | 程序自己维护，一般不用改 |

### 6.4 修改时的四条铁律

1. **英文双引号成对**；
2. **两项之间要有逗号，最后一项后面不要多逗号**；
3. **日期格式不要混**：纪念日 `05-20`，一次性 `2026-11-03`；
4. **改之前先复制一份 `memory.json`**。

如果 JSON 坏了，程序会：

- 把坏文件复制成 `memory.broken-时间.json`；
- 用示例数据重新生成 `memory.json`；
- 在屏幕上明确告诉你坏文件在哪。

它**不会**悄悄删掉你的内容，但你得从坏文件里手工把内容救回来。

### 6.5 怎么确认改对了

重新打开程序 → 菜单 6 → 7 查看数据摘要。
能正常显示，基本就说明结构没问题。
再分别用菜单 1、2、5 看一眼实际效果。

## 七、改情话和约会方案（不需要懂编程）

### 7.1 改情话

用编辑器打开 `assistant/love_assistant.py`，搜索：

```python
SCENE_TEMPLATES = {
```

你会看到四组列表：`morning`、`night`、`apology`、`comfort`。
只改引号里的中文，别动引号、逗号、方括号。

占位符：

- `{partner}` → 对方的称呼；
- `{me}` → 你的称呼；
- `{note}` → 你输入的「今天的小事」。

规则：

- 每个场景至少保留两条不带 `{note}` 的句子；
- 带 `{note}` 的句子只会在你输入小事时出现；
- 句子长度建议控制在 40 个汉字以内，方便手机上阅读；
- 不要写「永远」「保证」「没有你我就活不下去」这类压力很大的话。

### 7.2 改约会方案

搜索：

```python
DATE_PLANS = [
```

每个方案是一个大括号块。关键字段：

```python
"cost": 50,          # 两个人一共的大致花费
"minutes": 150,      # 总时长（分钟）
"place": "室内",      # 室内 / 室外 / 都行
"category": "宅家",   # 用来避免推荐重样
"flow": [            # 时间线：(从开始算起的分钟, 做什么)
    (0, "一起买菜"),
    (30, "回家洗菜"),
],
```

想加方案：复制一整段 `{ ... },`，改文字和数字。
最容易犯的错：

- 忘了最后一项后面的逗号；
- `flow` 里的括号写成了中文括号；
- `place` 写成了「家里」「外面」这种程序不认识的值；
- `category` 全部一样，导致推荐不出三个不同方案。

改完保存，重新启动程序即可。

## 八、进阶玩法一：让电脑读出来

> 只在 Windows 上可用，依赖系统自带的语音合成（SAPI）。
> 不是所有系统都装了中文语音；没有中文语音时，会读成英文或直接失败。

### 8.1 先看有哪些语音

打开 PowerShell，运行：

```powershell
Add-Type -AssemblyName System.Speech
$speak = New-Object System.Speech.Synthesis.SpeechSynthesizer
$speak.GetInstalledVoices() | ForEach-Object { $_.VoiceInfo.Name }
```

常见结果：

```text
Microsoft Huihui Desktop
Microsoft Zira Desktop
```

`Huihui` 是中文女声。没有中文声音的话：

- 设置 → 时间和语言 → 语言 → 添加中文（简体）语言包；
- 或在「语音」设置里添加中文语音；
- 装完重启 PowerShell 再查。

### 8.2 读今日概览

先让程序把内容写进文件：

```bat
python love_assistant.py --today --save
```

输出会保存在 `assistant/out/今日概览-时间.txt`。
然后在 PowerShell 里：

```powershell
Add-Type -AssemblyName System.Speech
$latest = Get-ChildItem "C:\你的路径\assistant\out\今日概览-*.txt" |
          Sort-Object LastWriteTime -Descending |
          Select-Object -First 1
$text = Get-Content -Raw -Encoding UTF8 $latest.FullName
$speak = New-Object System.Speech.Synthesis.SpeechSynthesizer
$speak.Rate = -1
$speak.SelectVoice("Microsoft Huihui Desktop")
$speak.Speak($text)
```

如果报「找不到语音」，把 `SelectVoice` 那一行删掉，用系统默认声音。

### 8.3 读一条晚安

```bat
python love_assistant.py --scene night --save
```

然后同上，把文件名换成 `晚安情话-*.txt`。

### 8.4 做成一个双击就朗读的 BAT

在 `assistant` 文件夹里新建 `朗读今日.bat`：

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"
set PYTHONUTF8=1
python love_assistant.py --today --save >nul
powershell -NoProfile -ExecutionPolicy Bypass -Command ^
  "Add-Type -AssemblyName System.Speech;" ^
  "$f = Get-ChildItem '.\out\今日概览-*.txt' | Sort-Object LastWriteTime -Descending | Select-Object -First 1;" ^
  "$t = Get-Content -Raw -Encoding UTF8 $f.FullName;" ^
  "$s = New-Object System.Speech.Synthesis.SpeechSynthesizer;" ^
  "$s.Rate = -1;" ^
  "$s.Speak($t)"
pause
```

注意：

- 如果系统没有中文语音，会读得很难听，这是系统限制，不是程序 bug；
- 朗读内容只在本机播放，不会上传；
- 不要在公共场合外放包含隐私的备注。

## 九、进阶玩法二：自动生成早安消息

### 9.1 先手动跑通

```bat
cd /d "C:\你的路径\assistant"
python love_assistant.py --scene morning --save
```

每次会在 `out/` 里生成一个 `早安情话-时间.txt`。
打开看看内容是不是你想要的风格。不满意就先改模板。

### 9.2 用「任务计划程序」每天自动生成

1. 按 `Win`，搜索「任务计划程序」，打开；
2. 右侧点「创建基本任务」；
3. 名称：`恋爱小助手-早安`；
4. 触发器：每天；
5. 时间：比如 `07:30`；
6. 操作：启动程序；
7. 程序或脚本：填 `python.exe` 的完整路径。

   在 `cmd` 里运行 `where python`，会得到类似：

   ```text
   C:\Users\你的用户名\AppData\Local\Programs\Python\Python314\python.exe
   ```

   把这个路径填进去。

8. 添加参数：

   ```text
   love_assistant.py --scene morning --save
   ```

9. 起始于（非常重要）：

   ```text
   C:\你的路径\assistant
   ```

10. 勾选「不管用户是否登录都要运行」需要管理员权限；普通使用选「只在用户登录时运行」即可；
11. 保存后，右键任务 →「运行」，去 `out/` 看有没有新文件。

### 9.3 让消息真正到达手机

程序只负责**生成文本**，不负责发送。可选的做法：

- **同步盘**：把 `out/` 放进 OneDrive / 坚果云 / iCloud Drive，手机上打开最新文件；
- **邮件**：用 Python 自带的 `smtplib` 写一个小脚本，把文本发到自己的邮箱（需要邮箱的 SMTP 授权码，不要把授权码写进代码后发给别人）；
- **剪贴板**：在电脑上运行 `Get-Content ... | Set-Clipboard`，再手动粘贴；
- **纸质**：打印出来放在桌上，比推送更难被忽略。

不建议做「自动发微信」：

- 微信没有开放个人号自动发消息的官方接口；
- 第三方自动化工具可能违反平台规则，也可能导致账号受限；
- 这类工具通常需要保持登录，隐私风险更高。

自动生成 + 手动发送，是更稳妥的做法。

### 9.4 让每次内容不重样

- 模板多写几条（每个场景 10 条以上）；
- 任务计划程序每天运行一次，程序会随机挑；
- 如果想要「每天固定同一批」，加 `--seed 日期`，例如 `--seed 20261025`；
- 如果想要「今天有特别的事就提一句」，可以在任务里加 `--note "今天她体检"`，但这样每天都要改任务，不划算。更好的做法是把重要事项写进 `memory.json`，让「今日概览」来提醒。

## 十一、隐私、安全与边界

### 11.1 它是明文的

`memory.json` 没有加密。任何能打开这个文件夹的人都能读到。
所以：

- 不要记录身份证号、银行卡、密码、验证码；
- 不要记录对方明确说过「不要写下来」的事；
- 不要记录第三人的隐私；
- 不要把它放在共享电脑的公共目录。

### 11.2 加一道锁

- **压缩包加密**：7-Zip → 添加到压缩包 → 设置密码 → 勾选加密文件名；
- **加密盘**：BitLocker（Windows 专业版）或 VeraCrypt；
- **系统锁屏**：设置 Windows 登录密码，离开时 `Win + L`；
- **备份加密**：`data/backups/` 和 `data/exports/` 同样是明文，复制前要一起处理。

### 11.3 关于「惊喜」的边界

这个工具能帮你准备惊喜，但不建议：

- 冒充他人发送消息；
- 用对方的生日、手机号、身份证号做密码；
- 未经同意查看对方的聊天记录、相册、定位；
- 把对方的隐私写进公开部署的网页。

惊喜的前提是**对方会感到安全**，而不是「被安排得明明白白」。

### 11.4 数据丢失

最坏的情况是硬盘坏了。建议：

- 每月手动导出一次，放到另一个物理位置；
- 重要记录同时留在第二大脑的 Markdown 里；
- 每半年打开一次备份，确认能读；
- 不要把唯一的副本放在 U 盘里。

## 十二、常见问题排查表

| 现象 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 双击 BAT 一闪而过 | 没装 Python / 没加 PATH | 打开 cmd 运行 `python --version`；重装并勾选 Add to PATH |
| 输入 python 弹出商店 | 应用执行别名 | 设置 → 应用 → 高级应用设置 → 应用执行别名 → 关闭 |
| `python` 可用但 BAT 报错 | BAT 被安全软件拦截 | 右键 BAT → 属性 → 解除锁定；或手动 `python love_assistant.py` |
| 中文乱码 | 控制台不是 UTF-8 | 用 BAT；或先 `chcp 65001` |
| 提示 JSON 解析失败 | 少逗号/引号/括号 | 打开 `memory.broken-*.json` 逐项检查；用 JSON 校验工具 |
| 保存失败、文件被占用 | 记事本/编辑器还开着 | 关闭编辑器；检查文件夹只读/同步盘冲突 |
| 日期差一天 | 系统时间不对 / 起点时间 | 检查系统日期；改「在一起的起点」 |
| 生日 2 月 29 日不提醒 | 非闰年 | 程序按 2 月 28 日提醒，这是有意的 |
| 搜不到某条记录 | 关键词不匹配 | 用标题里的词；或把标题写得更具体 |
| 情话重复 | 模板太少 | 每个场景多加几条 |
| 三个约会方案很像 | `category` 都一样 | 给方案设置不同 `category` |
| 语音没有中文 | 系统没装中文语音 | 设置 → 时间和语言 → 语音 → 添加中文 |
| 任务计划程序没生成文件 | 起始目录没填 | 「起始于」填 assistant 的完整路径 |
| 任务计划程序窗口一闪 | 参数/路径有空格没引号 | 路径用英文双引号包住；先用 cmd 手动跑通 |
