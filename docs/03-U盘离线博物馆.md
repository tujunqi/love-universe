# U 盘离线博物馆：把整个宇宙装进口袋

主页是“在线的情书”，U 盘博物馆是“可以摸到的纪念馆”。

它不依赖网络、不依赖账号、不依赖任何平台。只要 U 盘还在、文件还在、浏览器还认识 HTML，几十年后依然能打开。

这一篇讲清楚：

1. 博物馆里有什么；
2. 怎么把你们的照片、视频、语音、回忆录放进去；
3. 怎么复制到 U 盘、怎么打开；
4. 怎么设置插入后自动弹出；
5. 怎么做 U 盘封面、图标和开机画面；
6. 怎么验证它在别人的电脑上也能用。

---

## 一、先看成品结构

```text
offline/
├─ 离线博物馆.html                 ← 双击这个进入（入口）
├─ 使用说明.txt                     ← 给未来的自己看
├─ open-museum.bat                 ← 自动寻找 HTML 并打开（autorun 调用）
├─ 打开我-Windows.bat               ← Windows 双击打开（推荐）
├─ 打开我-静默.vbs                  ← Windows 无黑框打开
├─ 全屏参观.bat                     ← 全屏 / kiosk 模式
├─ 打开我-Mac.command               ← macOS 双击打开
├─ 打开我-Linux.sh                  ← Linux 双击/终端打开
├─ autorun.inf                     ← 老系统自动播放配置
├─ museum.ico                      ← U 盘在“此电脑”里的图标
├─ museum.css                      ← 样式
├─ museum.js                       ← 内容配置（改照片、视频、语音、回忆录）
├─ 单文件版/
│  ├─ 恋爱纪念博物馆-单文件版.html    ← 所有素材打包成一个文件
│  └─ 生成说明.txt                  ← 重新生成的命令
└─ media/
   ├─ photos/                      ← 照片
   ├─ videos/                      ← 视频
   ├─ voice/                       ← 语音
   ├─ memoirs/                     ← 回忆录、PDF、Word
   └─ audio/                       ← 背景音乐
```

**最重要的原则：保持目录结构不变。**

照片必须放在 `media/photos/`，视频必须放在 `media/videos/`。不要把所有文件拖到根目录，否则页面找不到。

## 二、博物馆里有什么

### 2.1 开馆封面

- 深色展厅风格，和主页的粉色不是一个气质；
- 显示你们的姓名、在一起的天数、当前日期；
- 一句“本馆仅接待两位观众”；
- 点击“推门进入”，背景音乐淡入；
- 有“参观须知”，告诉打开的人这是什么东西。

### 2.2 序厅

- 在一起多少天、多少张照片、多少个片段；
- 一句馆长的开场白；
- 一枚“镇馆之宝”位置，可以放你们最有意义的一张照片；
- 快速跳到各个展厅。

### 2.3 照片长廊

- 所有照片以画册方式排列；
- 点开看大图，支持左右切换、键盘方向键、手机滑动；
- 每张照片有标题和日期；
- 照片缺失时显示优雅的占位，不会整页崩。

### 2.4 影音室

- 视频卡片：封面 + 标题 + 日期 + 播放按钮；
- 语音卡片：一条条语音留言，点开播放；
- 背景音乐开关；
- 没有文件时显示“把文件放进来”的提示。

### 2.5 回忆录

- 按章节阅读，像一本小书；
- 章节内容写在 `museum.js` 里，不受本地文件读取限制；
- 也可以把 PDF、Word、TXT 放进 `media/memoirs/`，在页面里点开；
- 适合放：《我们的一年》《第一次旅行》《吵架与和好》《关于未来的十件事》。

### 2.6 时间胶囊

- 写给未来的一封信；
- 可以设置一个开启日期，例如十年后的纪念日；
- 未到日期时只显示倒计时；
- 也可以设置一个密码，提前查看；
- 再次提醒：前端密码不是真加密，别放真正不能见光的内容。

### 2.7 参观指南

- 怎么操作、怎么换素材、怎么联系馆长；
- 一页“几十年后打开指南”，即使没有网络也能看；
- 版本号和制作日期，方便未来识别。

## 三、把你的素材放进去

### 3.1 照片

1. 准备 1600 像素长边、单张小于 800KB 的 JPG；
2. 命名成 `p01.jpg` 到 `p20.jpg`；
3. 放进 `offline/media/photos/`；
4. 打开 `offline/museum.js`，找到：

```js
photos: [
  { src: "media/photos/p01.svg", title: "第一次一起看海", date: "2023.07.16" },
  ...
]
```

5. 把 `.svg` 改成 `.jpg`，标题和日期改成你们的；
6. 想加照片，复制一行，改路径；
7. 想删照片，删掉整行，注意最后一行不要留逗号。

封面用的三张图也在 `photos` 里单独配置：

```js
cover: {
  image: "media/photos/cover-1.svg",
  title: "我们的私人博物馆",
  subtitle: "仅接待两位观众"
}
```

换成你们的横图即可。

### 3.2 视频

1. 视频转成 MP4（H.264 + AAC）；
2. 建议单个小于 200MB，U 盘读取更稳；
3. 放进 `offline/media/videos/`；
4. 在 `museum.js` 里找到：

```js
videos: [
  {
    src: "media/videos/first-trip.mp4",
    poster: "media/photos/p07.jpg",
    title: "第一次旅行",
    date: "2024.01.13",
    note: "在陌生城市醒来的第一个早上"
  }
]
```

5. `poster` 是视频封面图，可以留空 `""`；
6. 没有视频就保留空数组：

```js
videos: [],
```

页面会自动显示“影音室正在布展”的提示。

**格式建议**：

| 格式 | 兼容性 | 建议 |
| --- | --- | --- |
| MP4 / H.264 | 最好 | 首选 |
| MOV / H.265 | 一般 | 老电脑可能放不了 |
| AVI | 差 | 不要用 |
| MKV | 一般 | 需要转 MP4 |
| WMV | 差 | 不要用 |

### 3.3 语音

1. 微信语音先导出成 MP3 或 M4A；
2. 放进 `offline/media/voice/`；
3. 在 `museum.js` 里：

```js
voices: [
  {
    src: "media/voice/2024-birthday.m4a",
    title: "生日那天的语音",
    date: "2024.10.16",
    note: "你说，今年也要一起吃蛋糕"
  }
]
```

浏览器对 M4A 的支持不错；不确定就转成 MP3。

### 3.4 回忆录和文档

两种方式：

**方式一：写进页面（推荐，最稳）**

```js
memoirs: [
  {
    title: "第一章 · 我们是怎么开始的",
    date: "2023.05.20",
    paragraphs: [
      "那天晚上八点十三分，你发来一句……",
      "我盯着屏幕看了很久，才想起来要回一个好。"
    ]
  }
]
```

每段一个字符串，手机阅读体验最好，也不怕文件丢失。

**方式二：放文件，页面给链接**

```js
documents: [
  {
    src: "media/memoirs/我们的一年.pdf",
    title: "我们的一年",
    note: "2023.05 - 2024.05",
    type: "pdf"
  },
  {
    src: "media/memoirs/未来清单.docx",
    title: "关于未来的十件事",
    note: "待完成",
    type: "doc"
  }
]
```

注意：

- 文件名尽量用英文数字，中文名在某些系统上会出现链接编码问题；
- PDF 浏览器一般能直接打开；
- Word、Pages 文件会触发下载，需要电脑上有对应软件；
- 想几十年后还能读，重要内容同时保留一份 PDF 和一份纯文本。

### 3.5 背景音乐

1. 把歌转成 `bgm.mp3`；
2. 放进 `offline/media/audio/`；
3. 在 `museum.js` 里：

```js
music: "media/audio/bgm.mp3"
```

进入博物馆时不会自动响，点击“推门进入”后才会播放。这是浏览器的规则，也刚好变成一个仪式。

## 四、复制到 U 盘

### 4.1 选 U 盘

| 项目 | 建议 |
| --- | --- |
| 容量 | 32GB 或 64GB 足够；照片视频多就 128GB |
| 接口 | USB 3.0 起步，老电脑也兼容 USB 2.0 |
| 品牌 | 正规品牌，避免无名扩容盘 |
| 文件系统 | exFAT（Windows/macOS 都能读写，支持大文件） |
| 备选 | FAT32（兼容老设备，但单文件不能超过 4GB） |
| 不建议 | NTFS（macOS 默认只读） |

### 4.2 复制步骤

1. 把 U 盘格式化为 exFAT；
2. 在 U 盘根目录新建文件夹 `恋爱纪念博物馆`；
3. 把整个 `offline` 文件夹里的内容复制进去；
4. 确认 `离线博物馆.html` 就在这个文件夹的第一层；
5. 安全弹出 U 盘；
6. 换一台电脑，双击测试。

最终 U 盘结构：

```text
U盘/
└─ 恋爱纪念博物馆/
   ├─ 离线博物馆.html
   ├─ 打开我-Windows.bat
   ├─ 打开我-静默.vbs
   ├─ 全屏参观.bat
   ├─ 打开我-Mac.command
   ├─ 打开我-Linux.sh
   ├─ open-museum.bat
   ├─ autorun.inf
   ├─ museum.ico
   ├─ museum.css
   ├─ museum.js
   ├─ 单文件版/
   │  └─ 恋爱纪念博物馆-单文件版.html
   └─ media/
```

不要把 `offline` 文件夹再套一层，否则 `.bat` 里的相对路径可能找不到入口。

### 4.3 复制后必须做的三件事

1. **在另一台电脑上打开一次**，不要只在自己电脑上测试；
2. **拔掉网络再打开一次**，确认真的离线可用；
3. **用手机 OTG 或另一台电脑再打开一次**，确认路径没有大小写问题。

## 五、怎么打开

### 5.1 Windows

三种方式，任选：

1. 双击 `打开我-Windows.bat`；
2. 双击 `打开我-静默.vbs`（不弹黑框）；
3. 直接双击 `离线博物馆.html`。

`.bat` 会依次尝试用 Edge、Chrome、默认浏览器打开。它不会安装任何东西，也不会改系统设置。

如果浏览器提示“无法访问此文件”，检查：

- 文件是不是被解压软件包了一层；
- 路径里有没有特殊符号；
- 浏览器是不是太老。

### 5.2 macOS

1. 双击 `打开我-Mac.command`；
2. 第一次可能提示“无法打开，因为来自身份不明的开发者”；
3. 右键 → 打开 → 仍要打开；
4. 或者在“系统设置 → 隐私与安全性”里允许。

也可以在终端里：

```bash
cd /Volumes/你的U盘/恋爱纪念博物馆
open "离线博物馆.html"
```

### 5.3 Linux

```bash
cd /media/你的用户名/你的U盘/恋爱纪念博物馆
xdg-open "离线博物馆.html"
```

或者双击 `打开我-Linux.sh`，第一次需要右键属性里勾选“允许作为程序执行”。

### 5.4 手机 / 平板

- Android：用文件管理器找到 HTML，选择浏览器打开；部分系统会限制本地文件，建议用 Chrome 或 Via；
- iPhone / iPad：Safari 对本地 HTML 支持有限，建议把单文件版发到“文件”App，用支持本地网页的浏览器打开；
- 最稳的方式：带一台旧笔记本，或者把单文件版放进网盘离线缓存。

## 六、插入 U 盘自动打开：真相和可行方案

### 6.1 先说真相

网上很多教程说“在 U 盘根目录放一个 autorun.inf，插入就会自动播放”。**这个说法在现在的 Windows 上基本不成立。**

原因：

- Windows 7 之后，微软为了防病毒，默认关闭了可移动存储的 AutoRun；
- Windows 10/11 进一步限制，U 盘插入后通常只会弹“选择要执行的操作”；
- 单位、学校电脑通常由管理员彻底禁用 AutoPlay；
- macOS 和 Linux 没有 Windows 式 AutoRun。

所以正确心态是：**自动打开是加分项，不是唯一方案。** 一个清楚的文件夹名、一个 `打开我` 的快捷方式、一张纸质说明，比不靠谱的自动运行更重要。

### 6.2 方案一：autorun.inf（能做的部分）

在 U 盘根目录放 `autorun.inf`：

```ini
[AutoRun]
open=恋爱纪念博物馆\open-museum.bat
icon=恋爱纪念博物馆\museum.ico
label=我们的纪念宇宙
```

它能做的：

- 在部分系统上设置 U 盘图标和卷标；
- 在 AutoPlay 开启的电脑上，可能出现在“选择要执行的操作”里；
- 老系统（Windows XP/7 且未打补丁）可能真的自动运行。

它不能做的：

- 在现代 Windows 上保证自动打开；
- 绕过杀毒软件；
- 在 macOS/Linux 上生效。

**不要**为了“自动运行”去关掉杀毒软件或修改注册表，得不偿失。

### 6.3 方案二：Windows 自动播放设置（每台电脑单独设置）

在**要展示的那台电脑**上：

1. 设置 → 蓝牙和其他设备 → 自动播放；
2. 打开“使用自动播放”；
3. 选择“每次询问”或“打开文件夹以查看文件”；
4. 插入 U 盘，选择“打开文件夹”；
5. 双击 `打开我-Windows.bat`。

这只是减少一步操作，不是真正自动运行。

### 6.4 方案三：任务计划程序 + U 盘插入事件（进阶，可靠但麻烦）

适合自己家的固定电脑：插入指定 U 盘时，自动用浏览器打开博物馆。

大致思路：

1. 打开“任务计划程序”；
2. 创建任务，触发器选“事件”；
3. 日志：`Microsoft-Windows-Kernel-PnP/Configuration`；
4. 事件 ID：`400` 或 `410`（设备插入相关，不同系统略有差异）；
5. 条件里绑定你的 U 盘设备实例路径；
6. 操作：启动程序 `msedge.exe`，参数填：

```text
--app="file:///E:/恋爱纪念博物馆/离线博物馆.html"
```

7. 保存后插入 U 盘测试。

这条路的坑：

- 盘符可能变化（E: 变 F:）；
- 事件 ID 因系统版本不同；
- 单位电脑没有管理员权限；
- 杀毒软件可能拦截。

如果你不是特别熟 Windows，建议直接用方案五：桌面快捷方式。

### 6.5 方案四：macOS 的“插入后打开”

macOS 没有原生“插入 U 盘自动打开某个网页”的设置。可以用：

-  Automator 创建“文件夹操作”，监听 `/Volumes`；
- 或写一个 LaunchAgent；
- 或在 U 盘根目录放一个显眼的 `打开我.command`。

对大多数人，最后一种最稳。

### 6.6 方案五：物理提示（最推荐）

- U 盘上贴一张小标签：`插入后打开「打开我-Windows.bat」`；
- 附一张卡片：`这是我们的小博物馆，双击打开就好`；
- 把 `打开我-Windows.bat` 改成更明显的名字，例如 `01-双击我-进入博物馆.bat`；
- 在 U 盘根目录放一个 `README.txt`，第一行就写怎么打开。

浪漫不只来自技术，也来自你替对方想到了“她/他可能不会操作”。

### 6.7 自动打开的“开机画面”替代方案

比起折腾系统 AutoRun，更推荐做一个**进入时的开馆画面**：

- 双击后先看到全屏封面；
- 显示“我们的私人博物馆 / 仅接待两位观众”；
- 点击“推门进入”，音乐响起；
- 浏览器按 `F11` 全屏，就像真的走进展厅。

博物馆已经内置了这个封面。你只需要换封面图和那句欢迎语。

## 七、U 盘图标和卷标

### 7.1 图标

`autorun.inf` 里的 `icon=` 指向 `museum.ico`。项目已经生成好了一个双人剪影图标。

如果 Windows 不显示图标：

1. 确认 `autorun.inf` 和 `.ico` 都在 U 盘根目录（或路径正确）；
2. 重新插拔 U 盘；
3. 在文件资源管理器里按 `F5` 刷新；
4. 有些系统会缓存旧图标，换一个 USB 口试试；
5. 企业电脑可能禁用了自定义图标。

### 7.2 卷标

`label=` 后面的文字就是 U 盘在“此电脑”里显示的名字，建议不超过 8 个汉字，例如：

```ini
label=我们的宇宙
```

也可以在格式化时直接设置卷标。

### 7.3 自己做一个图标

**方法 A：用项目自带脚本（推荐）**

`tools/make-icon.js` 会用封面图自动生成 5 个尺寸的 `museum.ico`：

```bash
node tools/make-icon.js
```

想换成你们的照片，编辑 `tools/make-icon.js` 里的 `object-position` 和 `img src`，再运行一次。

**方法 B：用在线工具**

1. 用一张你们的合照裁成正方形；
2. 导出 256×256 PNG（再补 48×48、32×32 更清晰）；
3. 用 ICO 转换工具生成 `.ico`；
4. 命名为 `museum.ico`，替换 `offline/` 里的同名文件。

图标建议：

- 不要放太多字，16×16 时看不清；
- 用一个剪影、一个爱心、一个日期就够；
- 深色底配浅色图形更容易辨认。

## 八、U 盘封面和“开机画面”

### 8.1 打印一张 U 盘封面卡

准备：

- 一张 8.5cm × 5.4cm 左右的卡纸（常见名片尺寸）；
- 你们的合照；
- 一句馆名；
- 一行小字：`插入电脑，双击「01-双击我」`。

排版建议：

```text
┌──────────────────────────┐
│                          │
│      我们的私人博物馆      │
│      OUR PRIVATE MUSEUM   │
│                          │
│   仅接待两位观众 · 2023—   │
│                          │
│  插入后双击「01-双击我」    │
└──────────────────────────┘
```

可以打印成不干胶，贴在 U 盘背面；也可以做成小卡片，和 U 盘一起放进盒子。

### 8.2 做一个“开馆画面”

博物馆自带的封面就是开馆画面。想换成你们的照片：

1. 打开 `offline/museum.js`；
2. 找到 `cover`；
3. 改 `image`、`title`、`subtitle`、`note`；
4. 保存，双击打开。

想更沉浸：

1. 用 Edge 打开博物馆；
2. 按 `F11` 全屏；
3. 或者在 `打开我-Windows.bat` 里用 `--kiosk` 参数（见第八节）。

### 8.3 全屏 / 展厅模式脚本

项目已经带了 `全屏参观.bat`。它会自动按顺序寻找 Chrome / Edge，找不到就退回默认浏览器：

```bat
@echo off
setlocal
cd /d "%~dp0"
set "PAGE="
for %%F in ("*.html") do if not defined PAGE set "PAGE=%%~fF"
set "BROWSER="
for %%B in (
  "%ProgramFiles%\Google\Chrome\Application\chrome.exe"
  "%ProgramFiles(x86)%\Google\Chrome\Application\chrome.exe"
  "%ProgramFiles%\Microsoft\Edge\Application\msedge.exe"
  "%ProgramFiles(x86)%\Microsoft\Edge\Application\msedge.exe"
) do if not defined BROWSER if exist "%%~B" set "BROWSER=%%~B"
start "" "%BROWSER%" --kiosk --autoplay-policy=no-user-gesture-required "file:///%PAGE:\=/%"
```

说明：

- `%~dp0` 表示脚本所在目录，换盘符也不会坏；
- `--kiosk` 会全屏且隐藏地址栏；
- 退出按 `Alt + F4`；
- 没有 Chrome / Edge 时，脚本会用默认浏览器打开，不会卡住。

这个模式适合当面送出时用，像一个小型展览。

### 8.4 关于“修改电脑开机画面”

需要明确：**Windows 的开机 logo 不能通过一个 U 盘或一个网页修改**，它由主板 UEFI/BIOS 固件决定，修改有风险，不建议普通人尝试。

你能做的是：

- 进入系统后自动全屏打开博物馆（任务计划程序）；
- 做一个开馆封面；
- 把 U 盘图标、卷标、贴纸做成统一视觉；
- 用旧平板/旧笔记本做成“展柜”，开机自动进入网页。

后者比改 BIOS 安全得多，也更像一份礼物。

## 九、在别人电脑上测试

### 9.1 测试清单

- [ ] 换一台 Windows 电脑，双击 `.bat` 能开；
- [ ] 断网后仍能打开；
- [ ] 照片、视频、语音都能播放；
- [ ] 中文路径不报错；
- [ ] 全屏模式能退出；
- [ ] U 盘图标显示（如果系统允许）；
- [ ] 单文件版也能独立打开；
- [ ] 杀毒软件没有误报（`.bat` 和 `.vbs` 偶尔会被误报）。

### 9.2 如果 `.bat` 被拦截

- 右键 → 属性 → 解除锁定（如果来自网络）；
- 用记事本打开 `.bat`，确认内容没有被篡改；
- 直接双击 `离线博物馆.html` 作为备用；
- 不要把来源不明的 `.bat` 发给别人。

### 9.3 如果视频不播放

- 换 MP4/H.264；
- 降低分辨率到 1080p；
- 文件不要超过 2GB（FAT32 限制 4GB）；
- 老电脑可能缺少解码器，用浏览器打开 MP4 通常没问题；
- 单文件版默认不内嵌大视频，视频仍从 `media/videos/` 读取。

### 9.4 如果字体变了

博物馆使用系统字体（宋体、苹方、微软雅黑等），不同系统会有细微差别，这是正常的。不要把字体文件塞进 U 盘，除非你确认授权允许分发。

## 十、U 盘版的隐私

- U 盘会丢。不要把唯一一份放在 U 盘里；
- 不要放身份证、银行卡、密码、住址；
- 如果内容很私密，U 盘可以加物理锁盒，或者只保留单文件版并设置压缩包密码；
- 送人前，确认 U 盘里没有其他旧文件；
- 格式化前备份；
- 如果是二手 U 盘，先彻底格式化，不要留下前主人的数据。

## 十一、单文件版：把整座馆装进一个 HTML

`offline/单文件版/恋爱纪念博物馆-单文件版.html` 是自动生成的“全内嵌版”：

- 照片、封面、背景音乐、语音、回忆录文档全部变成 data URI，写进 HTML；
- 不依赖 `media/`、`museum.css`、`museum.js`，单独拷走也能看；
- 适合发微信、放网盘、拷进手机、刻进光盘；
- 缺点：文件大（约 3MB，加视频会更大），改内容后要重新生成。

### 11.1 什么时候用文件夹版，什么时候用单文件版

| 场景 | 推荐版本 | 原因 |
| --- | --- | --- |
| U 盘长期保存 | 文件夹版 + 单文件版各一份 | 文件夹版方便替换素材，单文件版防止漏拷 |
| 微信 / QQ 发给对方 | 单文件版 | 一个文件，不会漏照片 |
| 放网盘 | 单文件版 | 不会被网盘“只预览 HTML” |
| 还要继续改内容 | 文件夹版 | 改 `museum.js` 后刷新即可 |
| 里面有视频 | 文件夹版 | 单文件版默认不内嵌视频 |
| 老电脑 / 旧浏览器 | 文件夹版 | 单文件版 3MB 的 data URI 对老浏览器压力更大 |

### 11.2 重新生成的完整步骤

需要电脑上装有 Node.js（和主页项目用的一样，Windows 安装包在 nodejs.org）。

1. 打开项目根目录（有 `tools` 文件夹的那一层）；
2. 在地址栏输入 `cmd` 回车，或在 VS Code 里打开终端；
3. 执行：

```bash
node tools/build-single-file.js
```

4. 看到下面的输出就成功了：

```text
✓ 单文件版已生成
  输出：offline\单文件版\恋爱纪念博物馆-单文件版.html
  大小：3.10 MB
  内嵌素材：27 个，原始 2.24 MB
```

5. 双击 `offline/单文件版/恋爱纪念博物馆-单文件版.html` 验证。

构建脚本每次都会重新读取 `offline/museum.js`、`museum.css` 和整个 `media/` 目录，
所以你改完名字、日期、照片后，只要再跑一次命令即可。

### 11.3 如果加了视频

视频默认不内嵌，原因很简单：一个 100MB 的视频会让 HTML 变成 130MB，微信发不出去，
老电脑打开也会卡死。

如果确定要连视频一起打包：

```bash
node tools/build-single-file.js --embed-video
```

注意：

- 生成时间会明显变长；
- 文件可能达到几百 MB；
- 部分浏览器打开超大 data URI 会崩；
- 发人之前先自己用另一台电脑测一次。

更稳的做法：视频留在文件夹版，单文件版只放照片、语音和文字。

### 11.4 单文件版的已知限制

1. **不能直接改**：里面的内容是压缩成一行的 base64，改源文件后重新生成，不要手动编辑。
2. **视频默认缺席**：见 11.3。
3. **馆藏文档变成下载**：PDF / TXT 内嵌后，点击会下载到本地再打开，这是浏览器的安全限制。
4. **文件很大时打开慢**：3MB 一般 1～3 秒；30MB 以上建议用文件夹版。
5. **音乐需要点击**：和文件夹版一样，点「推门进入」后才会响。
6. **浏览器缓存**：重新生成后如果还是旧内容，按 `Ctrl + F5`。

### 11.5 单文件版自检

项目里带了一个自检脚本，会直接用 `file://` 打开单文件版，检查：

- 是否还有外部 CSS / JS 依赖；
- 照片是否都加载；
- 背景音乐是否是 data URI 并能播放；
- 语音时长、馆藏文档、时间胶囊密码是否正常；
- 手机宽度下是否横向溢出；
- 控制台有没有 JS 报错。

```bash
node tools/audit-single.js
```

输出在 `tools/audit-single/report.json`，截图也在同一目录。

### 11.6 一个容易犯的错

改完文件夹版，忘了重新生成单文件版，结果发出去的是旧内容。

建议在 `使用说明.txt` 或自己的备忘录里写一句：

> 每次改完 museum.js，先按 F5 看文件夹版，再跑 `node tools/build-single-file.js`，最后看单文件版。
