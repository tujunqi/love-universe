# 10 · 惊喜发送全攻略

> 做完了，才是最难的部分：怎么送出去，才不像「完成任务」，而像「真的想到了你」。
>
> 这篇不教套路，只讲两件事：
> **怎么让对方顺利打开**，以及**怎么让打开的那一刻有分量**。
>
> 适用对象：主页、公网链接、U 盘博物馆、第二大脑、Python 小助手。
> 你可以只送一个链接，也可以把几样东西串成一次完整的惊喜。

---

## 零、先想清楚三个问题

在动手发送之前，先回答：

1. **她/他今天的状态，适合收到惊喜吗？**
   如果对方刚加班完、刚吵完架、正在赶论文、身体不舒服，一个需要探索和互动的网站可能是一种负担。先问一句「今天累不累」，比任何彩蛋都重要。

2. **这个惊喜是「给对方」的，还是「给自己一个交代」的？**
   前者会考虑对方的时间、设备、隐私和喜好；后者容易变成「我做了这么多，你怎么不感动」。

3. **里面有没有对方不希望被展示的内容？**
   合照、聊天记录、昵称、住址、工作单位、身体细节。**先征得同意，再放进去。**
   公开链接等于公开网页，任何人拿到都能看。

> 惊喜的前提是安全，不是失控。
> 不冒充别人、不制造假的紧急情况、不在对方明确拒绝后继续、不公开对方不想公开的东西。

## 一、两条路：线上链接，还是线下物件

| | 线上链接 | 线下 U 盘 / 本地文件 |
| --- | --- | --- |
| 适合 | 异地、即时、手机打开 | 同城、纪念日、想长期保存 |
| 优点 | 发出去就能看，更新方便 | 有实体感，不依赖网络，能放几十年 |
| 缺点 | 需要网络、链接可能被转发、隐私风险 | 需要电脑、Mac/Windows 兼容、U 盘可能丢 |
| 推荐模块 | 主页 + 公网部署 | 离线博物馆 + 单文件版 |
| 惊喜感 | 轻、快、随时能回看 | 重、慢、像收到一件礼物 |

**最稳的组合**：线上链接负责「现在就看」，U 盘负责「一直留着」。
链接里放一个提示：「U 盘在书架第二层」，让两个礼物互相指向。

## 二、线上链接：从做完到发出去

### 2.1 出发前检查（10 项）

- [ ] 手机流量下能打开，不只在家里的 Wi-Fi 能打开；
- [ ] 微信内置浏览器能打开（很多人直接点链接）；
- [ ] iPhone Safari 和安卓 Chrome 各试一次；
- [ ] 封面图不是空白，背景音乐点击后能播放；
- [ ] 照片墙里的照片都能加载，没有裂图；
- [ ] 时间线、抽签、默契测试、留言板都能用；
- [ ] 隐藏信的密码输入正确能打开，输错有提示；
- [ ] 页脚的小爱心点 7 下能看到隐藏的话；
- [ ] 页面里没有你的真实住址、公司、学校、身份证等信息；
- [ ] 把链接发给一个信得过的朋友，让对方用她的手机打开一次。

### 2.2 链接怎么发

#### 方式 A：直接发链接

最稳，也最不惊喜。适合：

- 对方不喜欢拐弯抹角；
- 你们已经约好今天要收一个东西；
- 链接本身需要对方尽快打开（比如生日当天）。

可以配一句很轻的话：

```text
给你做了个东西，不用现在看。
等你有空的时候，从第一页慢慢往下滑。
```

#### 方式 B：二维码

把链接生成二维码，打印出来，夹在书里、贴在礼物盒上、放在钱包里。

- 优点：有实体感，适合和花、信、蛋糕一起送；
- 注意：二维码别太小，至少 3×3 厘米；打印后自己先扫一次；
- 不要贴在会被雨水打湿的地方。

#### 方式 C：普通-looking 的链接（低调包装）

把链接放在一句很普通的话里，例如：

```text
上次你说的那家店，我整理了一个清单，放这里了：
https://你的链接
```

注意：

- 这是「低调」，不是「伪装成银行/快递/官方通知」；
- 不要用「你的账户异常」「快递丢失」这类会引发焦虑的标题；
- 不要冒充第三方，哪怕只是为了好玩；
- 链接打开后第一屏最好能立刻解释这是什么，别让对方困惑太久。

#### 方式 D：定时发送

如果你不能在当天陪着，可以用：

- 邮箱定时发送；
- 手机备忘录提醒自己，到点手动发；
- 任务计划程序定时生成早安消息（见 [09 教程](09-Python小助手运行教程.md)）。

不建议用第三方「自动发微信」工具，原因在 09 里已经写过：不合规、不稳定、隐私风险高。

### 2.3 不同关系阶段的发送话术

#### 刚确定关系

不要一次性把所有东西都倒出来。选一个最轻的入口：

```text
今天路过我们第一次见面的地方，突然想起来。
给你做了一个小页面，没什么大东西，就是一些我记得的片段。
https://...
```

重点：**少一点誓言，多一点具体的事**。

#### 异地

把「距离」写进去，而不是回避它：

```text
本来想今天去找你，但去不了。
所以把能放在网上的部分先给你：照片、时间线、还有一封要密码的信。
密码是我们第一次视频到凌晨的那天，四位数字。
https://...
```

注意：密码提示要足够明显，别让对方猜半小时。惊喜不是考试。

#### 稳定期 / 老夫老妻

不需要大场面，反而要「不像刻意准备」：

```text
今天没什么事。
顺手把我们这几年的照片整理了一下，你无聊的时候可以翻翻。
https://...
```

重点：**把隆重藏起来**。越像顺手，越容易让人放下防备。

#### 纪念日

提前一周开始铺垫，但不要每天都说：

- 第 7 天：随口提一句「今年纪念日别安排别的」；
- 第 3 天：把家里某件小东西换掉（比如杯子），不解释；
- 当天：先做一件很普通的事（吃饭、散步），最后再把链接或 U 盘拿出来。

#### 吵架之后

不要用「惊喜」代替道歉。顺序应该是：

1. 先道歉，把话说清楚；
2. 确认对方愿意见你/收东西；
3. 再把页面发过去，并说明：「不用现在看，等你想看的时候。」

如果对方还在气头上，任何精心准备的东西都可能被理解为「你在转移话题」。
**先修复关系，再送礼物。**

#### 长期 / 已婚

重点从「浪漫」转向「一起回看」：

- 把十年前的记录和第二大脑里的月度复盘放在一起；
- 让孩子/家人参与录制一段语音；
- 把 U 盘做成「家庭档案」，而不只是情侣礼物。

### 2.4 打开声音的正确姿势

浏览器普遍禁止「没有用户操作就自动播放声音」。所以：

- 页面通常需要点一下才能播放背景音乐；
- 在发送话术里加一句：「点一下页面，有声音」；
- 如果对方在办公室/地铁，提示「戴耳机」或「回家再点」；
- 不要用声音做唯一的彩蛋入口，静音环境会错过。

### 2.5 发送后不要做的三件事

1. **不要每分钟问「你看了吗」**。对方可能在忙，也可能想一个人慢慢看。
2. **不要要求对方立刻给出感动**。有人会哭，有人会沉默，有人只会说「哦，挺好」。反应不等于爱。
3. **不要在对方没看完时逐条解释彩蛋**。让探索本身成为乐趣；如果对方问，再回答。

可以做的：

- 发完就去做自己的事；
- 晚上轻轻问一句：「打开了吗？有没有哪里打不开？」
- 如果对方说「打不开」，先解决问题，不要先委屈。

## 三、线下 U 盘：把「链接」变成一件东西

### 3.1 准备清单

- [ ] U 盘一个（建议 16GB 以上，USB 3.0，别用太旧的）；
- [ ] `offline/` 整个文件夹复制到 U 盘根目录；
- [ ] 根目录有 `打开我-Windows.bat`、`打开我-Mac.command`；
- [ ] 图标 `museum.ico` 已设置（见 [05](05-开机画面与自动运行.md)）；
- [ ] 在 **对方的电脑** 上实际打开一次（Windows 和 Mac 都试更好）；
- [ ] 视频、语音能播放；
- [ ] 时间胶囊的密码和提示写在一张纸上；
- [ ] U 盘里没有你的其他私人文件；
- [ ] 做好另一份备份，别把唯一副本送出去。

### 3.2 包装

- 把 U 盘放进一个小盒子，盒子里放一张手写卡片；
- 卡片上不要写「插入电脑」这种说明书式的话，写一句只有你们懂的；
- 如果做成钥匙扣/挂件，注意别折断接口；
- 想做得更正式，可以打印一张「馆藏证书」，写上「本馆仅此一份」。

### 3.3 交付话术

#### 当面

```text
这个不是让你现在看的。
你回去以后，等有空，插到电脑上，双击第一个文件。
里面有说明书，也有密码提示。
```

#### 邮寄

在盒子里放一张纸：

```text
如果打不开，先看根目录的《使用说明.txt》。
密码提示：我们第一次看海的那天，月份和日期。
不用急着看，放很久也可以。
```

#### 藏在日常里

把 U 盘放在对方一定会发现、但不会立刻起疑的地方：

- 常用的抽屉；
- 书架上那本她最近在看的书旁边；
- 电脑包的小夹层；
- 冰箱贴下面（如果 U 盘不怕潮）。

不要藏在会损坏 U 盘的地方（洗衣机、花盆、冰箱冷冻层）。

### 3.4 Windows 的 AutoRun 真相

很多教程会说「插上 U 盘自动播放」，但：

- Windows 10/11 对 **可移动 U 盘** 默认禁用 AutoRun；
- 即使写了 `autorun.inf`，大多数情况下也只会显示图标，不会自动运行；
- 这是微软的安全策略，不是你的文件写错了。

所以正确预期是：

- 插上 U 盘 → 出现自定义图标 → 对方双击 `打开我-Windows.bat`；
- 不要承诺「插上就会自己打开」；
- 如果对方用的是 Mac，双击 `打开我-Mac.command`；第一次可能需要在「安全性与隐私」里允许。

`offline/autorun.inf` 仍然保留，是为了图标和少数环境，不要把它当成自动播放的保证。

### 3.5 全屏参观模式

`offline/全屏参观.bat` 会用 Chrome/Edge 的 kiosk 模式打开博物馆，适合：

- 纪念日当天，把电脑放在桌上，像一个小展厅；
- 展览/聚会时循环播放；
- 不想让对方看到浏览器地址栏和书签。

注意：

- kiosk 模式下退出可能需要 `Alt + F4`；
- 先在自己的电脑上试一次，确认能退出；
- 不要把它设成开机自启后自己忘了，否则下次开机很难关。

## 四、按关系阶段选方案

| 阶段 | 推荐组合 | 不建议 |
| --- | --- | --- |
| 刚确定关系 | 主页链接 + 一封短信 | 一上来就送 U 盘「博物馆」，太重 |
| 异地 | 主页链接 + 语音 + 定时早安 | 要求对方实时在线陪你逛 |
| 稳定期 | 主页 + 一顿普通饭 + 手写信 | 花大钱做场面，反而有压力 |
| 第一个纪念日 | 主页 + 相册 + U 盘备份 | 把「一周年」做成考试，问对方记不记得 |
| 吵架修复期 | 先道歉，再送一封信/一段语音 | 用礼物代替沟通 |
| 生日 | 生日弹层 + 蛋糕 + 一封信 | 在对方明确说累时硬搞派对 |
| 长期/已婚 | 第二大脑 + 家庭档案 + 孩子/家人语音 | 只复刻年轻时的浪漫，不更新现在的生活 |
| 分手/不确定期 | 不建议送 | 任何「挽回型惊喜」都可能造成压力 |

## 五、铺垫与反差：让那一刻有分量

### 5.1 七天铺垫法（适合纪念日/生日）

| 时间 | 做什么 | 注意 |
| --- | --- | --- |
| 第 7 天 | 随口说「今年那天别安排别的」 | 不要解释 |
| 第 5 天 | 把一件小东西换掉（杯子、床单、歌单） | 不主动提 |
| 第 3 天 | 问一个和回忆有关的问题：「你还记得第一次看海吗？」 | 不要立刻揭晓 |
| 第 1 天 | 做一件很普通的事（买菜、散步、洗碗） | 保持日常 |
| 当天 | 先正常吃饭，最后再拿出链接/U 盘 | 不要在对方饿、累、赶时间时揭晓 |
| 第二天 | 不追问感受，正常生活 | 让余味自己发酵 |

### 5.2 三段式

1. **日常**：让对方以为今天很普通；
2. **偏移**：出现一个很小的不对劲（桌上多了一个盒子、歌单里多了一首旧歌、链接里有一句只有你们懂的话）；
3. **落点**：真正的礼物出现，但不要一次全部解释完。

### 5.3 反差的三种做法

- **场景反差**：在最普通的周二，送一个准备了三个月的东西；
- **形式反差**：平时从不写信的人，写了一封手写信；
- **情绪反差**：前半段一直很轻松，最后一段突然认真，但不超过三句话。

### 5.4 不要用的「反差」

- 假装出事/生病/分手，看对方着急；
- 冒充快递、银行、公司发通知；
- 在对方明确说「不要惊喜」后仍然安排；
- 在公共场合让对方无法拒绝。

这些不是惊喜，是控制。

## 六、四个完整场景脚本

### 场景 1：异地，普通周末

**准备**：主页链接、一段 30 秒语音、一张当天的天空照片。

**发送**：

```text
今天这边天气很好，拍了一张，给你。
另外做了一个小页面，里面有一些我们以前的照片。
不用现在看，等你有空慢慢翻。
点一下页面会有声音，不方便的话先静音。
https://...
```

**后续**：晚上只问一句「打开了吗」，不追问感受。

### 场景 2：一周年，同城

**准备**：U 盘博物馆、手写信、一顿在家做的饭。

**流程**：

1. 白天正常上班/上课；
2. 晚上一起做饭，不提前说礼物；
3. 吃完饭，把 U 盘放在桌上，说：「这个不是现在看的，回去再看。」
4. 手写信当场给，信里只写三件事：这一年最想记住的一个画面、一次吵架后的感受、明年想一起做的一件小事。

**注意**：不要在这一天逼对方复盘「我们这一年有什么问题」。

### 场景 3：生日，对方说「不要惊喜」

**准备**：一碗面、一盏小灯、一封短信；主页的生日弹层已经设置好。

**做法**：

- 不搞派对、不叫人、不拍视频；
- 先问：「今天想吃什么？」
- 吃完面，把信拿出来；
- 如果对方想看网页，再打开；不想看就不打开。

**核心**：尊重「不要惊喜」这句话，本身就是最好的惊喜。

### 场景 4：吵架后，想修复

**准备**：一封不解释、不辩解的短信；一段语音；不要准备「大礼」。

**顺序**：

1. 先发一条只说感受、不指责的消息；
2. 对方愿意见面/回复后，再送信；
3. 信里只写：我哪里做错了、我当时的感受、我接下来会怎么做；
4. 不要求对方立刻原谅。

**不要**：把网页/礼物当成「道歉的替代品」，也不要在对方没消气时催她看。

## 七、失败预案

| 情况 | 先做什么 | 再做什么 |
| --- | --- | --- |
| 链接打不开 | 自己用手机流量试 | 检查部署是否过期；换 GitHub Pages/Vercel 备用 |
| 图片裂了 | 检查文件名大小写、路径 | 换成 JPG/PNG，避免 HEIC；重新部署 |
| 没有声音 | 让对方点一下页面 | 提供静音版说明；不要反复要求 |
| 密码忘了 | 用提示问题引导 | 不要直接告诉答案，除非对方明显烦躁 |
| U 盘打不开 | 换一个 USB 口/电脑 | 提供单文件版 HTML 作为备用 |
| Mac 提示无法打开 | 右键 → 打开；系统设置里允许 | 改用浏览器直接打开 HTML |
| 对方不想看 | 说「没关系，放那儿吧」 | 不要追问、不要委屈、不要当场演示 |
| 对方看完没有反应 | 正常生活 | 晚上轻轻问一句「有没有哪里打不开」 |

## 八、隐私与边界（必须读）

- **公网链接是公开的**。Cloudflare Tunnel 的随机域名、GitHub Pages、Vercel 都一样。任何人拿到链接都能看。
- **密码不是加密**。主页的信、博物馆的时间胶囊，密码都在浏览器里校验，懂技术的人可以直接看源码。
- **不要放**：身份证、银行卡、密码、住址、公司门牌、学校班级、他人隐私、未经同意的照片。
- **不要用**对方的生日、手机号、身份证后六位做密码。
- **不要追踪**。不要在页面里嵌统计代码去看来的人是谁、在哪、看了多久。
- **公开分享前**，把 `?preview=` 这类调试入口删掉，或至少知道它们能绕过密码。
- **U 盘丢失**等于数据泄露。送出去之前，确保里面没有备份的身份证照片、简历、工作文件。

更完整的部署隐私说明见 [`02-公网部署教程.md`](02-公网部署教程.md)。

## 九、发送前最后一张清单

- [ ] 我知道对方今天的状态，不是在最糟的时候硬送；
- [ ] 页面里没有未经同意的内容；
- [ ] 链接在手机流量下能打开；

## 十、最后

真正让人记住的，从来不是页面做得多复杂，而是：

**你记得她哪天累，记得他吃面不加香菜，记得那次吵架其实谁都没赢。**

技术只是把这些记忆放进一个能打开的地方。
如果有一天网页打不开了、U 盘读不出来了，那些记忆还在你身上，也还在你们之间。

这比任何彩蛋都重要。
