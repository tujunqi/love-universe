# 08 · 十条写完的示例：怎么读，怎么偷

> 这一篇不是新的模板，而是对 [`brain/examples/`](../brain/examples/) 里十条**已经写完**的记录做一次逐条拆解。
>
> 十条记录覆盖了十种不同的场景：开始、旅行、日常、天气、争吵、纪念日、重复的旅行、慢早餐、跨年、生日。它们不是"范文"，而是十种**处理素材的角度**。你可以整条替换成自己的故事，也可以只偷其中一个写法。
>
> 配套文件：
> - 模板：[`brain/templates/`](../brain/templates/)
> - 示例目录：[`brain/examples/README.md`](../brain/examples/README.md)
> - Agent 指令：[`07-Agent整理指令.md`](07-Agent整理指令.md)

---

## 怎么用这十条（三种读法）

### 读法一：整条替换（最快出成果）

挑一条场景最接近的，把里面的人名、日期、地点、对话、细节全部换成你的。保留它的**结构**和**句子节奏**，只换内容。

适合：第一次写记录，不知道一段记录该有多长、该写到多细。

### 读法二：只偷一个动作（最耐用）

每条示例后面都有一个「可以偷走的写法」。只拿那一个动作，用在你自己的素材上。

比如"用一件没做成的计划，反衬真正发生的事"——这个动作可以用在生日、纪念日、任何一次期待落空的约会上。

### 读法三：对照自己的素材（最像你）

先不看示例，自己写一版；写完再对照同场景的示例，看它多写了什么、少写了什么。

通常你会发现：示例多写的是**身体感受**和**具体物件**，少写的是**总结和评价**。

## 十条逐条拆解

### 01 · 在一起的第一晚

**文件**：[`01-在一起的第一晚.md`](../brain/examples/01-在一起的第一晚.md)
**场景**：确认关系，但两个人没见面
**时间**：2023-05-20 20:13

> 20:13，她发来一句："那就在一起吧。"
> 我盯着屏幕看了很久，久到手机自动暗下去，又亮起来。

**它做对了什么**：

1. **选了一个极小的切口**。这么重要的一天，它没有写"我们回顾了这段时间的相处"，只写了一个人在等一条消息。
2. **把等待写成了动作**：手机扣下去、翻过来、再扣下去；倒水、没喝、放在桌角、凉了。没有一句"我很紧张"，但每一句都在说紧张。
3. **时间是精确的**。20:13 不是一个大概的"晚上"，它是这段关系的起点坐标，后面所有计算天数、纪念日都从这里长出来。

**可以偷走的写法**：**写等待，不要写心情。** 把"我很紧张"换成三件你当时无意义地重复做的事。

### 02 · 第一次看海

**文件**：[`02-第一次看海.md`](../brain/examples/02-第一次看海.md)
**场景**：第一次一起出远门
**时间**：2023-07-16

**它做对了什么**：

1. **没有写海，先写路上**。大巴上睡着、醒来发现靠在她肩上、假装没醒——旅行记录里最动人的往往不是目的地。
2. **保留了不完美的照片**。拍糊了、构图歪了、她闭眼了，这些"废片"比精修图更有信息量。
3. **写了一个具体的失误**。比如带了不该带的东西、走错了一段路。完美的一天不值得记录，出错的一天才有人味。

**可以偷走的写法**：**给旅行记录留一个"翻车段落"。** 迷路、下雨、难吃的一顿饭、错过末班车——写清楚当时怎么解决的，比十张风景照更能让人回到现场。

### 03 · 咖啡馆的下午

**文件**：[`03-咖啡馆的下午.md`](../brain/examples/03-咖啡馆的下午.md)
**场景**：一个没有事件的普通下午
**时间**：2023-10-04

**它做对了什么**：

1. **证明了"没事发生"也能写**。整篇没有冲突、没有转折、没有金句，只有一个下午的光、杯子的水痕、她低头时头发的走向。
2. **用环境代替情绪**。阳光移到桌子的哪个位置、店里放的是什么歌、隔壁桌在聊什么——这些是情绪的容器。
3. **结尾不收束**。没有"这真是美好的一天"，而是停在某个还在继续的动作上。

**可以偷走的写法**：**写"无事发生"的记录时，只写五感。** 看到的三样东西、听到的两种声音、碰到的一样东西。不要解释它们意味着什么。

---

### 04 · 雪落在你肩上

**文件**：[`04-雪落在你肩上.md`](../brain/examples/04-雪落在你肩上.md)
**场景**：冬天、下雪、她穿少了
**时间**：2024-01-14

**它做对了什么**：

1. **一个物件贯穿全篇**：围巾。从"她说不冷"到"我把围巾给她"到"后来围巾一直在她那儿"，物件有了自己的时间线。
2. **关心写成了责怪的反面**。"你怎么穿这么少"这句话背后是心疼，但直接写心疼会腻，写责怪又伤人，它选了第三种：什么都不说，把围巾递过去。
3. **冷是具体的**。手僵、耳朵疼、说话有白气、手机掉电快——冷不是形容词，是清单。

**可以偷走的写法**：**给一条记录找一个"贯穿物件"。** 一把伞、一张票根、一只杯子、一件外套。让它在开头出现，在中间被使用，在结尾改变归属。

### 05 · 一场没有赢家的吵架

**文件**：[`05-一场没有赢家的吵架.md`](../brain/examples/05-一场没有赢家的吵架.md)
**场景**：争吵与修复
**时间**：2024-03-09

> 那次吵架的原因，现在已经想不起来了。
> 大概是一件很小的事，小到如果发生在别人身上，我们都会劝一句"至于吗"。

**它做对了什么**：

1. **不判对错**。整篇没有"她太敏感"或"我太固执"，只写两个人当时各自的逻辑。
2. **写了身体反应**：声音变大、手抖、胃空、吵完很饿。情绪先落在身体上，再落到语言上。
3. **修复是一个具体动作**，不是一句"我们和好了"。可能是一起煮了个蛋、下楼扔垃圾时顺便买了吃的、谁先去碰了谁的手。
4. **保留了"想不起来为什么吵"这个事实**。这比编一个清晰的原因更真实。

**可以偷走的写法**：**吵架记录只写三件事——我当时怎么想的、她当时怎么想的、我们怎么停下来的。** 不写谁对谁错，也不写"以后再也不这样"。

> 隐私提醒：这类记录写完先问对方能不能留、能不能给别人看。涉及对方的部分，对方有否决权。

### 06 · 在一起一周年

**文件**：[`06-在一起一周年.md`](../brain/examples/06-在一起一周年.md)
**场景**：第一个纪念日
**时间**：2024-05-20

**它做对了什么**：

1. **写了一个被取消的计划**。订好的餐厅没去成，反而在家吃了顿很随便的饭。计划落空的部分，成了整篇最好的部分。
2. **礼物不是重点，礼物背后的调查才是**。为什么选这个、在哪找到的、差点买错什么。
3. **做了一件"留得下"的事**：把一年的照片挑出十二张，做成一本小册子。记录本身也是礼物。
4. **结尾给下一年留了一句话**，不是誓言，是一个具体的小约定。

**可以偷走的写法**：**纪念日不要写"这一年我们经历了什么"，写"这一天我们做了什么"。** 宏大总结留给月度复盘，纪念日只负责把这一天钉住。

---

### 07 · 第二次看海

**文件**：[`07-第二次看海.md`](../brain/examples/07-第二次看海.md)
**场景**：回到同一个地方
**时间**：2024-09-17

**它做对了什么**：

1. **用"第二次"制造对照**。同一片海、同一家店、同一个拍照位置，变了的是人、是季节、是心境。
2. **写了一句她说过的话，并让它回响**。"不要紧"这三个字在文中出现两次，第二次的含义和第一次不一样。
3. **承认了重复**。不是每一年都会更好，有些年只是"又来了一次"，这种诚实反而珍贵。

**可以偷走的写法**：**给重要的地方建一个"回访"记录。** 同一个地点，每次去都写一条，用 `related` 互相链接。三年后回看，这组记录会自己长出一条线。

### 08 · 一顿很慢的早餐

**文件**：[`08-一顿很慢的早餐.md`](../brain/examples/08-一顿很慢的早餐.md)
**场景**：周末早上，吐司烤糊了
**时间**：2024-11-23

**它做对了什么**：

1. **把一个失败写成温柔**。吐司糊了、咖啡凉了、鸡蛋煎老了，但没有人着急。
2. **时间被拉长了**。一篇早餐能写一千字，是因为它写了等待、写了谁先起床、写了水烧开的声音。
3. **没有对话也能成立**。整篇对话很少，靠动作和空间关系推进。

**可以偷走的写法**：**练习写"低事件密度"的一天。** 这是最难也最有用的一类记录，因为人生大部分日子都是这样过的。写好了，你的记录才不是"年度大事记"。

### 09 · 跨年凌晨的便利店

**文件**：[`09-跨年凌晨的便利店.md`](../brain/examples/09-跨年凌晨的便利店.md)
**场景**：跨年后没回家，在便利店吃东西
**时间**：2025-01-01 00:47

**它做对了什么**：

1. **避开了所有跨年套话**。没有烟花、没有倒计时、没有"新的一年请多指教"，只有一张 00:47 的小票和两串关东煮。
2. **用票据当证据**。时间、金额、买了什么，这些冷冰冰的信息比抒情更可信。
3. **把"普通"写出了仪式感**，但不是靠形容词，是靠精确：几点、多少钱、坐在哪个位置、窗外是什么。

**可以偷走的写法**：**收集物证。** 小票、车票、电影票、药盒、便利贴、外卖单。拍下来或写下关键信息，它们是你以后回忆时最可靠的锚点。

### 10 · 小满的生日

**文件**：[`10-小满的生日.md`](../brain/examples/10-小满的生日.md)
**场景**：她加班很累，说不要惊喜
**时间**：2025-10-16

> 她进门的时候说："我今天很累，能不能不要搞惊喜？"
> 我说："没有惊喜，只有面。"
> 她说："那可以。"

**它做对了什么**：

1. **准备了很多，最后只拿出一点**。买了灯、写了信，但先说"没有惊喜"。克制本身就是一种爱。
2. **尊重了对方当下的状态**。生日不一定非要热闹，累的时候一碗面比一场派对更对。
3. **礼物有一封手写信**。信的内容没有被全文引用，只写了几个句子和"剩下的她自己看"。留白比全盘托出更有余味。
4. **结尾落在"明年"的一个具体想象上**，不是空泛的"希望一直在一起"。

**可以偷走的写法**：**写"我准备了什么"和"我最后做了什么"之间的差额。** 那个差额里，藏着你对她的了解。

## 十条放在一起看：它们共同的规律

把十条并排读，会发现它们几乎都不做这几件事：

| 它们不做的 | 它们改做的 |
| --- | --- |
| 总结"这一天很有意义" | 写一个具体的动作或物件，让意义自己浮出来 |
| 写"我们很幸福" | 写当时的光线、声音、温度、吃到的东西 |
| 把对话写成书面语 | 保留原话，包括停顿、口头禅、没说完的半句 |
| 编一个清晰的因果 | 承认"想不起来了""不知道当时怎么想的" |
| 每篇都写完整 | 有的停在动作上，有的停在问题上，不强行收尾 |
| 只写高光时刻 | 也写吵架、失败、烤糊的吐司、错过的末班车 |

### 一个简单的自检

写完一条，问自己四个问题：

1. 十年后读到这条，我能不能想起**当时在哪儿、光是什么样的**？
2. 里面有没有至少**一句原话**，是对方真的说过的？
3. 有没有一个**具体的物件或数字**（时间、价格、天气、型号）？
4. 如果去掉最后一段的总结，这条记录还成立吗？——如果成立，就把总结删掉。

## 从示例到自己的第一条

如果你现在就想写，按这个顺序：

1. 打开 [`01-每日约会记录模板.md`](../brain/templates/01-每日约会记录模板.md)，复制一份。
2. 文件名用 `YYYY-MM-DD-一句话标题.md`。
3. 先只填三行：日期、地点、今天最想记住的一个瞬间。
4. 再补一个动作、一句原话、一个物件。
5. 写不下去就停，不要凑字数。**记录可以只有三百字。**
6. 写完对照上面的四个自检问题改一遍。

十条示例是给你壮胆的，不是给你模仿的。你写出来的第十一条，应该比它们都更像你。
