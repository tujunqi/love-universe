# 00 · 总目录

> 这是一个完整的「恋爱数字纪念宇宙」。
> 它不是一个网页，而是六件可以分开使用、也能互相配合的东西：
> 一个纪念主页、一个公网入口、一个能塞进 U 盘的离线博物馆、一套长期记录方法、一个本地 Python 小助手，以及一套把惊喜送出去的做法。

---

## 先看这里：你属于哪种情况

### 情况 A：我只想马上看到一个能用的成品

1. 双击根目录的 [`index.html`](../index.html)；
2. 看到封面后，点一下页面；
3. 按 [`01-10分钟修改指南.md`](01-10分钟修改指南.md) 换照片、改日期、改名字；
4. 想发给她时，看 [`02-公网部署教程.md`](02-公网部署教程.md)。

如果完全不想看长教程，只想知道「手机怎么打开、先改哪几行」，直接看
[`12-手机打开与改内容-大白话版.md`](12-手机打开与改内容-大白话版.md)。

**预计时间：10 分钟改完，30 分钟部署完。**

### 情况 B：我想做一个能保存几十年的东西

1. 先看 [`03-U盘离线博物馆.md`](03-U盘离线博物馆.md)；
2. 再把照片和文字放进 `offline/media/`；
3. 按 [`05-开机画面与自动运行.md`](05-开机画面与自动运行.md) 做启动画面；
4. 最后读 [`04-几十年后打开指南.md`](04-几十年后打开指南.md)，做三份备份。

**预计时间：一个周末。**

### 情况 C：我想长期记录，不想只做一个礼物

1. 从 [`06-恋爱第二大脑搭建教程.md`](06-恋爱第二大脑搭建教程.md) 开始；
2. 用 [`07-Agent整理指令.md`](07-Agent整理指令.md) 把聊天记录和照片变成回忆；
3. 参考 [`08-记录示例10条.md`](08-记录示例10条.md) 找手感；
4. 需要查日期、生成情话时，用 [`09-Python小助手运行教程.md`](09-Python小助手运行教程.md)。

**预计时间：每天 10 分钟，持续三个月。**

### 情况 D：我已经做完了，只差「怎么送」

直接看 [`10-惊喜发送全攻略.md`](10-惊喜发送全攻略.md)。
想加彩蛋，看 [`11-进阶彩蛋清单.md`](11-进阶彩蛋清单.md)。

## 三套主题与统一设定

主页默认是「温柔粉」，右上角可以切换到：

- 温柔粉：粉白渐变、柔光、适合大多数场景；
- 夜空蓝：深蓝、星点、适合晚上打开；
- 复古棕：纸张色、旧照片感、适合做「老电影」氛围。

三个模块共用同一套示例设定：

| 项目 | 示例值 | 改哪里 |
| --- | --- | --- |
| 称呼 | 阿星 / 小满 | `js/main.js` 的 `CONFIG`；`assistant/data/memory.json` |
| 在一起 | 2023-05-20 20:13 | 同上 |
| 纪念日 | 5 月 20 日 | 同上 |
| 小满生日 | 10 月 16 日 | 同上 |
| 隐藏密码 | 0520（示例） | 页面右上角 ⚙ 设置 → 信；也可改 `js/main.js` 的 `CONFIG.secretPassword` |

**改的时候三处一起改，不然主页、博物馆和小助手会各说各的。**

## 一句提醒

这个项目里所有的「密码」「隐藏入口」「时间胶囊」都只是**客户端的小把戏**，不是真正的加密。
它们能制造惊喜，但挡不住懂技术的人。

所以：

- 不要放身份证、银行卡、私密照片；
- 公网链接是公开的，任何人拿到都能看；
- 想真正保密，请使用加密压缩包或加密盘；
- 送给对方之前，先确认里面没有你不想被任何人看到的内容。

详细说明见 [`02-公网部署教程.md`](02-公网部署教程.md) 与 [`04-几十年后打开指南.md`](04-几十年后打开指南.md) 的隐私章节。
