# 10 分钟修改指南

> **先看这里：现在有两种改法，大多数情况你不需要这份指南了。**
> 打开网页，点右上角的 ⚙ 设置，名字、日期、照片、时间线、默契题、信，
> 全部能在页面里直接改，改完点「保存并应用」就行。
> 这份指南讲的是另一种方式：直接改代码里的 `CONFIG`——适合想把改动
> 写死在文件里（比如重新生成手机版、分享给别人当模板）的情况。

这份指南只做一件事：让你在不学编程的前提下，把现在这个演示版，改成**只属于你们两个人的纪念宇宙**。

你不需要看懂 HTML、CSS、JavaScript。真正要动的，只有三个地方：

1. `index.html` 里少数几句固定标题；
2. `js/main.js` 最上面的 `CONFIG`；
3. `assets/` 里的照片、音乐、视频。

> 如果你还没搞清「手机上怎么打开」或者「到底该改哪几行」，
> 先看更简短的 [手机打开与改内容（大白话版）](12-手机打开与改内容-大白话版.md)，
> 再回来按这份指南逐项替换。

下面按“从最容易到最费时间”的顺序来。第一次做，建议完整读一遍再动手；熟练以后，十分钟足够。

---

## 0. 动手前的三件事

### 0.1 先复制一份原始文件

在 `love-universe` 文件夹上右键，复制，粘贴，改名成 `love-universe-原始备份`。

以后无论改坏了什么，把备份里的对应文件复制回来就行。**这一步不要省。**

### 0.2 用什么软件改

推荐顺序：

| 软件 | 适合 | 注意 |
| --- | --- | --- |
| VS Code | 最推荐，免费，有颜色高亮和行号 | 保存时确认编码是 UTF-8 |
| 记事本 | 电脑自带，改一两句够用 | 不要用“写字板”，容易改坏引号 |
| Sublime Text / Notepad++ | 轻量好用 | 同样保存为 UTF-8 |

不推荐 Word、WPS。它们会自动把英文引号变成中文引号，代码会直接报错。

### 0.3 一个必须记住的规则

代码里的**英文标点不能换成中文标点**。

- 正确：`"2023-05-20T20:13:00",`
- 错误：`“2023-05-20T20:13:00”，`

看起来几乎一样，但浏览器只认英文的 `"`、`,`、`:`、`[]`、`{}`。

改完保存，双击 `index.html`，刷新页面看效果。**每改一小步就刷新一次**，出问题时最容易定位。

## 1. 改名字、纪念日、生日和密码（约 2 分钟）

打开 `js/main.js`，第 12 行开始就是 `CONFIG`。找到第一段：

```js
names: {
  me: "阿星",
  partner: "小满"
},
startDate: "2023-05-20T20:13:00",
anniversary: {
  month: 5,
  day: 20
},
birthday: {
  monthDay: "10-16",
  title: "生日快乐，我最喜欢的人",
  message: "今天世界又多爱你了一年……"
},
secretPassword: "0520",
defaultTheme: "rose",
```

### 1.1 名字

`me` 是你，`partner` 是对方。

```js
me: "阿星",        // 改成你的名字
partner: "小满"     // 改成 TA 的名字
```

名字会出现在：

- 左上角两个圆形首字母；
- 封面那句 `FOR 小满 · FROM 阿星`；
- 页脚签名；
- 信的落款；
- 生日弹出的祝福。

名字可以是中文、英文、昵称，建议不超过 6 个字，太长会把封面排版挤乱。

### 1.2 在一起的准确时间

```js
startDate: "2023-05-20T20:13:00",
```

格式固定为：

```text
年-月-日T时:分:秒
```

- `T` 是分隔符，不能删，也不能换成空格；
- 时间用 24 小时制；
- 不确定具体分钟？写 `00:00:00` 也可以，只是“第几天”的切换会发生在午夜。

举例：

| 你们在一起的时间 | 应该写成 |
| --- | --- |
| 2022 年 8 月 7 日 下午 3 点 | `"2022-08-07T15:00:00"` |
| 2024 年 1 月 1 日 零点 | `"2024-01-01T00:00:00"` |
| 2021 年 12 月 31 日 晚上 11 点 59 分 | `"2021-12-31T23:59:00"` |

页面上会出现三种时间：

- **我们的第 X 天**：从在一起那天算第 1 天；
- **我们已经在一起 X 天**：已经度过的完整天数；
- **时:分:秒**：今天这一天的实时计时。

三个数字口径略有不同，不是 bug。

### 1.3 每年纪念日

```js
anniversary: {
  month: 5,
  day: 20
},
```

这里只写月份和日期，不写年份。页面会自动计算“下一个纪念日还有多少天”，并在当天显示“今天是一周年 / 两周年”。

如果你们的纪念日按第一次见面算，也可以改成那一天。注意封面上的“距离 X 周年纪念日”会跟着变。

### 1.4 对方生日

```js
birthday: {
  monthDay: "10-16",
  title: "生日快乐，我最喜欢的人",
  message: "今天世界又多爱你了一年……"
},
```

- `monthDay` 格式是 `"月-日"`，十月十六日写 `"10-16"`；
- 生日当天打开页面，会自动弹出祝福，一天只弹一次；
- 不想启用，把 `"10-16"` 改成 `""`；
- `title` 和 `message` 可以随便改，支持 `{me}` 和 `{partner}` 占位符。

### 1.5 隐藏信的密码

最推荐的方式：页面右上角 ⚙ → 信。
可以选：

- 自定义密码；
- 答对 3 道默契题解锁；
- 修改信的标题、正文和落款。

如果改代码，对应字段是：

```js
secretPassword: "0520",
unlockMode: "password", // "password" 或 "quiz"
```

页脚有一个不起眼的入口。点开输入密码或答对题目，会看到一封长信。
改了密码或解锁方式后，本机旧的解锁状态会自动失效，需要重新验证。

**必须知道的一件事**：这是前端密码，只用于制造惊喜，**不是真正的加密**。懂技术的人打开源代码就能看到密码和信的内容。所以：

- 不要放身份证号、银行卡、住址等敏感信息；
- 不要把密码设成对方的支付密码或常用账号密码；
- 如果信的内容非常私密，建议只在线下 U 盘版本里放，或者干脆手写。

### 1.6 默认皮肤

```js
defaultTheme: "rose",
```

- `"rose"`：温柔粉，默认；
- `"night"`：夜空蓝；
- `"retro"`：复古棕。

右上角三个小圆点可以随时切换。用户切换后，浏览器会记住选择；`defaultTheme` 只决定第一次打开时的样子。

## 2. 换照片（约 3 分钟，最影响效果）

### 2.0 先试最快的：点按钮 / 拖照片上传

现在网页里已经支持不用改代码先换照片：

- **照片墙**：把图片拖到相框上，看到虚线提示后松手；手机上点相框右上角的 `↻`；
- **大图查看器**：点开照片后，左上角有 `换一张`；已经换过的话会出现 `还原默认`；
- **封面**：封面下方有 `换这张封面`，也可以把图片拖到封面区域；
- **隐藏视频**：页脚密码信解锁后，点 `上传视频`，或把 mp4 拖到视频区域。

注意：这种方式只把照片存在**当前这台设备的当前浏览器**里。
换手机、换电脑、清浏览器数据、发给别人的单文件版，都不会自动带上。
它适合快速预览效果；最终想长期保存，仍然按下面的方法把照片放进 `assets/photos/`。

如果是在微信/QQ 里点上传按钮没反应，请点右上角 **「…」→「在浏览器打开」**。
微信内置浏览器经常限制本地文件选择，这不是照片坏了。

### 2.1 先准备照片

建议每张照片先处理一下，网页会快很多：

| 项目 | 建议 |
| --- | --- |
| 长边尺寸 | 1600 像素左右，最大不超过 2400 |
| 文件大小 | 单张 200KB 到 800KB |
| 格式 | JPG 最稳；PNG 适合截图；WebP 更小但要确认浏览器 |
| 方向 | 先在手机里把照片旋转正，避免网页里歪着 |
| 文件名 | `p01.jpg`、`p02.jpg`……只用英文数字，不要空格和特殊符号 |
| 隐私 | 关闭照片里的定位信息（微信发原图会带 EXIF，可以用“隐私保护”工具清除） |

不要直接用 iPhone 的 HEIC 格式。大多数浏览器不认，先导出成 JPG。

### 2.2 照片墙：替换 100 个瞬间

打开 `js/main.js`，找到：

```js
photos: [
  { src: "assets/photos/p01.svg", title: "第一次一起看海", date: "2023.07.16", alt: "我们在海边的合照" },
  ...
]
```

每一行就是一张照片，主要字段：

| 字段 | 作用 | 建议 |
| --- | --- | --- |
| `src` | 图片路径 | 改成你的文件名 |
| `title` | 照片下方的小标题 | 写那天发生的事，不要只写“合照” |
| `date` | 照片下方日期 | 用 `2024.05.20` 这种格式最整齐 |
| `alt` | 图片的文字描述 | 给读屏软件和图片加载失败时用，认真写 |
| `category` | 照片分类 | 可留空自动判断，也可填 `food`、`daily`、`travel`、`festival`、`moment`、`love` |

最省事的替换方法：

1. 把你的照片命名为 `p01.jpg`、`p02.jpg`……最多可放到 `p100.jpg`；
2. 放进 `assets/photos/`；
3. 在 `main.js` 里把 `p01.svg` 改成 `p01.jpg`，以此类推；
4. 同步改掉每行的 `title`、`date`、`alt`；
5. 或者直接在页面右上角 ⚙ → 照片里改标题、日期和分类。

如果你只有 12 张照片，就把多出来的行整行删掉。**删的时候连末尾的逗号一起处理**：最后一行不要留逗号。

```js
photos: [
  { src: "assets/photos/p01.jpg", title: "第一次一起看海", date: "2023.07.16", alt: "我们在海边的合照" },
  { src: "assets/photos/p02.jpg", title: "你笑起来的样子", date: "2023.06.03", alt: "你笑起来的样子" }
]
```

照片数量不用是 100，3 张、30 张、100 张都可以，瀑布流会自动排。
页面上方还有分类筛选：全部、吃喝、日常、出行、节日、重要时刻、小心动。

### 2.3 封面：换 3 张轮播图

```js
coverSlides: [
  { src: "assets/photos/cover-1.svg" },
  { src: "assets/photos/cover-2.svg" },
  { src: "assets/photos/cover-3.svg" }
],
```

建议用**横图**，宽度至少 1600 像素。封面会被裁切铺满屏幕，所以人物尽量放在画面中间偏左，避免被裁掉。

替换方法：

1. 把三张合照命名为 `cover-1.jpg`、`cover-2.jpg`、`cover-3.jpg`；
2. 放进 `assets/photos/`；
3. 把上面三行的 `.svg` 改成 `.jpg`；
4. 只想用一张？删掉另外两行，只留一行即可。

封面底部会自动淡出到页面背景色，照片下边缘不需要太干净。

### 2.4 图片不显示的排查顺序

1. **文件名大小写**：`P01.JPG` 和 `p01.jpg` 在服务器上是两个文件；
2. **扩展名**：确实是 `.jpg`，不是 `.jpeg` 或 `.JPG`；
3. **位置**：照片真的在 `assets/photos/` 里，不是桌面上；
4. **路径**：`assets/photos/p01.jpg`，斜杠是 `/`，不是 `\`；
5. **格式**：HEIC、TIFF 浏览器可能不支持，换成 JPG；
6. **刷新**：改完 `main.js` 后按 `Ctrl + F5` 强制刷新。

页面给每张加载失败的照片留了占位提示，不会整页崩掉。

## 3. 改时间线（约 2 分钟）

```js
timeline: [
  {
    date: "2023.03.14",
    title: "第一次见面",
    text: "在朋友的生日聚会上，你坐在我对面……",
    icon: "✦"
  },
  ...
]
```

每个节点四个字段：

- `date`：显示在左边，建议统一 `2023.03.14`；
- `title`：这一天的名字；
- `text`：两三句话，写具体细节，不要写“很开心”这种空话；
- `icon`：一个符号或 emoji，例如 `✦`、`♡`、`☕`、`🎬`、`🚄`。

增删规则和照片一样：每个 `{ ... }` 之间用英文逗号隔开，最后一个后面不要留逗号。

时间线建议 6 到 10 个节点。太多会显得碎，挑真正改变关系的时刻：

- 第一次见面；
- 第一次单独相处；
- 确定关系；
- 第一次旅行；
- 一次争吵后的和好；
- 一次共同完成的事；
- 最近一个普通但珍贵的日子。

## 4. 改情话和默契题（约 2 分钟）

### 4.1 50 句情话

```js
quotes: [
  "喜欢你，是我做过最顺手的事。",
  ...
]
```

- 想改哪句就改哪句，一句一行；
- 每句用英文双引号包住，句末有英文逗号；
- 句子里可以有中文引号、逗号、句号，没问题；
- 不要在一句中间按回车，除非你想让它断行；
- 想加句子，在最后一行后面加 `,` 再写新的一行；
- 想减句子，删掉整行，注意最后一行不要留逗号。

抽卡会尽量避免连续抽到同一句，并记住抽了几次。

### 4.2 默契题

```js
quiz: [
  {
    question: "我们第一次正式约会，是在哪里？",
    options: ["电影院", "咖啡馆", "公园", "夜市"],
    answer: -1
  },
  ...
]
```

默认示例里的 `answer` 都是 `-1`，意思是**不替任何情侣预设正确答案**。

现在有两种玩法：

- **两人默契模式**：一个人先答，另一个人再答，最后看你们有多少选择一样；
- **标准答案模式**：由你们在 ⚙ 设置 → 默契题里给每题选一个正确答案，再让别人来测。

如果要用标准答案模式，把 `answer` 改成正确选项的编号。编号从 **0 开始数**：

- 第一个选项是 `0`；
- 第二个选项是 `1`；
- 第三个选项是 `2`；
- 第四个选项是 `3`。

例如正确答案是“咖啡馆”，它在第二个，所以写 `answer: 1`。
不想设置答案就保持 `answer: -1`，网站会自动隐藏标准答案模式，只保留两人默契模式。

每道题建议 3 到 4 个选项。选项太多，手机上一屏放不下。
题目数量不固定，5 道、8 道都行。分数文案会根据比例自动变化。

## 5. 换背景音乐和隐藏视频（约 3 分钟）

### 5.1 背景音乐

```js
music: "assets/music/bgm.wav",
```

步骤：

1. 把你们的歌转成 `mp3`（兼容性最好）；
2. 命名为 `bgm.mp3`；
3. 放进 `assets/music/`；
4. 把上面改成 `"assets/music/bgm.mp3"`。

注意事项：

- 文件建议小于 8MB，太大加载慢；
- 不要用音乐平台下载的加密格式（`.ncm`、`.qmc` 等），浏览器不认；
- 手机浏览器通常禁止自动播放，用户必须点右上角的音乐按钮；
- 第一次点击后才会出声，这是浏览器规则，不是代码问题；
- 页面切到后台会自动降低音量，回来恢复。

### 5.2 隐藏视频

```js
secretVideo: "assets/video/secret.mp4",
```

1. 视频命名为 `secret.mp4`；
2. 放进 `assets/video/`；
3. 路径保持默认即可。

建议：

- 格式用 MP4（H.264 + AAC），兼容性最好；
- 时长 30 秒到 2 分钟，文件小于 50MB；
- 视频不要放太私密的内容，因为前端资源可以被下载；
- 没有视频也不用删这行。点“播放隐藏视频”时，页面会自动显示“把视频放进来”的提示，不会报错。

隐藏视频的入口在密码信里。先解锁信，再点播放。

## 6. 改那封隐藏的信（约 2 分钟）

```js
letter: {
  title: "写给正在读这封信的你",
  paragraphs: [
    "如果你读到了这里……",
    "我其实不太擅长把喜欢说得漂亮……",
    "谢谢你愿意和我一起……",
    "接下来的路，继续一起走吧……"
  ],
  sign: "—— {me}"
},
```

- `paragraphs` 是一个数组，每一项是一段；
- 想加一段，在最后加 `,` 再写一段；
- 段落里可以有中文标点，但外层必须是英文双引号；
- `{me}` 会自动替换成你的名字，`{partner}` 是对方；
- `sign` 是落款，可以改成 `"—— 永远站你这边的 {me}"`。

写信的建议：

1. 不要写成总结报告，写一件具体的小事；
2. 写一个只有你们知道的细节；
3. 写一句对未来的期待；
4. 控制在 4 到 6 段，太长手机上读起来累。

再次提醒：这封信不是加密的。密码只是“别让手滑的人一眼看到”的门槛。

## 7. 改颜色和主题（可选，约 3 分钟）

打开 `css/style.css`，最上面有三组主题变量。

### 7.1 温柔粉

```css
:root,
html[data-theme="rose"] {
  --bg: #fff8f6;
  --bg-2: #ffeef1;
  --ink: #3d292e;
  --accent: #ce7b8f;
  --accent-strong: #a54f66;
  ...
}
```

最值得改的变量：

| 变量 | 作用 |
| --- | --- |
| `--bg` | 页面主背景色 |
| `--bg-2` | 第二层背景色，用于渐变 |
| `--ink` | 主要文字颜色 |
| `--ink-soft` | 次要文字颜色 |
| `--accent` | 主强调色，按钮、爱心、下划线 |
| `--accent-strong` | 深一档的强调色 |
| `--gold` | 金色点缀 |
| `--cover-tint` | 封面照片上的那层颜色 |

改颜色最简单的办法：把色号复制到浏览器搜索“颜色选择器”，调好再粘回来。

### 7.2 夜空蓝和复古棕

同样的变量名，在 `html[data-theme="night"]` 和 `html[data-theme="retro"]` 两段里。三套主题共用一套结构，只换颜色。

### 7.3 换默认主题

回到 `main.js`：

```js
defaultTheme: "night",
```

保存刷新。注意：如果之前点过主题按钮，浏览器会记住上次选择，默认主题不会立刻生效。想验证，按 `F12` 打开控制台，执行：

```js
localStorage.removeItem("loveUniverse.v1.theme");
location.reload();
```

或者直接用无痕窗口打开。

## 8. 改页面上的固定标题（约 2 分钟）

有些文字不在 `CONFIG` 里，而是直接写在 `index.html` 中。打开 `index.html`，搜索中文即可。

常见的几处：

| 想改什么 | 在 `index.html` 搜索 |
| --- | --- |
| 页面标题（浏览器标签） | `<title>` |
| 顶部导航：照片 / 时间线 / 互动 / 留言 | `nav-link` |
| 照片墙大标题 | `把日子，` |
| 时间线大标题 | `我们是这样` |
| 游戏区大标题 | `把喜欢，` |
| 留言板大标题 | `给以后的我们` |
| 页脚一句话 | `footer` |
| 信的入口文字 | `secretEntry` |

只改标签之间的中文，不要动尖括号 `< >` 和属性。

例如：

```html
<h2>把日子，<em>过成一本相册</em></h2>
```

可以改成：

```html
<h2>我们的日子，<em>都在这里</em></h2>
```

## 9. 打开和测试

### 9.1 直接双击

双击 `index.html`，默认浏览器会打开。

支持：

- Chrome / Edge / Firefox / Safari 近两年的版本；
- 手机通过局域网访问需要先部署，见《02-公网部署教程》；
- 直接用数据线把整个文件夹拷到手机里，用文件管理器打开，部分手机浏览器可能限制本地文件，建议用电脑看或部署后看。

### 9.2 建议的完整测试清单

- [ ] 封面名字、天数、情话正确；
- [ ] 三张封面图能轮播；
- [ ] 右上角三个主题都能切换，刷新后记住；
- [ ] 照片墙里的照片都能点开、左右切换；
- [ ] 时间线节点数量、文字正确；
- [ ] 抽卡能翻面，句子不重复得太频繁；
- [ ] 5 道题答完有分数和评语；
- [ ] 留言能提交，刷新后还在；
- [ ] 密码能打开信，视频按钮不报错；
- [ ] 手机宽度下没有横向滚动条；
- [ ] 控制台（F12）没有红色报错。

### 9.3 最常见的 10 个坑

1. **中文引号**：`“ ”` 换成 `" "`；
2. **少了逗号**：数组每一项之间必须有逗号；
3. **多了逗号**：最后一项后面不要留逗号；
4. **日期格式错**：`2023-5-20` 要写 `2023-05-20`；
5. **图片路径错**：确认文件名、扩展名、大小写；
6. **HEIC 照片**：浏览器不认，先转 JPG；
7. **音乐不响**：先点右上角按钮，手机不允许自动播放；
8. **改了没变化**：`Ctrl + F5` 强制刷新，或清缓存；
9. **主题没变**：浏览器记住了上次选择，清 localStorage；
10. **整页空白**：多半是 `main.js` 少了一个括号或逗号，按 F12 看报错行。

### 9.4 改坏了怎么回滚

1. 打开备份文件夹；
2. 把 `js/main.js` 或 `index.html` 复制回来；
3. 如果照片也乱了，把整个 `assets` 文件夹换回来；
4. 刷新页面。

不要在没有备份的情况下大规模改 `css/style.css`。颜色改错通常还能看清，布局改错会整页乱掉。
