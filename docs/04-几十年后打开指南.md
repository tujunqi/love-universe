# 几十年后打开指南

这一篇不是写给今天的你，是写给**几十年后的你们**，以及那个时候可能坐在电脑前的孩子、家人、甚至陌生人。

它要解决一个很现实的问题：**今天的浪漫，怎么才能活到未来？**

不是“存在网盘里就永远在”，也不是“U 盘插上就能读”。技术会变，账号会失效，文件会损坏，浏览器会更新。真正能穿越时间的，不是某一项技术，而是一套习惯。

---

## 一、先接受三件事

### 1. 没有任何一种存储是永久的

| 存储 | 大致寿命 | 风险 |
| --- | --- | --- |
| U 盘 / SD 卡 | 不通电 5 到 10 年，质量差异大 | 主控损坏、闪存漏电、丢失 |
| 机械硬盘 | 3 到 8 年 | 磁头故障、坏道、长期不通电 |
| 固态硬盘 | 5 到 10 年，长期不通电会掉数据 | 主控故障、固件问题 |
| 光盘（普通） | 10 到 30 年 | 划伤、氧化、光驱消失 |
| M-DISC | 宣传可达百年 | 需要光驱，价格高 |
| 云盘 | 取决于公司 | 停服、封号、欠费、隐私政策变化 |
| 纸质 | 几十年到几百年 | 水、火、虫、搬家丢失 |

结论：**至少三份，放在两个以上不同地方，其中一份是离线。** 这叫 3-2-1 备份。

### 2. 文件格式比硬盘更重要

一个完好的硬盘，如果里面是今天的冷门格式，未来也可能打不开。

优先使用：

- 照片：JPG、PNG、TIFF（原图）；
- 视频：MP4 / H.264，避免 DRM 加密；
- 音频：MP3、WAV、FLAC；
- 文档：PDF/A、TXT、Markdown、DOCX（同时留 PDF）；
- 网页：纯 HTML/CSS/JS，不依赖后端和登录；
- 压缩包：ZIP（不要用冷门自解压格式）。

避免：

- 只有某个 App 能打开的专有格式；
- 带 DRM 的音乐、视频、电子书；
- 需要登录才能看的“云相册”；
- 依赖某个域名、某个账号、某个小程序的内容；
- 只有链接、没有文件的“收藏”。

### 3. 未来的读者需要“说明书”

几十年后，打开 U 盘的人可能不知道：

- 这是什么；
- 谁做的；
- 怎么打开；
- 密码是什么；
- 哪些文件最重要。

所以，**一定要有一份纯文本说明书**，和文件放在一起。不是只放在网页里，因为网页可能打不开。

## 二、这份纪念宇宙的“未来生存包”

建议准备一个文件夹，命名：

```text
我们的纪念宇宙-2026
```

里面放：

```text
我们的纪念宇宙-2026/
├─ 01-先读我.txt                 ← 纯文本说明书
├─ 02-离线博物馆/                ← 整个博物馆
├─ 03-单文件版/
│  └─ 恋爱纪念博物馆-单文件版.html
├─ 04-原始素材/
│  ├─ 照片原图/
│  ├─ 视频原片/
│  └─ 语音/
├─ 05-文档/
│  ├─ 恋爱第二大脑/
│  └─ 重要PDF/
├─ 06-密钥/
│  └─ 密码提示.txt（不要写完整密码）
└─ 07-校验/
   └─ SHA256.txt
```

### 2.1 `01-先读我.txt` 应该写什么

用**纯文本**，UTF-8 编码，不要用 Word。内容建议：

```text
这是我们两个人的纪念网站。

制作人：阿星
制作日期：2026 年 10 月
在一起：2023 年 5 月 20 日

怎么打开：
1. 双击「02-离线博物馆」里的「01-双击我-进入博物馆.bat」；
2. 如果打不开，直接双击「离线博物馆.html」；
3. 如果还是打不开，打开「03-单文件版」里的 HTML 文件；
4. 用 Chrome、Edge、Firefox、Safari 等浏览器打开。

如果浏览器提示文件不安全：
这是本地网页，不会联网，也不会上传任何内容。可以放心打开。

重要内容：
- 照片在 04-原始素材；
- 视频在 04-原始素材；
- 信在网站的「密码信」里，密码提示在 06-密钥；
- 回忆录在 05-文档。

如果未来网页打不开：
所有照片、视频、文字都保留了原始文件。
网页只是展示方式，不是唯一载体。

请定期把这份资料复制到新硬盘。
```

### 2.2 密码怎么留

不要把完整密码直接写在说明书里。可以用“提示”：

```text
密码提示：我们第一次约会那天的月份和日期，四位数字。
```

或者把密码写在纸上，装进信封，和 U 盘分开放。真正重要的内容，不要只依赖一个前端密码。

### 2.3 校验文件

在 Windows PowerShell 里：

```powershell
Get-FileHash "我们的纪念宇宙-2026\03-单文件版\恋爱纪念博物馆-单文件版.html" -Algorithm SHA256
```

把结果存进 `07-校验/SHA256.txt`。以后怀疑文件损坏，重新算一次，对比是否一致。

macOS / Linux：

```bash
shasum -a 256 "恋爱纪念博物馆-单文件版.html"
```

## 三、备份计划：3-2-1

### 3.1 什么是 3-2-1

- **3** 份数据；
- **2** 种不同介质；
- **1** 份放在异地。

例如：

1. 电脑硬盘一份；
2. U 盘 / 移动硬盘一份；
3. 云盘或父母家一份。

### 3.2 推荐组合

| 位置 | 介质 | 更新频率 |
| --- | --- | --- |
| 主力 | 电脑 + 移动固态硬盘 | 每次新增照片后 |
| 离线 | U 盘 / M-DISC | 每半年 |
| 异地 | 云盘加密压缩包 / 父母家硬盘 | 每年 |
| 纸质 | 精选照片 + 说明书 | 每五年 |

### 3.3 云盘怎么用才安全

- 不要只传“原图”，要传**打包后的文件夹**；
- 压缩包加密，密码单独保存；
- 不要用同一个密码注册所有服务；
- 开启两步验证；
- 定期登录，避免账号被回收；
- 不要把云盘当唯一备份。

### 3.4 每年一次的“纪念日维护”

建议每年纪念日做一次，十分钟：

1. 把过去一年的照片、视频放进资料包；
2. 更新 `01-先读我.txt` 的日期；
3. 重新生成一次单文件版；
4. 复制到 U 盘和移动硬盘；
5. 在另一台设备上打开一次；
6. 检查云盘是否能登录；
7. 把最重要的 10 张照片打印出来。

## 四、每隔五年做一次“格式迁移”

技术会过时。今天的浏览器，二十年后可能已经不流行；今天的 MP4，未来可能需要转码。

### 4.1 五年清单

- [ ] 用当时的浏览器打开一次网页；
- [ ] 播放一遍视频和语音；
- [ ] 打开所有 PDF 和 Word；
- [ ] 检查照片是否还能正常显示；
- [ ] 把冷门格式转成当时的通用格式；
- [ ] 把旧硬盘的数据复制到新硬盘；
- [ ] 重新计算校验值；
- [ ] 更新说明书；
- [ ] 告诉一个可信的人：这份东西在哪里、怎么打开。

### 4.2 转换建议

| 旧格式 | 转成 |
| --- | --- |
| MOV / AVI / WMV | MP4 (H.264) |
| WMA / APE | MP3 / FLAC |
| BMP / GIF（照片） | JPG / PNG |
| DOC / WPS | DOCX + PDF |
| 旧网页 / Flash | 截图 + PDF + 文字备份 |
| 专有电子书 | PDF + TXT |

转换时**保留原文件**，不要覆盖。原文件是证据，新格式是通道。

## 五、如果网页打不开，怎么办

按这个顺序试：

### 5.1 换浏览器

- Chrome / Edge / Firefox / Safari；
- 更新到较新版本；
- 不要用 IE；
- 不要用各种“极速浏览器”的马甲。

### 5.2 换打开方式

- 双击 `.bat`；
- 直接双击 HTML；
- 把整个文件夹复制到电脑硬盘再打开（不要直接在 U 盘上运行）；
- 用单文件版；
- 用手机浏览器。

### 5.3 看控制台

按 `F12`，打开 Console，看红色报错：

- `Failed to load resource`：文件路径错或文件丢失；
- `Unexpected token`：JS 文件被改坏；
- `Not allowed to load local resource`：浏览器安全限制，换打开方式；
- 空白页但没有报错：可能是 CSS 或图片路径问题。

### 5.4 用“原始素材”兜底

网页只是展示层。只要 `04-原始素材` 还在，照片和视频就还在。

未来的人可以：

- 直接用图片查看器看照片；
- 用播放器看视频；
- 用记事本读 TXT；
- 用 PDF 阅读器读 PDF；
- 用 Markdown 编辑器读 `.md`。

**这就是为什么原始素材必须单独保存，不能只存在网页里。**

### 5.5 极端情况：自己写一个打开器

如果未来 HTML 还能运行，但旧 JS 不兼容，可以让 AI 或程序员朋友根据 `01-先读我.txt` 和原始素材，重新生成一个简单的相册页。数据在，展馆可以重建。

## 六、关于“云端”的长期风险

### 6.1 域名会过期

- 自定义域名每年要续费；
- 忘记续费，链接就失效；
- 域名可能被他人抢注；
- 不要把这个链接当成唯一入口。

### 6.2 平台会变

- 免费套餐可能取消；
- 公司可能倒闭；
- 内容审核可能误删；
- 账号可能被盗或遗忘。

### 6.3 localStorage 会丢

主页的留言板、心动次数、主题选择存在浏览器的 localStorage 里。它只属于**那一台电脑、那一个浏览器**。

换电脑、清缓存、重装系统、换浏览器，留言就没了。

如果留言很重要：

- 在页面里手动复制保存；
- 截图；
- 写进第二大脑的 Markdown；
- 或者改成真正的后端数据库（需要服务器）。

**不要把“留言板”当成长期档案。**

可以把下面这段放进 `01-先读我.txt`：

```text
你好，打开这个文件的人：

如果你是我们中的某一个，
希望你还记得 2026 年的这个秋天。
```

## 九、最后一句

几十年后，你们可能已经换了城市、换了工作、换了手机，甚至换了身边的人。

这份东西不一定能证明什么，也不一定能被打开。

但只要你今天认真做了备份、写下了说明书、把最重要的照片打印了出来，它就有机会在某个普通的下午，被一个已经长大的人重新打开。

那时候，页面上的天数会停在一个很大的数字。

而你们会知道，那些普通的日子，真的曾经闪闪发光。
