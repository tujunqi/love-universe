# 安装成 App 与打包 APK

先说结论：

**不用上架应用商店，也不用懂代码。网页本身就支持「安装成 App」：桌面多一个爱心图标，点开全屏、没有地址栏，断网也能打开。**

两种方式选一个就好：

1. **安装成 App（推荐，5 分钟）**：手机上点几下就完成，免费、无广告；
2. **打包 APK（可选）**：想把一个安装包文件直接发给 TA 时用，借助微软的免费工具 PWABuilder。

前提：网站已经发布到公网链接 `https://tujunqi.github.io/love-universe/`（就是 README 里部署好的那个网址）。

---

## 一、安装成 App（推荐）

### 安卓手机（Chrome / Edge / 大部分国产浏览器）

1. 用浏览器打开网址：`https://tujunqi.github.io/love-universe/`；
2. 任选一种安装入口：
   - 页面**顶栏出现一个下载图标按钮**（⬇ 形状），点它 → 确认安装；
   - 或点浏览器菜单（右上角「⋮」）→「**安装应用**」或「**添加到主屏幕**」；
3. 桌面上出现一个玫红色爱心图标，点它就能像普通 App 一样打开。

### iPhone（必须用 Safari，这是苹果的限制）

iPhone 不会弹「安装」按钮，任何浏览器都弹不出来，只能手动添加：

1. 用 **Safari** 打开网址（微信里点开的不行，先点右上角「…」→「在 Safari 打开」）；
2. 点底部中间的**分享按钮**（方框带向上箭头）；
3. 往下滑，点「**添加到主屏幕**」→ 右上角「添加」；
4. 桌面出现爱心图标，名称是「纪念宇宙」。

### 装好以后是什么样子

- 全屏打开，没有浏览器地址栏，和真 App 一样；
- 桌面图标是玫红渐变的爱心；
- **断网也能打开**：第一次联网打开过之后，照片、音乐都缓存进了手机，之后坐地铁、没信号照样能看。

## 二、打包 APK（可选：想发安装包给 TA）

APK 是安卓的安装包文件。适合「不想发网址、想直接发一个能装的文件」的场景。

1. 电脑打开 **https://www.pwabuilder.com**（微软的免费服务，不用注册）；
2. 在首页输入框粘贴网址 `https://tujunqi.github.io/love-universe/`，点「Start」；
3. 等它检测完（绿色分数即可），点「**Package For Stores**」；
4. 选 **Android** 平台 → 直接点「Download」下载；
5. 得到一个 APK 文件，微信/QQ/U 盘发给对方；
6. 对方手机安装时，会提示「禁止安装未知来源应用」——在设置里允许这一次即可（这是安卓的正常安全提示，不是病毒）。

说明：

- 这个 APK 本质上是网页的壳，**断网可用性和直接安装 App 完全一样**；
- iPhone 不能用 APK，苹果手机请用第一节的 Safari 方法。

## 三、以后改了内容，App 怎么更新？

不用重新安装：

1. 你像往常一样改内容、push 到 GitHub；
2. 对方打开 App，**下拉刷新一下**（或关掉重开），就会自动拿到最新版。

原理：网页用的是「网络优先」策略——有网时永远先拿新内容，没网时才用缓存。所以不用担心对方看到旧版本。

## 四、常见问题

**问：iPhone 上为什么找不到「安装」按钮？**
正常。苹果只允许 Safari 手动「添加到主屏幕」，任何网站都弹不出安装按钮。照第一节 iPhone 的步骤做即可。

**问：断网后打不开？**
离线缓存要在「联网状态下完整打开过一次」之后才生效。先联网打开一遍，滑到照片墙让照片加载完，再断网试。

**问：桌面图标不是爱心 / 名字不对？**
长按图标删掉，清一下浏览器缓存（浏览器设置 → 清除缓存），重新按第一节的步骤装一次。

**问：安卓装好后有地址栏？**
说明是用「添加到主屏幕」而不是「安装应用」，或者该浏览器不支持完整安装。换 Chrome 或 Edge 打开网址再装一次即可。

**问：电脑能装吗？**
能。Chrome/Edge 打开网址，地址栏右侧会出现一个安装图标，点一下就装到电脑上了，效果一样。
