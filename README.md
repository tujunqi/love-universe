# 恋爱纪念宇宙 love-universe

一个**不改一行代码就能完全自定义**的恋爱纪念网页：
双击打开，点右上角 ⚙，把名字、天数、照片、时间线、默契题、那封信，
全部换成你们自己的——然后把这份文件发给 TA。

不需要服务器、不需要数据库、不需要联网，所有内容只存在浏览器里。
全部用原生 HTML / CSS / JavaScript 和 Python 标准库写成。

---

## 30 秒开始

### 1. 打开主页

双击 [`index.html`](index.html)。

- 封面：在一起的天数、秒级计时、轮播合照、专属情话；
- 往下滚：100 格分类照片墙、时间线、恋爱清单、抽情话、默契大考验、留言板；
- 右上角：⚙ 设置 / 三套主题 / 背景音乐；
- 页脚：一封上锁的信（示例密码 `0520`）。

### 2. 点 ⚙，把它变成「你们的」

不用改任何代码，在设置面板里就能改：

| 页签 | 你能改什么 |
| --- | --- |
| 我们 | 两个人的名字、在一起的准确时间、每年纪念日、生日、封面情话、默认皮肤 |
| 照片 | 100 个瞬间的标题、日期、分类，加格子、删格子（换图片直接拖到相框上） |
| 时间线 | 「我们走过的每一个坐标」：日期、标题、内容、图标，随便加减 |
| 默契题 | 出你们自己的题（预置 10 道），默认不替任何人决定答案；也可以设置标准答案 |
| 信 | 信的标题、正文、落款；解锁方式：自定义密码，或答对 3 道默契题 |
| 备份 | 自动本地快照 + 导出/导入全部设置和照片；支持选择文件、拖拽 JSON，导入失败会显示原因 |

改完点「保存并应用」，页面立刻焕然一新。

### 3. 换照片 / 换封面 / 传视频（拖拽就行）

- **照片**：把图片直接**拖到任意相框**上，或点相框右上角「↻ 换这张」，或在大图里「换一张」；
- **封面**：把图片**拖到封面**上，或点封面上的「换这张封面」；
- **隐藏视频**：打开页脚那封信，点「上传视频」或把 mp4 拖进信里；
- 传错了随时「还原默认」。

上传的照片和视频存在**这台设备的浏览器**里（IndexedDB），不会上传到任何地方。
想让别人也看到：用「备份」页签导出文件发给他，或按老方法把照片放进 `assets/photos/`。

### 4. 看离线博物馆

双击 [`offline/离线博物馆.html`](offline/离线博物馆.html)，
或双击 [`offline/打开我-Windows.bat`](offline/打开我-Windows.bat)。

### 5. 用 Python 小助手

Windows 双击 [`assistant/启动小助手.bat`](assistant/启动小助手.bat)，
纪念日语提醒、情话、约会策划，详见 [`docs/09-Python小助手运行教程.md`](docs/09-Python小助手运行教程.md)。

## 手机上怎么看？

手机不用装 App，浏览器就是播放器。五种方式，按方便程度排序：

- **安装成 App（推荐）**：手机打开网址 → 安卓点顶栏的下载按钮/菜单「安装应用」，
  iPhone 用 Safari「添加到主屏幕」——桌面有爱心图标、全屏无地址栏、断网也能打开，
  详见 [`docs/13-安装成App与打包APK.md`](docs/13-安装成App与打包APK.md)；
- **直接发文件**：把 `手机版/恋爱主页-发手机打开这份.html` 发微信/QQ，
  手机上选「用浏览器打开」即可——这一个文件自带全部照片和音乐；
- **同一个 Wi-Fi**：双击根目录的 `手机预览-Windows.bat`（免安装，系统自带 PowerShell），
  把窗口里显示的地址输入手机浏览器；
- **发给她一个网址**：按公网部署教程做一个链接，她在微信里点开后选「在浏览器打开」；
- **离线博物馆**：发 `offline/单文件版/恋爱纪念博物馆-单文件版.html`，用手机浏览器打开。

注意：日常改内容用的主页是 `index.html` + `css/` + `js/` + `assets/` 的组合，
**不能只把 `index.html` 一个文件发出去**——想发文件就发上面的「手机版」单文件。
iPhone 本地文件限制、详细步骤、常见坑，见
[`docs/12-手机打开与改内容-大白话版.md`](docs/12-手机打开与改内容-大白话版.md)。

## 项目结构

```text
love-universe/
├─ index.html                     核心纪念主页（主页三文件之一）
├─ manifest.webmanifest           PWA 清单：安装成 App 的名称、图标、全屏模式
├─ sw.js                          Service Worker：离线缓存（第二次访问后断网也能打开）
├─ 手机预览-Windows.bat           同一 Wi-Fi 下用手机看（免安装，用系统自带 PowerShell）
├─ 手机版/                        发手机用的主页单文件版（自带全部照片和音乐）
│  ├─ 恋爱主页-发手机打开这份.html
│  └─ 怎么发到手机-必读.txt
├─ css/
│  └─ style.css                   样式、动画、三套主题、设置面板
├─ js/
│  └─ main.js                     CONFIG 默认数据 + 设置面板 + 全部交互
├─ assets/
│  ├─ photos/                     3 张封面 + 100 张照片墙占位图
│  ├─ icons/                      PWA 图标（玫红爱心，安装到桌面用）
│  ├─ music/bgm.wav               背景音乐（代码合成的浪漫钢琴曲，可换成你们的歌）
│  ├─ video/                      隐藏视频（把你们的视频命名为 secret.mp4 放进来）
│  └─ voice/                      语音（备用）
├─ docs/                          00~13 全部教程
├─ offline/                       U 盘离线博物馆（文件夹版 + 单文件版 + 启动脚本）
├─ brain/                         恋爱第二大脑（模板 + 示例 + Agent 指令）
├─ assistant/                     Python 本地小助手
└─ tools/                         可选：构建与自检脚本（需要 Node.js）
   ├─ build-single-file.js        生成离线博物馆单文件版
   ├─ build-phone-single.js       生成「手机版」主页单文件版
   ├─ make-music.js               合成浪漫背景音乐（纯代码，无素材依赖）
   ├─ make-pwa-icons.js           生成 PWA 爱心图标（assets/icons/）
   ├─ make-assets.js              生成封面 + 前 20 张占位图
   ├─ make-photos-extra.js        生成第 21~100 张占位图
   ├─ audit-ui.js                 无头浏览器全套自检（截图 + 交互测试）
   ├─ audit-settings.js           设置、引导横幅、备份导入与安全专项自检
   ├─ audit-upload.js             拖拽上传、封面、隐藏视频专项自检
   ├─ audit-phone-single.js       手机版单文件 file:// 自检
   ├─ phone_preview.ps1           手机预览（PowerShell 版，被根目录 bat 调用）
   └─ phone_preview.py            手机预览（Python 版，Mac/Linux 也能用）
```

`tools/` 不是运行项目必需的。只有想重新生成单文件版、重新合成音乐、
重新生成占位图或跑自检时才需要 Node.js。

## 两种改内容的方式，选适合你的

| | 页面里点 ⚙（推荐） | 改 js/main.js 的 CONFIG |
| --- | --- | --- |
| 适合谁 | 所有人 | 想深度定制、要发布给很多对情侣的人 |
| 数据在哪 | 这台设备的浏览器（可导出备份迁移） | 写死在代码里，谁拿到文件就是谁的数据 |
| 换照片 | 拖拽上传，秒生效 | 改文件名 + 刷新 |
| 改完要做什么 | 点保存，自动刷新 | 重新构建手机版（如有需要） |

**两种方式可以混用**：CONFIG 是出厂默认，⚙ 设置里改的内容会覆盖它；
「备份 → 恢复出厂默认」可以随时回到 CONFIG 的样子。

## 隐私与分享

- ⚙ 设置里改的一切、上传的照片和视频，**只存在当前设备的浏览器**，不上传云端；
- 每次保存设置、导入备份、恢复默认前，会自动生成一份本地快照，可一键回滚；
- 普通版本更新不会清掉 localStorage / IndexedDB；快照防的是误操作、清缓存、换设备；
- 「恢复出厂默认」会清空当前设置、留言、主题、解锁状态和上传照片，但快照仍保留；
- 网页里的密码只是"防手滑"，不是真正加密，不要放太私密的内容；
- 把备份 json 发给朋友 = 把你们的设置送给他当模板，他再改成自己的；
- 公网部署后链接是公开的，详见 [`docs/02`](docs/02-公网部署教程.md) 的提醒。

## 常用命令（可选）

```bash
# 生成手机单文件版（改完 CONFIG 或重要内容后跑一次）
node tools/build-phone-single.js

# 重新合成背景音乐
node tools/make-music.js

# 重新生成占位图
node tools/make-assets.js && node tools/make-photos-extra.js

# 全套自检（先起预览服务器，再跑；产物在 tools/audit*/report.json）
powershell -NoProfile -ExecutionPolicy Bypass -File tools/phone_preview.ps1
node tools/audit-ui.js
node tools/audit-settings.js
node tools/audit-upload.js
node tools/audit-phone-single.js
```
